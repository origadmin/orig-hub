# P6：EE 导出本体设计（byte-ownership 收尾）

> 依据：`docs/design/byte-ownership-amendment-2026-09-24.md` §4 P6；用户目的 = 把媒体库中**已就绪**的视频+内容+图片导出，供 orig-studio-ee 上传。

## 1. 输出结构

导出生成一个**本地目录**（用户选定），目录内：

```
<targetDir>/
  manifest.json
  series-<id>/
    content.json
    <episodeNo>-<titleSlug>.<ext>   ← 视频文件
    images/
      poster.<ext>                   ← 剧集/条目 poster
      <episodeNo>-<n>-<titleSlug>.<ext> ← 集级挂图
```

## 2. manifest.json

```json
{
  "schema": "orighub-export/1",
  "exportedAt": "2026-09-25T02:55:00Z",
  "seriesCount": 1,
  "series": [
    {
      "id": 101,
      "title": "...",
      "description": "...",
      "kind": "series",
      "directory": "series-101",
      "contentPath": "series-101/content.json"
    }
  ]
}
```

## 3. content.json（每部剧集一份）

```json
{
  "id": 101,
  "title": "...",
  "description": "...",
  "kind": "series",
  "episodes": [
    {
      "episodeId": 123,
      "episodeNo": "S1E1",
      "title": "...",
      "description": "...",
      "video": "S1E1-title.mp4",
      "images": ["images/poster.jpg", "images/S1E1-0-cover.jpg"]
    }
  ]
}
```

## 4. 端点与行为

- `POST /api/media/export`
  - Body: `{ seriesIds?: number[], targetDir: string }`（`seriesIds` 缺省 = 全库）
  - 先走 `export_readiness` 校验；**任何 issue 存在 → 422 + issue 列表**（P5 preview 已做闸口，后端再防一次）。
  - 校验通过后创建目录、复制字节、写 manifest/content.json。
  - 复制是**复制不是移动**——导出是 EE 上传的临时包，库内字节不动。
  - 返回：`{ targetDir, exportDir, seriesCount, filesCopied, manifestPath }`。

## 5. 前端交互

- `ExportPreviewDialog` 在 `issuesTotal === 0` 时显示「导出」主按钮；否则禁用并提示先补齐。
- 点击导出 → `POST /api/media/export` → 成功后显示导出目录路径 + "打开文件夹" 按钮。
- 保持 P5 的只读 preview 语义；导出动作另端点，一动词一端点。

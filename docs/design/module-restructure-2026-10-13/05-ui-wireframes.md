# 界面框架与线框（UI Wireframes）

> **⚠️ 最高效力（2026-10-13 三轮/四轮）**：界面真值以可交互原型 **[`prototype/`](prototype/index.html) v3**
> 与 [09](09-revision-2026-10-13-v2.md) §9/§10 为准——**五项一级 + 两棵树**：
> 「文件」树（分类组：视频/音乐/图片/文档/压缩/其他；资料库组：剧集/标签/未归档 + 剧集详情 drill-in）、
> 「下载」树（父行=全部任务全局监控；下载中/已暂停/已完成三档；**页内无状态 tabs**，仅来源筛选 chips）；
> 命名 文件/下载/Telegram（D14）；媒体库无独立入口；共享 L2 为内容区 segmented（非侧栏树）。
> 本文以下 ASCII 线框与原型/09 冲突处（含「TG 采集」旧称、六/七域、文件页 subtabs/rail 旧形态）一律以后者为准。

- 配套：[01-frontend-architecture.md](01-frontend-architecture.md)
- 视觉基线（沿用现状，不换风格）：dark-first，zinc/slate 底 + emerald/cyan 主色；侧栏展开 w-48 / 折叠 w-12；
  顶 ContextBar h-12；底部状态栏 h-8（连接点唯一渲染点仍在右下）。
- 通用约定：主按钮一律标题栏右侧；无 FAB；弹窗关闭按钮 outline/sm；中文文案；设置用 divider 列表。

## 1. 应用骨架

```
┌────────────────────────────────────────────────────────────────────────────┐
│ TitleBar（拖拽区 / 窗口控件）                                                 │
├──────────┬─────────────────────────────────────────────────────────────────┤
│          │ ContextBar h-12（当前页面标题 ICON+名 ｜ 上下文动作 ……  状态点）    │
│ 下载  ▾   ├─────────────────────────────────────────────────────────────────┤
│ 文件     │                                                                 │
│ TG 采集  │                  当前域主内容区                                     │
│ 共享      │                                                                 │
│ ─────    │                                                                 │
│          │                                                                 │
│ 设置     │                                                                 │
├──────────┴─────────────────────────────────────────────────────────────────┤
│ 状态栏 h-8  ……                              ● 实时连接（右下角唯一连接点）       │
└────────────────────────────────────────────────────────────────────────────┘
```

- 侧栏：五域 + 分隔线 + 设置置底；「共享」关闭态在图标旁小灰点 `OFF`（不是红点）。
- TG 入口常驻：未启用时点击进入引导页（见 §4），不再从侧栏消失。
- 折叠态：仅 ICON + 状态点；tooltip 显示中文名。

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ▤ 文件                                            [↑ 导入]  [⇩ 导出]         │
├──────────┬─────────────────────────────────────────────────────────────────┤
│ 内容 ▹    │ 〔全部〕〔视频〕〔图片〕〔音频〕                                    │
│ 剧集      ├─────────────────────────────────────────────────────────────────┤
│ 标签      │ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐                  │
│ 文件夹    │ │ 封面     │ │ 封面     │ │ 封面     │ │ 封面     │                  │
│          │ │ 标题 12′ │ │ 标题 3′  │ │ 标题     │ │ 标题 44″ │                  │
│          │ │ [编辑][删]│ └─────────┘ └─────────┘ └─────────┘                  │
│          │ └─────────┘ …（MediaCard 现状体系不变）                            │
└──────────┴─────────────────────────────────────────────────────────────────┘
```

- 「内容」= 媒体领域投影（现媒体库 items）；「剧集」一级；「标签」；
  「**文件夹**」M2 新增，浏览**全部受管字节**（含文档/压缩包）：

```
┌──────────┬─────────────────────────────────────────────────────────────────┐
│ 文件夹 ▹  │ 根目录：〔库根〕〔下载-Videos〕〔下载-Others〕…                      │
│          ├─────────────────────────────────────────────────────────────────┤
│          │ 📁 2026/                                    12 项 · 8.4 GB        │
│          │ 📄 manual.zip                              压缩包 · 200 KB  [定位] │
│          │ 🎬 demo.mkv  〔来源：TG〕                     视频 · 482 MB        │
│          │ 🖼 cover.png 〔来源：下载 TRC-00011〕          图片 · 1.2 MB        │
│          │ ⚠ 孤儿条目：old-deleted.mp4（有条目无文件）     [重新定位] [移除条目] │
└──────────┴─────────────────────────────────────────────────────────────────┘
```

- 行图标按 kind 着色，同页同体系；非媒体文件只出现文件夹视图，不进「内容」。
- 删除入口：卡片悬停/常驻单条删除（BUG-057），批量走顶部勾选工具条（outline 按钮）。
- 点击媒体文件仍开全局 MediaViewer；非媒体给「打开所在位置/系统打开」。

## 6. 设置域（七区块，左锚点 + 右 divider 列表）

```
┌──────────────┬──────────────────────────────────────────────────────────────┐
│ 通用         │ 通用                                                         │
│ 下载与存储    │ ─────────────────────────────────────────────────────────   │
│ 网络与代理    │ 语言                          [中文 ▾]                          │
│ 播放引擎      │ 主题                          [深色 ▾]                          │
│ TG 插件      │ 开机启动                      〔开关〕                          │
│ 共享         │ ─────────────────────────────────────────────────────────    │
│ 关于         │                                                              │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

各区块内容归属（与 spec §3.5 / §5 一致）：

- **下载与存储**：默认下载目录、分类目录（视频/音乐/图片/文档/压缩/其他）、并发/速度；
  **媒体库根目录 libDir 归此**（M0 先只搬 UI，写入端点不变；M3 随库迁 daemon）。
- **网络与代理**：监听接口（InterfacePicker）、代理开关/地址/测试（现 network+proxy 合并展示）。
- **播放引擎（M1）**：

```
│ 播放引擎（ffmpeg）                                                           │
│ ─────────────────────────────────────────────────────────────────────────   │
│ 状态      已安装 · ffmpeg 7.1 · C:\…\bin\ffmpeg.exe            [重新检测]      │
│ 硬件加速  自动（推荐：NVIDIA CUDA #0）        [自动 ▾]  显卡 [#0 ▾]           │
│ 手动指定  [选择 ffmpeg.exe…]   （未安装时：[一键安装]（M4）/ 离线安装说明）     │
│ ⚠ 当前被环境变量 ORIG_TG_HWACCEL=off 覆盖（只读提示）                          │
```

- **TG 插件**：启用开关（从现「通用」迁回）、账号列表/登录（现 accounts tab 内容）、监控默认值；
  底部一行「缓存管理 →」打开 CacheManagerDialog（字节清理 tab）。
- **共享（M5）**：同 §5 启用表单（网卡/端口/令牌/访问记录），侧栏开关与本区块开关同源。
- **关于**：应用与各 sidecar 版本、数据目录（打开）、日志（打开）、许可证。

行控件统一：label（主）+ 描述（次行灰字）+ 右侧控件；switch 禁用时带状态标签（已启用/即将推出）；
纯展示项不渲染保存按钮；危险操作二次确认。

## 7. 跨域状态文案

- 媒体来源离线（TG 关/未登录）：沿用现有 `media.sourceOfflineHint` 口径——「库内内容照常可播可管理，仅『重新缓存』暂不可用」。
- 库/服务两态拆分（M3）：区分「媒体库未就绪（库）」与「TG 未连接（来源）」两个空状态，重试按钮各找各的服务。
- 转码 501（M1 起）：播放器内给可行动提示「未检测到 ffmpeg，转码播放不可用 → 去安装」，跳 settings.engine。

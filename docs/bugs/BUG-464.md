# BUG-464: 本集图组瓦片尺寸硬编码（88×120 / 80×112），宽容器右侧留大片空白

- 状态: fixed
- 发现日期: 2026-10-27
- 模块: shell
- 严重程度: low
- 排期: 2026-12-26

> 来源：用户报告「**本集图组 编辑图大小需要重新考虑，当前一行 4 张，但是没有充分利用
> 空间，右边大量空白。放大是必须的，但是 3 张/4 张根据自己考虑下。**」

## 现象

1. 显示态挂图瓦片是**固定像素**：`EpisodeExpanded.tsx:371`
   `className="group/img relative h-[120px] w-[88px] shrink-0 ..."`，
   容器是 `flex flex-wrap` ⇒ 单张大小与容器宽度**完全无关**，
   宽右栏里排完 4 张左右就在右侧留下大片空白。
2. 编辑态缩略图同为固定像素：`EpisodeEditPanel.tsx:216`
   `className="h-20 w-28 ..."`（80×112，BUG-429 从 `h-14 w-20` 放大过一轮），
   容器 `flex flex-wrap gap-2`（`:206`）⇒ 同样不随宽度放大。
3. 挂图选择对话框：`EpisodeImagePickerDialog.tsx:90` 用
   `grid-cols-4 sm:grid-cols-6`，但外层受 `max-w-2xl`（`:67`）限制，
   项数一多单格就回到图标级尺寸。

## 根因

1. **尺寸是像素常量，不是「列数 × 容器宽度」的函数。** `flex-wrap` 只决定
   「一行能放几个」，不决定「每个多大」⇒ 剩余宽度变成死白，而不是分配给瓦片。
2. **列数规则与尺寸规则分离**：`albumGridClass`（`lib/tgmedia.ts:124-127`）最多
   只到 3 列且只给列数、不给尺寸；图组这里连它都没用，直接写死 `w-[88px]`。
3. BUG-429 只做了「按图标尺寸渲染 ⇒ 放大到 80×112」这一轮修正，
   修的是「够不够大」，没修「是否随容器自适应」—— 放大是必要的，
   但固定尺寸放大到任何容器都会留下新的空白。

## 复现

1. 文件管理 → 剧集 → 打开一部有挂图的剧集（或给某一集挂 ≥4 张图）。
2. 观察右栏「本集图组」：4 张 88×120 的瓦片靠左排列，右侧整片空白。
3. 点「编辑本集」⇒ 编辑态缩略图 80×112，同样靠左，右侧空白。

## 修复方向（未实施；≥2 实质选项 + 1 个「不做」）

### 选项 A（推荐）：改网格 + 列宽自适应（列数 3/4 二档，瓦片填满列宽）

- 显示态改为 `grid grid-cols-3 min-[1400px]:grid-cols-4`（或
  `repeat(auto-fill, minmax(120px, 1fr))`），瓦片 `w-full` + `aspect-[3/4]`，
  由列宽决定大小；容器越宽图越大，不再留白。
- `涉及:` `EpisodeExpanded.tsx:371`（瓦片类）与其容器（`:206` 附近或 SeriesDetail
  的图组容器）；`EpisodeEditPanel.tsx:206-217` 同步。
- `量化:` 单张宽度由 88px → 列宽（1fr / 3 或 4 列，实测 ≥140px）；
  列数 3（窄）/ 4（宽）；既有 testid `episode-image-open` / `episode-image-detach` 不变。
- `回归风险:` 中 —— 与 BUG-270（图组堆叠/跑马灯）共用同一区块，需确认
  「超出才跑马灯」的判据不被列数变化打破；BUG-429 的「露边」判据需重测。
- `后果:` 充分利用宽度，图更大；3/4 列按容器断点切换。

### 选项 B：固定 3 列，瓦片填满 1/3 列宽（不再用 4 列）

- `涉及:` 同上，列数恒 3。`量化:` 单张更大（≈1/3 容器宽）。
- `回归风险:` 低 —— 列数不随宽度变，版式稳定。
- `后果:` 图最大，但一屏能同时看到的张数变少（10 张要滚更多）。

### 选项 C：只放大固定尺寸（88×120 → 120×160 / 编辑态 80×112 → 112×160）

- `涉及:` 两处类名常量。`量化:` 单张 +36%。
- `回归风险:` 低。
- `后果:` 图更大，但**右侧空白依旧**（根因未动）—— 只缓解「看不清」，
  不解决「浪费空间」。

### 选项 D：不做

- `涉及:` 无。`量化:` 0。`回归风险:` 无。
- `后果:` 宽屏下右侧持续大片空白，图始终偏小。

## 关联

- BUG-429（fixed）：本集图组平铺露边太薄 + 编辑态缩略图按图标尺寸渲染
  （已放大一轮）—— 本档是其未竟部分（自适应）。
- BUG-270（open）：本集图组堆叠 / 跑马灯 —— 同一区块，改列数须一并验。
- BUG-412（fixed）：编辑态与显示态图文顺序 —— 尺寸改动须保持两态顺序一致。

## 验收证据
瓦片尺寸改为「容器宽度 × 列数」的函数：`grid auto-fill minmax(96px/88px,1fr)` + `aspect-[3/4]`，
宽容器不再在右侧留死白（显示态 96px 下限、编辑态 88px 下限）。

落点 `tauri-shell/src/components/media/EpisodeExpanded.tsx`、`EpisodeEditPanel.tsx`。
反向证伪：改回固定宽度瓦片，宽右栏右侧重新出现整片空白。

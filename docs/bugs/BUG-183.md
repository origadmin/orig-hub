# BUG-183 剧集介绍展示位缺失：活的剧集内页不渲染剧集介绍，唯一承载它的 `SeriesHero` 是零 importer 孤儿

- **状态**: open
- **发现日期**: 2026-09-29
- **模块**: shell
- **严重程度**: mid

关联 BUG-149（重构不是删能力的授权）、BUG-181 家族、BUG-041（介绍可显式清空）。

## 现象

用户在剧集内页**看不到「剧集介绍」**，也无法在页面上编辑它 —— 而剧集介绍（`media_series.description`）
是既有数据字段，既有「显示 + 展开/收起 + 编辑入口」的完整能力。

对用户表现为「剧集介绍这块没做」，但**能力曾经存在且仍以组件形式躺在仓里**，
只是没有任何地方引用它。**任何按 testid 计数或按组件名检索的验收脚本看它都可能是「有」的**。

## 根因

**活的剧集内页 `SeriesDetail.tsx` 从头到尾不渲染剧集介绍。**

| 位置 | 事实 |
|---|---|
| `tauri-shell/src/components/media/SeriesDetail.tsx` | 全文 **`detail.description` 零命中**（`grep -n "detail\.description\|series\.description\|seriesDescription"` 无输出）——剧集介绍字段在活实现里**从未被读取** |
| `tauri-shell/src/components/media/SeriesDetail.tsx:523` | 渲染的是 `{cur.description}` —— 这是**当前分集**的介绍（`cur` 是 `MediaEpisode`），**不是剧集介绍** |
| `tauri-shell/src/components/media/SeriesHero.tsx:208` | `data-testid="series-description"` —— **全仓唯一**的剧集介绍展示位（`grep -rn "series-description" tauri-shell/src` 只此一处命中） |
| `tauri-shell/src/components/media/SeriesHero.tsx:210` | `{detail.description}` —— 真正渲染剧集介绍的地方 |
| `tauri-shell/src/components/media/SeriesHero.tsx:212-233` | 完整的「展开/收起」(`series-desc-toggle`) + 「编辑入口」(`series-desc-edit`) 能力 |
| `tauri-shell/src/components/media/SeriesHero.tsx` | **零 importer**（`grep -rn "from '.*SeriesHero'" tauri-shell/src` 无命中）⇒ 上述能力全部不可达 |

**决定性证据（能力曾经存在 + 自称零删减却实际缺失）：**

`tauri-shell/src/components/media/SeriesDetail.tsx:88-91` 的组件头注释白纸黑字写着：

> `EpisodeBoard` / `EpisodeExpanded` / `SeriesHero` 上的**全部能力**（编辑 / 挂图 / 多源 / 上移下移 /
> 移除 / 播放 / 前往条目 / 重缓存 / 灯箱 / 标签 / 合并 / 删除 / 导出）逐一迁入，
> **能力零删减**（BUG-149：重构不是删能力的授权）。

**该注释与实际不符**：`SeriesHero` 是本次重构中被取代的旧形态，其「剧集介绍展示 + 编辑入口」
**并未迁入** `SeriesDetail` —— 迁移时漏搬了这一项，注释却宣称「全部能力零删减」。

> 迁移清单里也确实**没有列「剧集介绍」**（列了编辑/挂图/多源/上移下移/移除/播放/前往条目/
> 重缓存/灯箱/标签/合并/删除/导出，唯独漏了它）—— 这解释了漏搬的机制：
> **清单本身就是漏的，所以按清单核对永远核不出来**。

## 复现

**已完成：静态证据链（决定性 · 但为静态证据，未做运行时观测）**

> **如实标注**：本节的证据是**代码事实**（可直接复核的真实观测），但**尚未做运行时观测** ——
> 未启动应用、未截图、未在真实界面确认「剧集介绍确实不显示」。
> 静态证据已足以定位根因（活组件不读该字段 + 唯一承载组件零 importer 是不可达的），
> 但**修复动工前应补一次运行时观测**（打开一个带剧集介绍的剧集 → 截图确认无介绍区），
> 并追加到本节。本档不把静态证据冒充运行时证据。

复核命令（三条，任一台机器可复现）：

```sh
# ① 活实现不读剧集介绍字段
grep -n "detail\.description\|series\.description\|seriesDescription" \
  tauri-shell/src/components/media/SeriesDetail.tsx      # → 零命中

# ② 唯一承载组件不可达
grep -rn "from '.*SeriesHero'" tauri-shell/src            # → 零 importer

# ③ 展示位全仓唯一
grep -rn "series-description" tauri-shell/src             # → 仅 SeriesHero.tsx:208
```

## 修复

`tauri-shell/src/components/media/SeriesDetail.tsx`（活的剧集内页）：

1. 在左栏剧集总览区（`series-cover` / 标题 / 标签一带）补回**剧集介绍展示位**，
   数据源为 `detail.description`（`MediaSeriesDetail` 上既有字段）；
2. 迁回**展开/收起**（超行时显示 `series-desc-toggle`）与**编辑入口**
   （点击进 `SeriesEditPanel`，`series-desc-edit`）；
3. **空态**保留可编辑空位（不出现首集介绍文本）—— 与 `SeriesHero.tsx:236-244` 的既有行为一致；
4. 完成后**删除或改写** `SeriesDetail.tsx:88-91` 的自称「能力零删减」注释 ——
   注释与事实不符正是本缺陷的成因，留着会让下一次核对继续假绿。

**不得**简单把 `SeriesHero` 整个挂回（它是被新形态取代的旧实现，挂回会带回旧布局与重复入口）；
本修复是**把漏搬的那一项能力迁进活实现**。

## 修复后验收要点（预声明 · 待 fixed 时转为 验收证据 并立真实证据）

1. **能力断言（打真实渲染，不打组件是否存在）**：打开一个 `description` 非空的剧集内页 →
   页面上出现剧集介绍文本（等于 `media_series.description`）；
   介绍超行时出现展开/收起；点编辑入口能进 `SeriesEditPanel`。
2. **空态断言**：打开一个 `description` 为空的剧集 → 出现可编辑空位，
   **且不出现首集（`cur.description`）的介绍文本**（防「分集介绍冒充剧集介绍」）。
3. **反向证伪**：把展示位从 `SeriesDetail.tsx` 撤掉 → 上述断言 **必须 FAIL**。
   否则断言是假绿（这是本缺陷最容易被漏过的点：`SeriesHero.tsx` 里 testid 一直都在，
   按 testid 检索全仓会误判为「已实现」）。
4. **注释一致性**：`SeriesDetail.tsx` 头注释不再声称「能力零删减」除非逐项核对为真。
5. 入库验收脚本（跨机器可复核）：待修复时新增 `tauri-shell/verify/verify_series_description_slot.cjs`。

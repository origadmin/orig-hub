# BUG-120：「编辑」与「改名」割裂 —— 实现视角的拆分，改标题要找两个地方

- 状态: open
- 严重程度: low
- 模块: shell
- 发现日期: 2026-09-22

## 现象

改一条内容的信息时，用户要在「编辑」和「改名」两个入口之间选，且两者行为不一致
（写的地方不同、校验不同）。

## 根因

这是**实现视角**的拆分（改元数据面板 vs 改标题字段），不是**用户视角** ——
用户心里只有一件事：**「我要改这条内容的信息」**。

## 修复方向

- 合并为**单一「编辑」面板**，标题是其中一个字段；
- 保留「双击标题 / 右键重命名」作为**快捷方式**，但两个入口必须：
  - 写同一份数据；
  - 走同一套校验（否则会重演 BUG-087 的教训：同一语义两份实现，改需求时齐刷刷错成一样）。

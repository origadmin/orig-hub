# BUG-038：监控频道内容在面板内永不更新

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: shell
- 严重程度: high

## 现象
用户报告「监控频道不更新内容」。停留/进入监控频道时看不到新发布内容。

## 根因
两层叠加：
1. `TgPanel` 消息流走 `GET /api/tg/monitor/messages`，该端点**本地满页即不回网**
   （本地库有历史行时永远满页）——新内容只能靠后台 30s 同步循环入队；
2. 面板对同步结果**零消费**：不同步、不轮询、不提示，唯一看到新内容的途径是
   重新选择频道（重触发本地查询）。后端循环同步本身工作正常
   （实测两监控频道游标 5635/11667 与频道网络侧最新一致，channels quiet 时 added=0 属正常），
   但 UI 无任何「有新内容」反馈路径。

## 修复
`TgPanel.tsx`：
- 进入监控频道立即触发一轮 `POST /api/tg/monitor/sync`（全局增量）；
- 面板停留期间每 60s 一轮；
- 同步到新条目**不粗暴重载**（会拽走滚动位置），累计进「有 N 条新内容 · 点击刷新」
  提示条（消息列底部浮动），点击才重载并清零。

## 验收
- e2e：手动 `POST sync` 返回 added=0（频道安静，游标一致）；
- 面板内 60s 轮询生效由 Playwright 观察 pendingNew 状态路径。

# BUG-478: 详情页动作区信息架构整体错误——多轮重排均在排列错误归属的按钮

- 状态: fixed
- 发现日期: 2026-10-28
- 模块: shell
- 严重程度: high
- 排期: 2026-10-28

> 来源：用户 2026-10-28 逐条裁决：「文件管理页面的大量按钮全部都是错误设计错误实现，
> 完全违反设计美学，违反简洁设计规则」——导出预览/完备性校验混乱且作用不明、
> 合并/拆分应为一个功能集、本剧标签弹出标签堆毫无逻辑、播放全部位置不对、
> 编辑和删除放这里突兀、右栏「编辑本集」一个按钮占一行。

## 现象

1. 左栏剧集动作区：播放全部、编辑、标签、合并到、拆分、导出预览、删除七颗按钮
   经三轮重排（扁平栈 → 三层 → 2 列网格）仍被用户整体否定——**重排没有解决归属**：
   内容消费（播放）与管理动作同堆同体量；删除以全宽大红条占据最大视觉权重；
   合并/拆分被拆成两个无关联观感的格。
2. 右栏：`编辑本集` 全宽独占一行（上一轮为「主操作突出」而做），用户判
   「一个按钮占了一行，能不能有点逻辑性」。
3. 内容级（按钮层修不掉）：「导出预览」弹出的完备性校验对话框作用不明、范围不明，
   用户无法理解导出内容与范围；「本剧标签」弹出的标签选择器一堆标签毫无组织逻辑。

## 根因

1. **方法错误**：连续四轮修改都在「重新排列」既有按钮，从未重新裁决每颗按钮的
   **归属与形态**——排列组合不产生信息架构。
2. **体量无差别**：主操作（播放）与管理小动作使用接近的按钮体量，堆内无主次。
3. **形态错配**：删除（低频破坏动作）用全宽实心大红条 = 动作区视觉最重元素，
   既突兀又诱导误点；编辑本集（右栏）用全宽 = 单按钮撑一行无信息量。

## 修复方向（已实施：按钮层 IA 重构）

左栏 `series-actions`（leaf testid 全保留）：
- `播放全部`：内容消费主操作，紧贴封面全宽 `primary` —— 体量与下面的管理带拉开。
- 管理工具带：单行 `flex-wrap` 紧凑小钮，语义顺序 = 编辑 → 标签 → 结构
  （**合并 / 拆分相邻 = 同一功能集**）→ 导出；删除为行内危险形态
  （`Trash2` 图标 + 危险色文字，自然折行末位），不再全宽大红条。
右栏 `episode-action-secondary`：
- `查看大图`(照片集) / `编辑本集` / `查看内容` / `上移` / `下移`（/ 条件 `重新缓存`）
  全部并入**一条工具带**，同一形态，编辑不再独占全宽；「从剧集移除本集」红条独立末位保留。

## 二次裁决（2026-10-28，用户「右上角不是有导出吗？有什么区别？」「当前布局逻辑完全乱七八糟」）

工具带方案仍被否。复核发现两处**重复入口**（一语义多入口，简洁设计的直接违反）：

1. **导出**：卡片级 `series-export` 打开的就是右上角库级导出（ContextBar 标题行注册的
   `export` → 同一个 `ExportPreviewDialog`），唯一差别是预勾当前剧（BUG-410 修法）
   —— 伪差异不构成第二颗按钮。⇒ 拆除卡片级入口与 `MediaLibraryPanel` 的 `onExport`
   接线，导出只留右上角库级唯一入口（一语义一入口）。
2. **标签编辑**：`SeriesEditPanel` 本就含 tags（title/description/year/tags 一次提交，
   R10），卡片级 `series-tag-edit` + 顶部独立标签编辑条是第二/第三入口，且标签条的
   「保存」按钮只做 `setEditingTags(false)` **从未提交过**（坏行为）。⇒ 整体拆除
   （state/块/i18n 无关键），标签编辑唯一入口 = 编辑面板。

动作归属重裁（本轮是裁决归属，不是排列）：
- 播放全部 → **封面右下角覆盖钮**（媒体通识：海报即播放入口），`series-play-all`
  testid 保留；全宽 primary 行删除。
- 编辑 → **标题行行尾 icon-only outline**（编辑对象 = 总览卡内容），`series-edit` 保留。
- 合并 / 拆分（结构调整功能集）+ 删除（破坏）→ **卡片底部安静行**
  （ghost 小字，删除危险色末位 `ml-auto`），与日常动作分离；三个 testid 保留。
- verify 同步：`verify_bug412`（tag-edit→edit）、`verify_bug409_410_414_ia`（410 改断言
  「卡片无导出入口」）、`_probe_episode_actions`（页级探测 + 新 IA 断言）。

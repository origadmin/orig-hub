# BUG-139：「打开已下载」= 系统默认播放器、「预览」= 内置播放器——同一「打开」动词两种行为

- 状态: open
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: low

## 现象

TG 面板里对已缓存内容的「打开」动作弹**系统默认播放器**（离开应用），「预览」动作用**内置播放器**（留在应用内）——同一「打开」语义两种截然不同的行为，用户建立不起稳定预期；且系统播放器路径完全绕过内置播放器的解码健康提示（BUG-034）与倍速/连播能力。

## 根因

`TgPanel.tsx:979-989` `openDownloaded` = `import('@tauri-apps/plugin-opener').openPath(path)`（系统默认应用）；`onBubblePreview`（`:1021-1028`）走 `openViewer`（内置播放器）。两者挂在同一气泡的不同按钮上，无文案/图标层面的语义区分。

## 复现

对已缓存视频分别点「打开」与「预览」：一个跳出应用、一个留在应用内。

## 修复

需产品决策：

- **统一内置播放器**（推荐：行为可控、带解码健康提示、与媒体库一致）；
- 或保留双轨，但按钮文案/图标明确区分（如「用系统播放器打开」）。

# BUG-081: 「清理入口在本面板的『缓存字节』页签」提示在本页签自己也显示

- 状态: fixed
- 发现日期: 2026-09-20
- 模块: shell
- 严重程度: low

## 现象

缓存管理面板顶部常驻一行提示：`清理入口在本面板的「缓存字节」页签`。
用户正身处「缓存字节」页签时这行提示**依然显示**——指路牌指向自己脚下，
属于自指废话（用户原话：「当前就是缓存字节页面，还出现这个提示」）。

## 根因

`tauri-shell/src/components/CacheManagerDialog.tsx:405-417`：

该提示所在的"缓存用量条"渲染在 `view === 'tasks'` 的分支**之前**，属于**两个页签共用**的
头部区块；`{t('tg.cachePurgeHere')}`（414 行）无条件输出，没有按 `view` 做条件渲染。
于是：

- `view === 'bytes'`（正在缓存字节页签）→ 提示"入口在缓存字节页签"（自指）；
- `view === 'tasks'` → 提示才真正有指路作用。

文案本身没错，错在**只在非目标页签才该出现**这一约束没被表达。

## 复现

1. 打开缓存管理面板 → 默认/切到「缓存字节」页签；
2. 看顶部用量条右侧 → 仍显示「清理入口在本面板的「缓存字节」页签」。

## 修复

把提示改为**条件渲染**：仅当 `view !== 'bytes'` 时输出 `tg.cachePurgeHere`
（即只在"任务记录"页签指路）。`view === 'bytes'` 时该位置留空或改显更贴合的信息
（如"清理只影响本目录内的缓存文件"），不再自指。

验收锚点：`data-testid="cache-purge-hint"` 在 bytes 页签下**不出现**，在 tasks 页签下出现。

# BUG-012: 无法拉取应用（TG 频道列表失败）且显示已登录但实际会话失效

- 状态: fixed
- 发现日期: 2026-09-16
- 模块: engine
- 严重程度: high

## 现象

UAT 环境：
1. APP 无法拉取应用（TG 频道/订阅列表拉不出来），并反复弹出错误提示小窗。
2. TG 界面显示已登录（Authorized），但实际后端 `GET /api/tg/session` 返回 Anonymous，频道列表不可用。

## 根因

两个叠加问题：

1. **频道列表拉取失败（无法拉取应用）**：`dialogs()` 在枚举频道前先调用 `folders()`（`GetDialogFilters`）建立分组映射。`folders()` 经代理偶发网络失败（`read error, IO failed: read 0 bytes`）时，整个 dialogs 请求被判失败，频道列表全部拉不出来 → 前端反复 setError → 弹小窗。
   - 位置：`download-engine/crates/orig-tg/src/grammers.rs`

2. **会话失效（显示已登录但实际 Anonymous）**：升级 grammers 0.10 后，会话存储从旧二进制 `Session` 改为 `SqliteSession`（SQLite）。旧的 `tg.session` 是旧二进制格式，`SqliteSession::open` 报 `file is not a database`，`GrammersClient::connect` 失败回退 dummy 客户端，会话显示 Anonymous。grammers 0.10 已移除 BinarySession，旧会话无法迁移，需重新登录。
   - 位置：`download-engine/crates/orig-tg/src/grammers.rs`（connect）

## 复现

- 拉取频道：在代理抖动时调用 `GET /api/tg/dialogs`，整体失败。
- 会话：用升级前二进制登录产生旧格式 `tg.session`，升级后用新版读取，`api_mode` 回退 dummy、`phase` 为 Anonymous。

## 修复

1. `grammers.rs` `dialogs()`：`folders()` 失败降级为「未分组」（`if let Ok(folders)`），频道枚举照常返回，不再整体失败。（已 commit `28f9b77`）
2. 会话：清理旧格式 `tg.session` 后 `api_mode` 恢复 real；重新登录写入新的 SQLite 会话后可正常拉取。旧会话无法自动迁移（grammers 0.10 无 BinarySession）。

## 验收

- 重新登录后 `GET /api/tg/dialogs` 能返回频道列表（即使 folders 请求失败也只影响分组标注，不影响列表）。
- `GET /api/tg/session` 返回 Authorized。

# BUG-086: UI 验收通道自身不可执行 —— verify 脚本 require('playwright') 而依赖未声明，且无零依赖替代

- 状态: fixed
- 发现日期: 2026-09-21
- 模块: shell
- 严重程度: high

## 现象

用户报告「容器验证失败，调试阶段失败 = 没有修复任何问题」。实际排查结论与「前端坏了」相反：

- **页面本机渲染完全正常**。Edge headless 取渲染后 DOM（约 90 KB）：12 个关键
  `data-testid` 全部命中，`vite-error-overlay` / `Failed to resolve` / `Uncaught` 出现次数均为 0，
  可见文本含「全部文件 / 下载中 / 已完成 / daemon 运行中」等预期内容。
- **坏的是验收通道本身**：`tauri-shell/verify/` 下 6 个 `shot_*.cjs` 全部
  `require('playwright')`，而 `tauri-shell/package.json` 的 devDependencies **没有 playwright**，
  `node_modules/playwright` 与 `node_modules/playwright-core` **均不存在**。
  任何人在任何机器上跑这些脚本，第一件事就是 `MODULE_NOT_FOUND` 崩溃 —— 这就是「验证失败」。

即：**验收结论「失败」是验收脚本自身崩溃产生的假象，并不反映被测页面的状态。**

## 根因

三层，各自独立成立：

1. **主因（依赖未声明）**：`shot_clear_center.cjs:33`、`shot_context_bar.cjs:15`、
   `shot_item_cache.cjs:19`、`shot_media_delete.cjs:26`、`shot_media_tags.cjs:26`、
   `shot_series_text_edit.cjs:28` 六处均为 `const { chromium } = require('playwright')`，
   而 playwright 从未写入 `package.json`。脚本依赖了一个**仓库不提供**的包。
   反过来也不能直接补进 devDependencies：playwright 需下载浏览器二进制，
   在离线 / 代理 502 的机器上会让 `npm install` 失败 —— 那属于**引入新故障**。
2. **次生（依赖安装不完整，致白屏）**：`node_modules` 安装残缺（`npm ls` 大量 `extraneous`、
   `@babel/core` 缺失），而 `@vitejs/plugin-react@4.7.0` 依赖 `@babel/core`，
   页面因此报 `Failed to resolve import "@babel/core"` 并白屏。
   关键点：**此时 dev server 仍返回 HTTP 200** —— 这正是 `docs/ACCEPTANCE.md`
   禁止「仅以 curl 5180 200 作为验收结论」的原因，也解释了为何此前出现过「200 就算通过」的误判。
3. **环境约束**：本环境无法稳定下载 playwright 浏览器（代理 502 / 直连超时），
   故修复**不能依赖下载任何东西**。

## 复现

1. `cd tauri-shell`（未装 playwright）；
2. `node verify/shot_context_bar.cjs` → 立即 `Cannot find module 'playwright'`，退出码 1（崩溃）；
3. 而同一时刻 `http://127.0.0.1:5180/` 在真实浏览器里渲染正常。

## 修复

**不删除、不改写任何现有脚本的业务逻辑**（历史资产，删改即破坏），只做最小增量：

1. **优雅降级**：6 个脚本各自的 `require('playwright')` 用 try/catch 包住。
   缺失 playwright 时打印中文说明（为什么不能跑、怎么装、零依赖替代是什么）并 **exit 2**，
   不再抛裸的 `MODULE_NOT_FOUND`。
2. **新增零依赖 CDP 驱动** `tauri-shell/verify/lib/cdp.cjs`：仅用 Node 内置 `WebSocket`
   （Node ≥ 22）与标准库，自动探测本机 Edge/Chrome（可用 `EDGE_PATH` / `CHROME_PATH` 覆盖），
   随机探测空闲调试端口（不硬编码 9333），轮询 `/json/version` 至就绪（超时明确报错、不静默挂起），
   暴露 `launch()` / `newPage()` / `goto()` / `content()` / `evaluate()` / `screenshot()` /
   `consoleErrors()` / `pageErrors()` / `close()`（必杀进程树，不留孤儿）。
3. **新增真实渲染验收** `tauri-shell/verify/verify_ui_render.cjs`：走上述驱动，断言 JS 执行后的 DOM，
   **绝不用 curl 200 冒充验收**；支持 `APP_URL` 覆盖；失败逐项打印 PASS/FAIL 清单并 exit 非 0；
   产物落系统临时目录，且**拒绝**写入仓库（AGENTS.md §6）。
4. `package.json` 增加 `"verify:ui": "node verify/verify_ui_render.cjs"`，
   **不**把 playwright 写进依赖。
5. `tauri-shell/verify/README.md` 固化前置步骤（`npm install` → 起 daemon → `npm run dev` → 验收）
   与排障表，避免「依赖没装」被重复当成「页面坏了」。

## 验收证据

- 真实渲染验收：`tauri-shell/verify/verify_ui_render.cjs` —— 对 `http://127.0.0.1:5180/`
  实测 **20/20 断言全 PASS，exit 0**（`#root` 有子节点、`body.innerText` 非空、
  无 `vite-error-overlay` / `Failed to resolve` / `Uncaught`、无未捕获异常、无 console error、
  12 个 `data-testid` 全命中）。
- 零依赖驱动：`tauri-shell/verify/lib/cdp.cjs` —— 仅 Node 内置 `WebSocket` + 标准库，
  实测无 `node_modules/playwright*` 亦可驱动本机 Edge 完成导航与取 DOM。
- 优雅降级：6 个 `shot_*.cjs` 在无 playwright 环境下**逐个实测 exit 2 + 中文提示**，
  不再 `MODULE_NOT_FOUND` 崩溃。
- `npm run dev` 可用性：vite 7.3.6 正常启动并转译（`/src/main.tsx` 返回 200），
  证明 `@babel/core` 已补齐、转译链路修复。
- 步骤与排障固化在 `tauri-shell/verify/README.md`。
- 门禁：`scripts/check-bugs.py` 与 `scripts/check-pollution.sh` 均 EXIT 0。

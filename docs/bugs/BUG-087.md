# BUG-087: 连接态指示三处各写各的 —— 上下文栏读 store，底部状态栏/侧栏底部硬编码「已连接/运行中」+恒绿点

- 状态: fixed
- 发现日期: 2026-09-21
- 模块: shell
- 严重程度: mid

## 现象

UI 交互体检（零依赖 CDP 驱动真浏览器）抓到：点 `nav-settings` 后**同屏**三处连接指示互相矛盾 ——

- 上下文栏 `[data-testid=context-conn]`：`data-conn-state="offline"`，文案「daemon 未连接」；
- 底部状态栏：文案「daemon 已连接」+ 恒绿点；
- 侧栏底部：文案「daemon 运行中」+ 恒绿点。

10 秒内采样 3 次始终如此。用户看到的是「一个说没连上、两个说连上了」，不知道该信谁。

## 根因

连接态**没有唯一来源**，三处各自实现：

- `tauri-shell/src/components/ContextBarStatus.tsx`（修前 41-47 行）：唯一的正确实现，
  由 `store.connected`（SSE 链路）+ `store.daemon.alive` 判定三态 `live`/`degraded`/`offline`；
- `tauri-shell/src/components/MainLayout.tsx:283-284`（修前）：硬编码 `{t('main.daemonConnected')}`
  + `bg-success` 恒绿点，**不读任何状态**；
- `tauri-shell/src/components/Sidebar.tsx:349-354`（修前）：硬编码 `{t('status.daemonRunning')}`
  + `bg-success` 恒绿点，同样不读状态。

即：判定逻辑只存在于上下文栏组件内部（局部函数），另两处无从复用，于是复制粘贴退化成写死常量。

## 复现

1. `npm run dev` 起 5180，浏览器打开 `http://127.0.0.1:5180/`；
2. 点 `nav-settings`；
3. 同时读 `[data-testid=context-conn]`、`[data-testid=statusbar-conn]`、`[data-testid=sidebar-conn]`
   的 `data-conn-state` 与 `innerText` —— 修前三处不一致（offline / 已连接 / 运行中）。

## 修复

1. **抽唯一规范来源** `tauri-shell/src/store/connState.ts`：导出 `ConnState` 三态类型、
   `resolveConnState(connected, daemonAlive)` 纯函数、`CONN_DOT`（配色）、`CONN_LABEL`（i18n key）、
   `useConnState()`（订阅 store 的 `selectConnected` / `selectDaemonAlive`）。
   三态文案复用上下文栏既有措辞：`ctx.connected` / `ctx.degraded` / `ctx.disconnected`，
   **不新造第二套说法**。
2. `ContextBarStatus.tsx`：删掉本地的 `resolveConnState` / `CONN_DOT` / `CONN_LABEL` 副本，改为
   从 `store/connState.ts` 引入 —— 规范来源只剩一处。
3. `MainLayout.tsx` 底部状态栏与 `Sidebar.tsx` 侧栏底部：改读 `useConnState()`，文案取 `CONN_LABEL`、
   圆点色取 `CONN_DOT`，并各自带 `data-testid`（`statusbar-conn` / `sidebar-conn`）与
   `data-conn-state`，便于门禁复测。

## 验收证据

真实浏览器（零依赖 CDP 驱动，Chromium 内核）实测，`nav-settings` 视图下同屏三处：

| 注入状态 | context-conn | statusbar-conn | sidebar-conn |
|---|---|---|---|
| `daemon=null` | offline /「daemon 未连接」 | offline /「daemon 未连接」/ `bg-muted` | offline /「daemon 未连接」/ `bg-muted` |
| `daemon.alive=true, connected=false` | degraded /「降级轮询中」 | degraded /「降级轮询中」/ `bg-warning` | degraded /「降级轮询中」/ `bg-warning` |
| `daemon.alive=true, connected=true` | live /「实时已连接」 | live /「实时已连接」/ `bg-success` | live /「实时已连接」/ `bg-success` |

三态逐一注入（`import('/src/store/useStore.ts').useStore.setState(...)`）后取渲染后 DOM，
**三处 `data-conn-state` 与文案逐行相同**，同屏不再出现自相矛盾；页面 `pageErrors` 为空。

- 规范来源：`tauri-shell/src/store/connState.ts`（入库，跨机器可核）
- 三个消费点：`tauri-shell/src/components/ContextBarStatus.tsx`、
  `tauri-shell/src/components/MainLayout.tsx`、`tauri-shell/src/components/Sidebar.tsx`
- 复测驱动：`tauri-shell/verify/lib/cdp.cjs`（BUG-086 入库的零依赖 CDP 通道，本机实测可用）
- 门禁：`python scripts/check-bugs.py` 与 `sh scripts/check-pollution.sh` 均 EXIT 0；
  `node node_modules/typescript/bin/tsc --noEmit` EXIT 0

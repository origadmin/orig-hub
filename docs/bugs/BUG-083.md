# BUG-083: 顶部下载工具栏仅在下载视图渲染，媒体库/TG 下整组消失（是否常显与占位）

- 状态: open
- 发现日期: 2026-09-20
- 模块: shell
- 严重程度: low

## 现象

用户：「下载新建、暂停、继续按钮在顶部应该常时显示，那么在媒体库、TG 中是否需要显示？
这一栏是否需要占位？」

现状核对（`tauri-shell/src/components/MainLayout.tsx:124-213`）：

```ts
const isDownloadView = view === 'all' || view === 'downloading' || view === 'completed'
...
<header className="flex h-12 shrink-0 items-center justify-end gap-3 border-b ... px-4">
  {isDownloadView && busy && (<span ...>{formatSpeed(totalSpeed)}</span>)}
  {isDownloadView && (<div ...>新建 / 暂停全部 / 继续全部 / (已完成页)清空</div>)}
</header>
```

已确认的两个事实（回答"是否需要占位"）：

1. **`<header>` 本身是常驻的**——`h-12 shrink-0` 始终渲染，条件只包住**按钮组**。
   所以切换视图**不发生高度跳动**，额外"占位"在布局上没有必要。
2. 但在媒体库 / TG / 设置下，这一行是**完全空白**的（只剩边框和底色）；
   且 TG/媒体库各自在内容区内部另有一套头部/工具栏 → 出现"顶部一条空栏 + 内容区又一条"
   的双层观感。

## 根因

1. `isDownloadView` 把"下载语义的操作"与"这一行是否存在"**耦合成一个判断**：
   非下载视图时整组消失，行虽在却空着。
2. 媒体库/TG 的操作（导入、刷新、缓存管理）被放在各自面板内部，没有上行到这条常驻栏，
   于是该栏在非下载视图下**有高度无用途**。
3. 与 BUG-082 同源：`DOWNLOAD_MODULE_HIDDEN` 让下载视图本身也不可达，
   这栏在默认落地视图（媒体库）下**永远空白**。

## 复现

1. 启动应用（默认落地媒体库）→ 顶部操作栏整行空白；
2. 切到 TG → 同样空白，而 TG 面板内部另有一排自己的按钮；
3. 切到"全部文件"（需导航可达）→ 新建/暂停/继续出现。

## 修复

**待拍板**（见「设计裁定」）。已明确的评估结论：

- **布局上不需要额外占位**：`<header>` 常驻且定高（`h-12 shrink-0`），
  不存在跳动问题，为占位而占位只会多一个空 div。
- **语义上媒体库/TG 不应显示下载按钮**：新建下载/暂停全部/继续全部 操作的是
  orig-daemon 的下载任务队列，与媒体库（内容管理）和 TG（抓取/缓存）不是同一对象，
  强行常显会出现"按钮在但点了没对象"的空操作。
- **真正要处理的是"空白行"**：把各视图自己的主操作上行到这条常驻栏
  （媒体库=导入/刷新，TG=刷新/缓存管理），或在该栏非下载视图时承载视图专属动作，
  使这一栏在**任何视图下都有用途**，而不是留一条装饰性空栏。

## 设计裁定（产品经理评估，2026-09-20）

**判断：媒体库 / TG / 设置下不显示「新建下载 / 暂停全部 / 继续全部」。**

理由：这三个按钮的作用对象是 `downloads`（daemon 队列）；媒体库条目是**已入库媒体**、
TG 是**缓存任务**，都不是其对象。强行常显会被误读成"能暂停 TG 缓存"，点了没有可见反馈。

用户说的"常显"，本质是**"全局任务控制不因切视图而消失"**——这个诉求应该作用于
**TG 缓存任务池**，而不是 daemon 下载队列。

`h-12` 定高常驻、切视图不跳动，**无需额外占位**。建议把这条栏改成"上下文栏"，二选一：

| 方案 | 做法 | 取舍 |
|---|---|---|
| **推荐（低成本）** | 媒体库/TG/设置下放「视图标题 + 右侧全局态」（daemon 连接 / 聚合速度 / 进行中数） | 改动小，但仍是"两条栏" |
| 彻底（中成本） | 把媒体库/TG 内容区自带工具条**上行合并**进这一行，内容区不再有第二条栏，根治双层观感 | 观感最好，但两个面板布局要跟着调 |

## 待拍板②：媒体库/TG 内部工具条「上行到全局栏」还是「留在内容区」？

- **因果**：顶部空栏 + 内容区工具条并存，形成双层观感；根因是全局栏当初**按 download 视图
  设计**，其他视图没内容可填。
- **选项**：(a) 全局栏放"标题 + 全局态"，内容区工具条不动；(b) 工具条上行合并，内容区不再有第二条栏。
- **建议**：先 (a)，(b) 列为后续 UI 收敛项。

# BUG-393: 选择态形态不统一——下载域选择条与剧集墙两套样式，且缺「全选/全不选」

- 状态: fixed
- 模块: shell
- 发现日期: 2026-10-23
- 严重程度: mid
- 报告: 用户 2026-10-23 04:25「全部下载 的选择又出现了样式不一致情况. 应该和剧集一样. 样式就应该统一,应该有一个标准」。

## 现象

选中若干条之后：剧集墙是**底部居中胶囊条**（`items-selection-bar`，`rounded-full` + `bg-surface/95 backdrop-blur` + `text-[11px]` 按钮，含全选/全不选）；下载域是**顶部方块条**（`dl-batch-bar`，`rounded-lg bg-accent/5`、`text-sm` 按钮、只有「清空/取消选中」，**没有全选/全不选**）。两处学到的是两套交互。

行选择框同样不同源：下载行 `h-4 w-4`，剧集拆分行 `h-3.5 w-3.5`。

## 根因

「选中之后的条」与「行选择框」在**每个域各写一份**，没有共享组件 ⇒ 样式不是「不一致」而是「从未有过单一真源」，改一处必然漏另一处。

## 修法（结构性：让不一致不可表达）

抽出 `components/ui/selection-bar.tsx` 作为**全仓唯一选择形态**：
- `SelectionBar`：底部居中浮层胶囊（`absolute bottom-4 left-1/2 -translate-x-1/2 rounded-full border-accent/40 bg-surface/95 backdrop-blur-md`），count=0 时不渲染；
- `SelectAllButtons`：全选/全不选**成对**，`size="sm" h-7 px-2 text-[11px]`（outline + ghost）；
- `RowCheckbox`：行选择框唯一尺寸 `h-4 w-4 cursor-pointer accent-accent`。

落地：剧集墙（`MediaLibraryPanel`）与下载域（`DownloadPanel`）共用前两者；`DownloadItem` / `IngestGroupRow` / `SeriesDetail` 行选择框改用 `RowCheckbox`。下载域补上此前缺失的全选/全不选（语义 = 全选当前可见行，与剧集「全选本页」同源）。

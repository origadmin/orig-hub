# BUG-171: 剧集详情页同一段简介出现两次 + Hero 海报比例被 flex stretch 顶掉

- 状态: fixed
- 发现日期: 2026-09-25
- 模块: shell
- 严重程度: mid
- 档位: standard

`63d7dc4`（refactor: restore row-based episode list）把分集区改回左右行式、把剧集简介
搬回 Hero 常驻、删掉单集聚焦块。CDP 探针复检这一版，发现两处缺陷。

## 现象

1. **同一段简介在页面上出现两次。** Hero 里常驻整段剧集简介，分集行里又整段渲染一次
   本集介绍——两处文案逐字相同。实测某剧集：单集，本集介绍与剧集简介逐字全等。
   **这正是本次改版要消除的东西**（上一版「本集/全剧」合并区就是因为
   重复被判定「不如之前的左右设计」），改回来之后又从行里冒出来了。
2. **Hero 海报不是 16:9。** 浏览器实测：720px 视口下 320×634，820px 下 320×535，
   只有 ≥900px 才是正确的 320×180。窗口越窄海报越高，被拉成长条。

## 根因

### 1. 本集介绍与剧集简介同源，未做去重

TG 入库时整段 caption 既写进 `media_series.description`，也逐条写进
`media_episode.description`。单集剧集因此必然两者全等。行式渲染里
`ep.description ? <p>{ep.description}</p> : null` 只判了非空——**没有一处判「与剧集
简介是否相同」**，而 Hero 那份是全量常驻的，于是同一段话渲染两遍。

### 2. `align-items: stretch` 压过 `aspect-video`

海报容器 `hidden aspect-video w-80 shrink-0 ... min-[720px]:block` 是 flex 行
（`flex min-w-0 gap-4`）的子项。flex 默认 `align-items: stretch`，子项高度被拉到
与右列等高，`aspect-video` 声明的 `aspect-ratio` 在有确定高度时不生效。右列
（标题 + 元信息 + 标签 + 整段简介）越高，海报越高——所以窄窗口下最离谱。

## 修法

- **去重（`tauri-shell/src/components/media/SeriesDetail.tsx`，分集 map 回调内）**：

  ```ts
  const seriesDesc = (detail.description ?? '').trim()
  const epDesc = (ep.description ?? '').trim()
  const showEpDesc = epDesc.length > 0 && epDesc !== seriesDesc
  ```

  行内简介块改由 `showEpDesc` 门控。**只判逐字全等**：真有独立于剧集简介的本集介绍时
  照常显示，不误杀。
  ⚠️ **编辑能力不能因此丢失**：打开编辑面板的 `episode-edit` 铅笔与 `episode-slot`
  集号按钮**不受 `showEpDesc` 影响**，始终渲染——description 字段仍可读写。
- **海报比例**：海报容器加 `self-start`（`align-self: flex-start`），脱离 stretch，
  高度回到内容自身，`aspect-video` 在任意宽度下成立。一个类，无其它改动。

## 验收证据

验收脚本：`tauri-shell/verify/verify_bug171_status.cjs`，**14 断言全绿**（headless Edge + CDP，
真实渲染；按 `getBoundingClientRect()` / `innerText` 实测，不读 className）。

夹具：某剧集（单集；某一集的本集介绍与剧集简介规范化后逐字全等）。

- **断言 1（简介唯一性）**：整页可见文本中该剧集简介出现**恰 1 次**（`innerText`=1 /
  `textContent`=1）。左栏 `series-description` 展示位在场，右栏 `episode-focus-desc`
  **不存在**（`shouldRenderEpisodeDescription` 去重命中）⇒ 不再重复。
- **断言 2（海报比例）**：`[data-testid="series-cover"]` 的 `getBoundingClientRect()`
  宽高比三视口均 **1.7778**（16:9）—— 720px→252×141.75、820px→352×198、
  1280px→314×176.63。旧的 320×634 / 320×535 长条**不复现**。
- **断言 3（编辑能力）**：`episode-edit` 在场，点击后 `episode-title-input` 出现
  （description 字段仍可读写）。
- **反向证伪**：去掉 `tauri-shell/src/lib/episodePresentation.ts:50` 的
  `&& epDesc !== (series.description ?? '').trim()` → 简介出现 **2 次**（判据 1 FAIL）
  ⇒ 去重是**活的有效门控、非空转**；已还原，sha256 相等，该文件不在
  `git diff --name-only`。
- 无 `pageerror`（仅 favicon 404 控制台错误）。

**结论**：BUG-171 的两处根因（简介重复 / Hero 海报被 flex stretch 拉长）在当前
「左右主从」形态下**均不可复现** —— 去重已由 `shouldRenderEpisodeDescription` 承担，
`SeriesHero` 已成零 importer 孤儿；本档因**登记时未复跑探针**而长期滞留 `in_progress`，
现据实转 `fixed`。

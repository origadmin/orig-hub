# BUG-197 剧集内页默认进入编辑态：打开剧集就直接看见编辑表单，主次颠倒

- **状态**: fixed
- **发现日期**: 2026-09-30
- **模块**: shell
- **严重程度**: high

关联用户长期抱怨（剧集内页体验问题之一）。本档是**实现层修复**——根因是状态机缺一格：
`SeriesDetail` 对**剧集级**编辑有 `editingSeries`（默认 false），对**标签级**编辑有
`editingTags`（默认 false），唯独**单集级编辑**没有对称的开关，导致 `<EpisodeEditPanel>`
被无条件挂上去，「编辑本集」「编辑介绍」按钮都只是 `scrollIntoView`——表单永远在视野里。

产品语义（落地文档 §「剧集内页」一节）：剧集内页是**浏览/播放主战场**，编辑是显式二次动作。

## 现象

打开任一剧集（或在剧集墙点开一条剧集的右栏），右栏**默认就显示**「编辑本集」表单——
标题 textarea、季号 / 集号 / 结束集 inputs、介绍 textarea、保存 / 取消按钮，
以及上移 / 下移 / 移出资料库全部默认渲染。

用户原话：「这里是播放的浏览的地方，谁 TM 默认编辑，天天编辑啊」。

## 根因

`tauri-shell/src/components/media/SeriesDetail.tsx` 修复前的相关行：

- 状态（`:121-129`）：定义了 `focusedEpisodeId` / `editingSeries` / `editingTags` 等，
  但**没有 `editingEpisode`**——单集编辑面板缺一个对称的开关。
- 渲染（修复前 `:628-635`）：`<EpisodeEditPanel>` **无条件渲染**——
  没有 `{editing ? <Panel/> : null}` 的门控。
- 按钮（修复前 `:617-626` 「编辑本集」、`:545-554` 「编辑介绍」）只
  `editBlockRef.current?.scrollIntoView(...)`——因为面板始终在场，scroll 实际只滚到自己脚下。

`EpisodeEditPanel.tsx` 自身不持有「是否显示」状态——它是受父组件驱动的纯表单组件，无辜的受害者。

## 修复

最小对称修复（沿用 `editingSeries`/`editingTags` 同款门控，不引入新概念）：

1. 加 `const [editingEpisode, setEditingEpisode] = useState(false)`（`SeriesDetail.tsx:123`）。
2. `<EpisodeEditPanel>` 包入 `{editingEpisode ? ... : null}` 门控（`SeriesDetail.tsx:649-657`）。
3. 「编辑本集」按钮 `onClick` 改为 `editingEpisode ? closeEdit : openEdit`（`:649`）——已开则关、未开则开。
4. 「编辑介绍」按钮 `onClick` 改为 `openEdit`（`:577`）——开 + 滚到面板。
5. `openEdit` / `closeEdit` / `handleEditSaved` 三个处理器集中定义（`:252-272`）：
   - `openEdit`：幂等打开，新打开时 `setTimeout(() => scrollIntoView(...), 0)`——等 React 把面板挂上去再滚，否则 ref 还指着空节点。
   - `closeEdit`：`setEditNonce(v => v + 1)` 让下次打开草稿从头 + 关闭。
   - `handleEditSaved`：`onChanged()`（重取详情） + `setEditingEpisode(false)`（保存即退出编辑态回到浏览态）。
6. `detail.id` 切换时的 reset effect（`:152-163`）补 `setEditingEpisode(false)`——与 `editingSeries`/`editingTags` 同等处理，避免上一部剧的面板状态「挂着」到新剧。

按钮 label / icon 不动——「编辑本集」仍叫「编辑本集」（点开后才看到表单和自带的保存 / 取消按钮）；
不引入新 i18n 文案，避免扩散到 locale 文件。

## 关联

- 落地文档：剧集内页是浏览/播放主战场，编辑是显式二次动作（语义层裁定）。
- `editingSeries` / `editingTags`（同文件 `:122`/`:135`）同款默认 false 模式——本档补齐最后一块对称。

# BUG-072: 网页调试模式下「浏览…」选择目录报错（Cannot read properties of undefined (reading 'invoke')）

- 状态: fixed
- 发现日期: 2026-09-20
- 模块: shell
- 严重程度: mid

## 现象

设置页 → 默认下载目录 → 点「浏览…」，在**网页调试模式**（前端由 `vite dev` 跑在普通浏览器里、不在 Tauri WebView2 内）下，弹出提示：

> 选择目录失败：Cannot read properties of undefined (reading 'invoke')

无法选择目录，按钮像「点了没反应」。

用户原话：「连1，网页调试模式下点击浏览显示:选择目录失败：Cannot read properties of undefined (reading 'invoke')」。

## 根因

`tauri-shell/src/components/DirectoryPicker.tsx`：

- 第 2 行 `import { open } from '@tauri-apps/plugin-dialog'`；`pick()`（DirectoryPicker.tsx:51-64）直接 `await open({ directory: true, multiple: false })`。
- `@tauri-apps/plugin-dialog` 内部走 Tauri 的 `invoke` IPC 桥（`@tauri-apps/api/core`）。在**纯浏览器**里没有 Tauri 运行时，`invoke` 是 `undefined`，于是 `undefined.invoke` 抛 `TypeError`，被 `catch` 包装成「选择目录失败：…」。
- 本仓库已有 Tauri 环境探测范式：`'__TAURI_INTERNALS__' in window`（`MediaLibraryPanel.tsx:60`、`TgPanel.tsx:282`、`DownloadItem.tsx:15` 的 `isTauri()`），但 `DirectoryPicker` 没有用它做守卫。

## 复现

1. `cd tauri-shell && npm run dev`，浏览器打开（非 `tauri dev`）；
2. 设置页 → 默认下载目录 → 点「浏览…」；
3. 出现「选择目录失败：Cannot read properties of undefined (reading 'invoke')」。

## 修复

- 新增共享 `tauri-shell/src/lib/env.ts`：`isTauri()` 探测 `'__TAURI_INTERNALS__' in window`，
  统一「是否在 Tauri 运行时内」判断（消除三处重复定义：`DownloadItem` / `MediaLibraryPanel` /
  `TgPanel` 各有一份，本 bug 不强制回收它们，后续可另立清理）。
- `DirectoryPicker.tsx`：
  - `pick()` 开头 `if (!isTauri())`：**软失败 + 提示**，而不是让 `undefined.invoke` 抛错把设置页炸成
    错误现场；手动输入路径与历史下拉在网页模式下仍可用，不影响调试。
  - 「浏览…」按钮在网页模式下 `disabled` + `title` 提示「网页调试模式不支持系统原生目录对话框」，
    不再长得像可点却点了报错。

目的：网页调试态本就不该有原生对话框——把它从「点击即抛错」变成「静默禁用 + 提示」，错误环境即消失。

## 验收证据

| 层 | 证据（入库，可跨机器复跑） | 结果 |
|---|---|---|
| 改动文件 | `tauri-shell/src/lib/env.ts`（新增共享 `isTauri`）、`tauri-shell/src/components/DirectoryPicker.tsx`（`pick` 与「浏览…」按钮均 `isTauri()` 守卫） | 入库可核 |
| 类型检查 | `npx tsc --noEmit`（`tauri-shell/`） | 干净 |
| 静态守卫 | `DirectoryPicker.pick` 与按钮均 `isTauri()` 守卫；非 Tauri 时 `open()` 不再被调用 | 已核对（grep 确认 `open` 仅在 `isTauri()` 后方可达） |

`pick()` 在网页模式下的行为变更：原 `await open(...)` → `undefined.invoke` 抛 `TypeError` 被包成
「选择目录失败：Cannot read properties of undefined (reading 'invoke')」；现 `if (!isTauri()) return` + 提示，
不再抛错。手动 `Input` 与历史下拉不依赖 `open()`，照常工作。

# BUG-118：封面与内容同级 —— `poster` 与 `file_path` 并列，生命周期无法定义

- 状态: open
- 严重程度: mid
- 模块: engine
- 发现日期: 2026-09-22

## 现象

封面的更新 / 失效 / 误删策略**无法定义**：删掉一个条目的字节时，封面该跟着走还是留下？
换封面会不会动到内容？这些在数据模型上都答不出来。

## 根因

`poster` 字段**同时**存在于 `media_series` 与 `media_item` 两张表，且与 `file_path`
**同级并列**：

```sql
media_item(id, source, ref, title, kind, file_path, poster, size, duration, ...)
media_series(id, title, description, kind, poster, year, source_key, ...)
```

「展示物」（封面）和「内容物」（字节）在结构上**没有区别** —— 它们是同一行的两个字段。

## 后果

- 清理逻辑无法区分「删内容」与「删封面」；
- 封面失效（TG 链接过期 / 文件被移走）没有独立的修复路径；
- 与 BUG-117 叠加：内容域还要为封面去现场代理 TG 缩略图。

## 修复方向

按评审文档第 5、6 节：把封面外置为**附件**：

```sql
media_attachment(id, owner_type: series|episode|asset, owner_id,
                 role: poster|gallery|thumb, source: local|tg,
                 tg_chat, tg_msg, file_path NULL, sort_order)
```

封面只存在于 `attachment`，不再与 `file_path` 同级。迁移期旧 `poster` 字段保留双读，
观察一个版本后下线（迁移期 poster 空窗要能回落旧字段）。

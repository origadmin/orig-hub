# BUG-356: 默认下载目录显示为裸根「/」——解析链不拒退化路径，下载落点变成文件系统根

- 状态: fixed
- 发现日期: 2026-10-21
- 模块: engine
- 严重程度: high

## 现象

用户复报（2026-10-21，第二次强调）：设置页 / 下载域展示的**默认下载目录**路径为 `/`，且「问题依然」。裸根 `/` 意味着下载落点退化成文件系统根，所有下载失败、UI 把 `/` 当生效路径显示。

## 根因

下载根解析链 `effective_download_root` / `manual_download_root` / `default_download_dir` 只拦**禁用盘**（`C:`），**不拦退化路径**：

- `effective_download_root` 旧逻辑：`if orig_core::paths::is_forbidden_content_drive(&norm)` 才改道；`norm = "/"` 时 `is_forbidden_content_drive("/")` 因无盘符返回 `false` ⇒ 放行，下载根直接变成 `/`；
- `manual_download_root` 旧逻辑：直接返回 `default_download_dir()`，未校验其是否为合法内容根；
- `default_download_dir()` 末级回退旧为 `PathBuf::from(".")`（当前目录），同样不是合法内容根。

即：一旦 toml / env（`SURGE_DOWNLOAD_DIR`）/ 内存里落了 `/` 或盘符根 `D:/`，解析链全部放行，裸根直达落盘与展示。缺少一个统一的「是否可作内容根」判据。

## 修复

**裁定**：引入单一判据 `is_valid_content_root`，拒绝 `/`、`.`、空、`C:/`、`D:/` 等退化路径，从根上消灭「下载根 = 裸根」；三处解析一律非法即回退 `content_root()`（D 盘内容根 `D:\OrigDown`）。

- **`paths.rs`**：新增 `is_valid_content_root`（拒绝空 / `.` / `/` / 盘符根，并 subsumes `is_forbidden_content_drive`）；`default_download_dir()` 末级回退由 `PathBuf::from(".")` 改为 `content_root()`；新增单测 `is_valid_content_root_rejects_degenerate_paths`；
- **`config.rs`**：`effective_download_root` 判据 `if !orig_core::paths::is_valid_content_root(&norm)` → 回退 `content_root()` 并打 warn；`manual_download_root` 改为 `if is_valid_content_root(&d) { d } else { content_root() }`；新增单测 `bare_root_download_dir_is_redirected_to_content_root_bug355`（覆盖 `/`、`D:/`、有效路径三态）。

## 验收证据

- **Rust 单测**：
  - `download-engine/crates/orig-core/src/paths.rs` 单测 `is_valid_content_root_rejects_degenerate_paths` **PASS**（覆盖 `/`、`.`、`""`、`D:/`、`C:/`、`C:/Users/me/Downloads` 反向变异 + `D:/OrigDown`、`//server/share` 正向）；
  - `download-engine/crates/orig-daemon/src/config.rs` 单测 `bare_root_download_dir_is_redirected_to_content_root_bug355` **PASS**（覆盖 `/` → `content_root()`、`D:/` → `content_root()`、有效路径原样返回三态）；
  - 既有 `forbidden_drive` / `tg_unavailable` / `cache_views` 单测**无回归**。
- 代码真源：`download-engine/crates/orig-core/src/paths.rs`（`is_valid_content_root` +
  `default_download_dir` 末级回退）、`download-engine/crates/orig-daemon/src/config.rs`
  （`effective_download_root` / `manual_download_root` 关卡）。
- `tauri-shell/verify/_probe_bug355_download_scope.cjs` 4/4 PASS 一并覆盖「下载根非法 ⇒ 下载源
  `available=false`、横幅报『普通下载不可用』」这一派生态。

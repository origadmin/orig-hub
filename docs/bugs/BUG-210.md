# BUG-210 剧集内页主任务错位：播放被埋在「操作」区末行、与描边按钮同尺寸；无备用源时「来源」块仍整块渲染

- 状态: fixed
- 发现日期: 2026-09-30
- 模块: shell
- 严重程度: mid

## 现象

用户在媒体库 → 剧集内页（右栏 = 当前单集显示与编辑）反馈：**播放是最高频的主任务，却在页面上找不到、或要滚到底才看见**。实测右栏：标题行在最上、编辑面板紧随其后，而唯一播放入口 `episode-play`（实心按钮）被放在右栏**最后一行的「操作」区**，与「挂图 / 在媒体库中查看 / 重缓存」三个**描边**按钮**同尺寸**（`h-7 px-2.5 text-[11px]`）并排。主任务被降格成四个并列操作之一，视觉权重与出现位置都与其频率不符。

另一处噪声：当某集**没有备用源**（`cur.sources` 为空）时，「来源」块（`sourcesTitle` + 主版本行 + 备用源列表）**仍然整块渲染**，只是内部备用源列表为空——用户在无任何来源选择可做的情况下，仍看到一整块「来源」标题与主版本行，属「无选择却有控件」的空展板噪声。

## 根因

`tauri-shell/src/components/media/SeriesDetail.tsx` 右栏的渲染顺序把播放放在末行：`episode-play` 与其余操作按钮同处「操作」行（改前 `:723-774`），既无位置前置、也无尺寸区分。设计文档 `docs/design/episode-internal-ia-v2-2026-09-29.md`：

- §4.2 定档：「▶ 播放本集 ← **唯一实心主按钮，独占一行，位置随集不变**」。现状违反「独占一行」与「唯一实心主按钮」两条——它与三个描边按钮同行同尺寸。
- §5 S4 定档：「**无备用源 ⇒ 来源区整块不渲染**」（原则「无选择即无控件」）。现状来源块无条件渲染，违反该定档。

## 复现

1. 媒体库 → 打开任意剧集 → 进入剧集内页（右栏单集区）。
2. 右栏顶部是标题行、其下是本集图组与介绍；继续向下滚到右栏**底部**，才看到「操作」区里与描边按钮同尺寸的 `episode-play`。
3. 结论：播放主任务位置被后置、尺寸被拉平，不符合「高频主任务突出」的产品要求。
4. 另：打开一个**无备用源**的集（`sources` 为空）→ 右栏仍出现整块「来源」标题 + 主版本行，无任何可切换对象。

## 修复

改动限于 `tauri-shell/src/components/media/SeriesDetail.tsx`：

1. **播放主区固化**：把 `episode-play` 按钮从「操作」行**移出**，上移到**本集图组 Deck 块之后、本集介绍块之前**，渲染为**独占一行、整行宽**的实心主按钮（`className="h-9 w-full gap-1.5 text-[13px]"`，`Button` 默认 variant 即实心）。位置由结构固定，不随介绍长度 / 挂图数量漂移。`data-testid="episode-play"`、`disabled={!hasMediaBytes(cur)}`、`onClick={() => playEpisode(cur)}`、`title`、`<Play className="h-3 w-3" />`、`{t('media.episode.play')}` **逐字保留**。
2. **来源区降噪**：把「来源」块用 `{(cur.sources ?? []).length > 0 ? (…) : null}` 门控——**无备用源时该块在 DOM 中完全不存在**（非 `hidden`、非 `opacity-0`）。块内 `sourcesTitle` 标题、主版本行、备用源 `<ul>`（含 `episode-source-switch` / `episode-source-detach`）原样保留。「正在从哪播」已由标题行 meta 的 source 徽标（`:557-560`）承载，故门控不丢失该信息。
3. 「操作」行仅移除 `episode-play`，其余（`episode-attach-images`（`!editingEpisode` 门控）/ `episode-goto-item` / `episode-recache`（`!hasMediaBytes` 门控））与区块标题 `media.episode.actions` 保留原位不动。

**能力不减**（BUG-149：重构不是删能力的授权）：播放、切主、摘除备用源、挂图、前往条目、重缓存等入口全部在场；被验收脚本断言的 `data-testid` 全部沿用，无删除。

- 前端 TypeScript 编译门禁 `node node_modules/typescript/bin/tsc --noEmit` 退出码 **0**（修复后实测 2026-09-30）。

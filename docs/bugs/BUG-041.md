# BUG-041：介绍无法显式清空——PATCH null 语义缺失

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: engine+shell
- 严重程度: mid

## 现象
剧集/单集介绍一旦设置就永远删不掉：前端把空串转成 `undefined`（=不改），
后端 `SeriesPatch.description`/`EpisodeEdit.description` 是 `Option<String>`——
JSON `null` 反序列化成 `None`，与「字段缺省」不可区分。

## 修复
契约对齐既有裁定（资源 id 只从路径来；PATCH 用 `Option<Option<T>>` 区分
缺省与显式 null）：两处 description 改 `Option<Option<String>>` + `nullable`；
前端空介绍保存发 `null`。

## 验收
e2e：`PATCH series/3 {"description":null}` → 200 → descLen=0；
`verify_episode_edit.py` 12/12。

BUG-022（PATCH 契约）。

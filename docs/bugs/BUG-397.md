# BUG-397: 频道展示的内容图片被截断（上下丢失）

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: mid
- 报告: 用户 2026-10-23 16:43「频道展示也有问题,展示的内容图片被截断了,没有显示全部内容图片的上下都丢失了.」

## 现象（实测，非推测）

频道消息流里的**内容图片**（相册封面、单图、左列缩略图、视频海报）被上下裁切——竖向（portrait）照片只看到中段，顶部与底部内容丢失。用户判定：应该显示**完整**内容图，而不是裁切。

## 根因：`object-cover` 在限高容器里裁切，且用在了「内容图」上

`TgPanel.tsx` 多处内容照片用 `object-cover`：
- 相册封面（折叠/单图）：`h-auto max-h-72 w-full object-cover`（行原 3361/3397）——`max-h-72`(288px) 限高 + `object-cover` ⇒ 竖向图高被压到 288px 时上下裁切；
- 相册宫格瓦片：`aspect-square ... object-cover`（行原 3457）—— 方形容器的内容图被 crop 成方；
- 左列缩略图 `PhotoBlock` compact：`absolute inset-0 h-full w-full object-cover`（行原 3636）；
- 左列视频海报 compact：`absolute inset-0 h-full w-full object-cover`（行原 3749）。

`object-cover` 的语义是「裁切填满」，只适合**纯装饰/索引**缩略图；**内容图片**要的是「完整可见」，应用 `object-contain`（letterbox，不裁切）。

## 修法（内容图用 object-contain，UI 图标类保持 cover）

将上述四处**内容照片**的 `object-cover` 改为 `object-contain`：
- 相册封面（3361/3397）：`h-auto max-h-72 w-full object-contain`；
- 相册宫格瓦片（3457）：`h-full w-full object-contain`；
- `PhotoBlock` compact（3636）：`h-full w-full object-contain`；
- `VideoBlock` compact 海报（3749）：`absolute inset-0 h-full w-full object-contain`。

非 compact 的大图预览本就是 `object-contain`（行 3636/3750 的 else 分支），无需改。`CoverImage`/`SeriesHero` 等封面索引仍按各自既有规则保持 `object-cover`（那是版面封面，不是「内容图」）。

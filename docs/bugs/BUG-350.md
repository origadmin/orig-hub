# BUG-350: 剧集详情右栏主次颠倒——核心播放夹在展示流中间，「在 TG 中查看」高亮抢主位且与左栏重复

- 状态: fixed
- 发现日期: 2026-10-21
- 模块: shell
- 严重程度: high

## 现象

用户报障（2026-10-21）：「剧集详情主次不分，把核心播放位置放到了次(展示)，TG 中查看
这个次内容放到了主（而且次中已有）。排版逻辑非常混乱。」

旧版式实测（活库 5180，`verify/_probe_bug350_series_detail.cjs` 取证）：右栏（单集面）
**8 段 border-t 平铺**，展示块与动作块交错：

```
#0 标题行(含编辑按钮)  #1 本集图组(空标题)  #2 ▶播放  #3 本集介绍
#4 来源(两颗绿色高亮「在 TG 中查看」)  #5 移除组  #6 操作组  #7 合并溯源
```

- 播放（核心动作）被夹在「本集图组」与「本集介绍」两个**展示区**之间，视觉上像
  展示流的一部分；
- 「在 TG 中查看」（次要动作）在来源主版本行放了一颗
  `border-accent/60 bg-accent/10 text-accent` 的**高亮主位按钮**，而左栏选集器
  **每一行已有**同款入口（`episode-row-view-tg`）——次内容占主位且重复；
- 管理动作散布三处（标题行编辑 / 移除组 / 操作组）；
- 无图组的集渲染「本集图组」空标题（BUG-340 同口径噪音）。

## 根因

右栏是**追加式堆砌**：历次 BUG（210/265/285/305/197）各自往面板里加块、加按钮，
没有「主区/次区」的结构分层——动作与展示按加入时间交错排列，主次关系由视觉
偶然性决定。

## 修复（已实施）

`tauri-shell/src/components/media/SeriesDetail.tsx` 右栏重排为**两层结构**
（区块收敛 8 → 3）：

1. **主区**（`data-zone="primary"`，`episode-primary-zone`）：紧跟头部，
   ▶ 播放 = 右栏第一个内容、唯一实心主按钮（w-full h-9，BUG-210 判据保持）；
   其下一条动作条收拢全部管理动作：编辑本集 / 挂图 / 前往条目 / 重缓存(无字节时) /
   上移 / 下移 / 移除——编辑仍是同一开关（BUG-197/202，testid `episode-edit` 不变）；
2. **次区**（`data-zone="secondary"`，`episode-secondary-zone`）：纯展示流，
   本集图组（**无帧整块不渲染**）/ 本集介绍 / 来源 / 合并溯源，容器一条分隔线；
3. **「在 TG 中查看」降级**：主版本行与备用源行的 `episode-source-jump-tg`
   从高亮实心改为与 t.me 外链同款灰边次要样式（testid/tagName/href 不变，
   BUG-285/305 判据不受影响）；应用内跳转能力保留，左栏行级入口保留。

# BUG-002: 无法查看每连接状态与分块进度

- 状态: fixed
- 发现日期: 2026-08-26
- 模块: engine+shell
- 严重程度: mid

## 现象
下载进行时，前端只能看到总体进度百分比，无法看到：
- 每个连接（源 / 网卡）的当前状态（待分配 / 分配中 / 完成 / 失败）、所属网卡、实时速度；
- 分块下载（Range 模式）每块的状态网格（pending / assigned / done / failed）。

## 根因
`Progress` 结构体缺少逐连接与分块的明细字段，引擎 `progress()` 未填充这些信息，
daemon 未透传，前端类型与组件也未渲染。

`file: download-engine/crates/libsurge/src/protocol.rs`（`Progress` 定义）
`file: download-engine/crates/libsurge/src/engine.rs`（`progress` 函数）

## 复现
启动一个多源 / 多网卡 / 分块下载任务，观察 SSE `Progress` 事件是否携带
逐连接与分块明细。

## 修复
- `libsurge/src/protocol.rs`：新增 `ConnInfo` 结构（id / state / block / speed /
  iface / source_index）+ `BLOCK_PENDING/ASSIGNED/DONE/FAILED` 常量（u8 0/1/2/3）；
  `Progress` 增加 `connections_detail: Vec<ConnInfo>`、`blocks: Vec<u8>`、
  `blocks_total`、`blocks_done`、`blocks_pending`（`#[serde(default)]`）。
- `libsurge/src/engine.rs`（`progress`）：用 `selector.health(i)` + `sources[i].iface_name()`
  构建 `connections_detail`；由 `bm.blocks` 统计 `blocks_total/done/pending` 并生成
  `blocks` 状态数组（>4096 块时为空，避免超大负载）。
- `surge-daemon/src/status.rs`（`DownloadStatus` + `from_progress`）：透传上述新字段。
- `tauri-shell/src/types.ts`：`DownloadStatus` 增加对应字段并新增 `ConnInfo` 接口。
- `tauri-shell/src/components/DownloadItem.tsx`：整行点击打开底部详情 Sheet
  （`DownloadDetailSheet`），移除内联块网格 / 连接 chip。

## 增强：底部 Sheet 详情视图（2026-08-26 定稿）

经方案评审（预览 v4），将 BUG-002 的内联渲染改为**底部滑出 Sheet**，并补两块后端埋点。

### 后端新增埋点
- `protocol.rs` `BlockMap` 增加 `block_source: Vec<u8>`（255=未分配），`new` 初始化，
  新增 `set_source`/`source_of`；`Progress` 增加 `block_source: Vec<u8>` 与 `supports_range: bool`
  （均 `#[serde(default)]`，与 `blocks` 同门控 >4096 留空）。
- `engine.rs` `worker`：在 `pick_source` 成功后 `block_map.set_source(idx, si)`，记录每块负责源
  （重试覆盖为新源）；`progress()` 填充 `block_source` / `supports_range`。
- `status.rs` / `types.ts`：透传 `block_source` 与 `supports_range`。

### Sheet 显示方案（已批准）
- **触发**：列表项整行点击打开，操作按钮 `stopPropagation` 不触发。
- **块网格按负责网卡着色**：颜色 = 源所属网卡（eth0/wlan0/…）；未分配块统一灰色；
  **完成/失败/待下载颜色统一为网卡色**，仅用填充样式区分（实色=完成、半透明=下载中、红框=失败）。
- **表头重做**：顶部细渐变强调线 + 标题行内嵌抓手(⠿)，消除原悬浮竖条导致的标题上方空洞。
- **源/网卡表**：中文状态（下载中/错误/空闲）、中文表头（源# / 网卡 / 状态 / 速度）。
- **全局聚合去重**：Sheet 内仅保留「一行小字」（总速度 / 任务数），不重复画条（MainLayout 已有常驻全局条）。
- **降级**：非 Range 单流（`supports_range=false`）→ 不渲染块网格，提示「以字节进度为准」；
  块数 >4096 → 文字计数 `{done}/{total} 块`。
- **语言统一**：状态 / 连接状态 / 表头全中文，元信息 `ETA` → `剩余`，解决英文/中文混搭。

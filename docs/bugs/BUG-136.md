# BUG-136：cache 接口 external 字段双形状双口径——stats 返数字、clear/preview 返对象

- 状态: fixed
- 发现日期: 2026-09-22
- 模块: engine
- 严重程度: low

## 现象

同一个 `external` 语义（「下载目录之外的已登记文件」），两个接口返回**两种 JSON 形状**，且**口径不同**：

| 接口 | 形状 | 口径 |
|---|---|---|
| `GET /api/cache/stats` | **数字** | 只计数、**不累加字节**（命中外部文件直接 `continue`） |
| `GET /api/cache/clear/preview` | **对象**（含 `bytes`、`removable: false`） | 计数 **且累加字节** |

前端若想展示「外部文件占了多少」，只能依赖 preview 那一次；stats 的 external 答不出字节。

## 根因

- `cache.rs:858-870`（stats）：`if !inside_dir(&dir, &it.file_path) { external += 1; continue; }` —— 一个字节都不加。
- `cache.rs:611-616`（clear_preview）：`else { external += 1; external_bytes += size; }` —— 累加。

## 复现

对同一份含外部文件的库分别请求两接口，比对 `external` 的类型与 bytes 口径。

## 修复

已修（提交 `9bbee58`，engine；`6ee9e76`，shell 侧同步）：

- `stats.external` 归一为与 `clear/preview` **逐字同形状**
  `{"count": n, "bytes": n, "removable": false}`，并累加外部文件的真实字节。
- 字节口径收口到**唯一实现** `cache::file_len()`：此前 `stats` 用
  `metadata()` + `is_file()`、`preview` 用 `metadata().map(len)`（目录也会被算出一个长度），
  同一事实两套实现必然漂移；现在两处都读它。
- `bytes` 的既有含义**未变**（仍只含「下载目录内、由条目背书的可清字节」）；未新增 `total`
  等任何超出本缺陷范围的字段。
- 前端 `tauri-shell/src/api/tg.ts`：`getCacheStats().external` 与 `CacheClearPreview.external`
  共用同一个 `CacheExternalBytes` 类型。旧验收脚本 `tauri-shell/verify/shot_clear_center.cjs`
  此前把 `stats.external` 当数字比较，已改读 `.count`。

兼容面已实查：`stats.external` 在 `tauri-shell/src` **零消费**（界面那行读的是
`preview.external.count`，`CacheBytesPanel.tsx`），Rust 侧无内部调用方，故形状变更不打断 UI。

（本机 curl 坑仍在：`-o /dev/null` 恒 exit 23；故脚本走 `urllib`，判成败只看 HTTP 状态码与响应体。）

真实报文摘录（同一隔离实例，下载目录内 2048 B 条目一条 + 目录外 4096 B 条目一条）：

1. 判据 1（同形状）与判据 2（同值）：

   ```text
   GET /api/cache/stats
   → 200 {"bytes": 2048,
          "external": {"bytes": 4096, "count": 1, "removable": false},
          "files": 1, "ok": true}
   GET /api/cache/clear/preview
   → external {"bytes": 4096, "count": 1, "removable": false}
   ```

   两接口 `external` 形状一致（键集 == `count/bytes/removable`）且 count、bytes **逐字相等**；
   `removable` 恒 false（外部文件永不删）。

2. **反向证伪**（先造「下载目录外文件」用例，断言两端都把它计入 external；任一端恒 0 即 FAIL）：
   外部文件磁盘实占 4096 B，`stats.external.bytes` 断言等于 **4096**（不是 0，也不是只计数不累加）；
   同时 `stats.bytes` 断言等于 **2048**、与 `preview.total.bytes` 逐字相等 —— 证明「累加外部字节」
   没有把外部字节混进 `bytes`（既有含义未变）。

3. 消费方复检：`git grep` 全仓确认 `stats.external` 在 `tauri-shell/src` 无消费者，Rust 侧无内部调用方。

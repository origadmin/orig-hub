# BUG-455: 下载域「全部下载」页文案丢失（i18n key 缺失）

- 状态: in_progress
- 发现日期: 2026-10-27
- 模块: shell
- 严重程度: high
- 排期: 2026-10-30

## 现象

「全部下载」页（下载域任意树档）大量文案显示成 i18n key 原文（如 `download.panel.selectAllPage`、
`download.panel.emptyHint`）或空白，页面文字整体丢失，用户判定「全部下载页面文字丢失」。

## 根因

`DownloadPanel.tsx` 引用 `download.panel.*` / `download.list.*` 共 20+ 个 key（168-392 行），例如：
`download.panel.scopeDaemonDown / scopeBothDown / scopeTgUnavailable / scopeDlUnavailable /
skippedIngest / cancelNothing / cancelSkipped / selectAllPage / selectNone / clearSelection /
clear / cancelSelectedTitle / cancelSelectedLabel / snapshotNote / emptyTitle / emptyRecover /
emptyTg / emptyHint`、`download.list.loading / list.retry`、`download.selectedCount` 等。

但 `zh-CN.json` 仅定义 `download.done / download.paused / download.running /
download.selectedCount / download.toggleBuckets`；`en-US.json` 同样**不存在** `download.panel.*` /
`download.list.*` 任意键。即这批 key 自引入起从未落库（与 BUG-447 同类：引用不存在的 key →
react-i18next 默认回退显示原始 key 串）。

## 复现

- 打开下载域 → 观察空态标题/副文案、底部选中条（全选/清空/取消选中）、来源不可达横幅 →
  全部显示为 `download.panel.*` 原始 key。

## 修复

以 `DownloadPanel.tsx` / `DownloadList.tsx` / `IngestDetailSheet.tsx` 实际引用集合为单一真源，枚举全部
`download.panel.*` / `download.list.*`（共 22 个扁平 key），已在 `zh-CN.json` 与 `en-US.json`
同时补齐中文/英文文案（插入点：`download.toggleBuckets` 之后）。

涉及 key：
`download.panel.{scopeDaemonDown,scopeBothDown,scopeTgUnavailable,scopeDlUnavailable,skippedIngest,
cancelNothing,cancelSkipped,selectAllPage,selectNone,clearSelection,clear,cancelSelectedTitle,
cancelSelectedLabel,snapshotNote,emptyTitle,emptyRecover,emptyTg,emptyHint}`、
`download.list.{loading,retry,emptyTitle,emptyHint}`。

`download.selectedCount` 此前已存在，不在补录范围。

注：BUG-447 同类门禁（引用未定义 key 即失败）仍待落地，本回合先补 key 止血。

## 关联

- BUG-447（i18n 引用不存在的 key，界面显示原始 key）—— 同类根因。
- BUG-372 / BUG-366（下载域信息架构重构，本面板文案随重构引入但未补 i18n）。

## 验收证据

门禁（可跨机复核）：`python3 scripts/check-i18n-keys.py` →
`OK - i18n keys aligned (2 locales, 923 keys)`，EXIT=0 —— 即**引用集合 ⊆ 定义集合**
在 zh-CN / en-US 两侧同时成立，同一类漏 key 再发生会直接红（本 BUG 的复发由既有门禁拦截）。
另 `tsc --noEmit` 0 错、`vite build` EXIT=0；
`grep -c "download.panel\.\|download.list\." zh-CN.json` 与 `en-US.json` 各命 22 个 key，与引用集合一致。
**待 GUI 复验**：全部下载页各树档截图，文案显示正常中文、无 `download.panel.*` 残留 key
（需 dev 栈 + CDP，本机无法起 GUI）。

# BUG-143：ImportDialog 默认目录硬编码 D:\test_videos——开发残留进了生产 UI

- 状态: fixed
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: low

## 现象

「导入本地目录」对话框的目录输入框**默认值**是 `D:\test_videos`（开发机的测试路径），placeholder 同样硬编码该路径——任何用户的导入对话框打开都预填一个与自己无关的路径。

## 根因

`media/ImportDialog.tsx:26` `useState('D:\\test_videos')`；`:109` placeholder 同值。属开发期图省事的残留，随功能直接进了生产。

## 复现

媒体库 → 工具条「导入目录」→ 对话框打开即见预填的 `D:\test_videos`。

## 修复

默认值改空串（或接入 `lib/recentDirs.ts` 的最近使用目录）；placeholder 改中性示例文案并走 i18n（并入 BUG-141 批次）。

## 关联

- BUG-141（i18n 批次）、BUG-128（同类「开发值进生产」教训）
- handover 报告 N3

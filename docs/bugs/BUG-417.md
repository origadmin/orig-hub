# BUG-417: 缺少视频跳帧功能——每段前/后跳固定秒数

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: low

## 现象
播放视频时，用户**先设定「前面跳过 N 秒 / 后面跳过 M 秒」**，播放器只播中间的**主要段**
（如跳过片头片尾），不播首尾。本质是**片头/片尾裁剪式分段播放**，不是控件条上的步进按钮。

## 根因
播放器缺「分段裁剪（片头/片尾跳过）」模型：既有 `contentOffset` / `contentDuration` / `timeScale` 已构成「内容窗口」机制（贯穿 `useMediaClock` / `PlayerTimeText` / `PlayerProgressBar` / `seekToRatio`），但无「用户设定前跳 N 秒 / 后跳 M 秒、只播中间主段」的入口与钳制；`loadedmetadata` 后自动 seek 到段首、到段尾即止的逻辑缺失；控件条无跳段入口。

## 复现
待补。

## 修复
复用既有 content-window 机制（不写入 rate-switch 的 `contentOffsetRef` / `contentDurationRef`，规避转码锚点冲突），以运行时 props 实现，无需落库字段：
- `VideoPlayerProps` 增 `skipStartSec?` / `skipEndSec?`（默认 0 / null）；`segOffset = max(skipStartSec,0)`、`segDuration = skipEndSec>segOffset ? skipEndSec-segOffset : null`。
- 显示层：两处 `PlayerTimeText` + 两处 `PlayerProgressBar`（含 compact）的 `contentOffset/contentDuration` 改用 `segOffset/segDuration`，进度条只呈现主段。
- 真实元素钳制（独立 effect）：`timeupdate` 监听，越起点拉回 `segOffset`；到达 `segOffset+segDuration-0.1` 则 `pause()` + `onPlayNext()`；`loadedmetadata` 时若起点 >0 直接 seek 到 `segOffset`。
- 控件条（倍速前）加「跳过片头/片尾」按钮（`Scissors` 图标，`data-testid="player-skip-segment"`）+ 弹层（两个 number input 绑 `skipStartSec/skipEndSec`，激活时按钮 `bg-accent/30`）；i18n：`player.skipSegment` / `player.skipSegmentHint` / `player.skipStart` / `player.skipEnd`（中/英）。

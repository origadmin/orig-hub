# BUG-417: 缺少视频跳帧功能——每段前/后跳固定秒数

- 状态: open
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: low

## 现象
播放视频时，用户**先设定「前面跳过 N 秒 / 后面跳过 M 秒」**，播放器只播中间的**主要段**
（如跳过片头片尾），不播首尾。本质是**片头/片尾裁剪式分段播放**，不是控件条上的步进按钮。

## 根因
待定位（播放器缺「分段裁剪」模型：条目缺 `skip_head_sec` / `skip_tail_sec` 属性；控件条/进度条
缺主要段标记，及「loadedmetadata 后自动 seek 到段首、达段尾即止」的逻辑；关联 BUG-035 自绘控件条）。

## 复现
待补。

## 修复
待修复（增强类需求，方案拍板后再实施）。
数据模型：media item 增 `skip_head_sec` / `skip_tail_sec`（可逐集设、可整剧套用默认）。
播放器 `loadedmetadata` 时若 `currentTime < skip_head_sec` 则 seek 到该偏移；`timeupdate`
达 `duration - skip_tail_sec` 即视为本集结束（续播或停）。进度条渲染主要段（段首/段尾手柄），
设置入口在单集编辑面板。

## 关联
- BUG-035（自绘播放器控件条，跳帧入口可挂于此）

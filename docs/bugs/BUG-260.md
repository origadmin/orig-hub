# BUG-260: 分集行把槽位标签渲染两遍 —— `S1E3 S1E3 未缓存`

- 状态: fixed
- 发现日期: 2026-10-10
- 修复日期: 2026-10-12
- 模块: shell
- 严重程度: mid
- 登记: 主理人跑 BUG-254 验收时从实测读数发现（用户未报）。取证脚本
  `tauri-shell/verify/verify_bug_254_nobytes_visibility.cjs` 的行文本读数。

## 现象

剧集详情「分集列表」每一行把同一个槽位标签渲染**两次**：

| 分集 | 实测行文本 | 应为 |
|---|---|---|
| `epId=654`（无字节） | `S1E3S1E3未缓存` | `S1E3 未缓存` |
| `epId=652`（有字节带时长） | `S1E1S1E14:42` | `S1E1 4:42` |

照片集（如 series 218）现状：左列是 `🖼` 图标、中列渲染 BUG-049 兜底标题
（如 `TG 图片 #8609`），**不再**重复槽位标签 —— 本文档初版「🖼 🖼」的读数是
**旧手风琴代码**留下的，当前左选右看布局下已不成立（结论保留断言防回归，
见「验收证据」判据 2）。

## 根因（代码事实）（2026-10-12 活体取证后重写）

`tauri-shell/src/components/media/SeriesDetail.tsx` 的分集选择行
（`data-testid="episode-pick"`，三列栅格，当前行号约 :678-701）：

- **左列**（:693）：`{photo ? '🖼' : episodeSlotLabel(ep)}` —— 槽位标识；
- **中列**（修复前 :700）：`{shouldRenderEpisodeTitle(ep, detail) ? ep.title : episodeSlotLabel(ep)}`。

**初版根因假设不成立（活体证伪）**：初版认为「BUG-246/BUG-200 把无标题分集的
`ep.title` 回填成槽位标签」（于是判据为真、中列渲出槽位标签）。实测否证：
BUG-200 的裁定恰是「集可以没有标题、空标题可显式清空」；活库
`GET /api/media/series/315` 的 8 集里 **7 集 `media_item.title` 就是空串**。

真正的重复机制是**中列回退**：标题为空 ⇒ `shouldRenderEpisodeTitle` 为 false
⇒ 中列回退渲染 `episodeSlotLabel(ep)` ⇒ 与左列逐字重复。即「空标题可表达」
（BUG-200 裁定）+「中列拿槽位标签兜底」两个各自正确的决定叠出了本缺陷；
判据只挡「标题 == 剧集标题」，**没挡「标题 == 槽位标签」**。

## 与 BUG-254 的关系（边界）

两行在 BUG-254 提交（`87a2683`）中均为**未改动上下文**（diff 里以空格前缀出现），
故本条是**既有缺陷**，由 BUG-254 的验收读数暴露，**不是 BUG-254 的回归**。

## 修复方向（已按此落地，2026-10-12）

1. `shouldRenderEpisodeTitle` 增加第三条判据：`ep.title !== episodeSlotLabel(ep)`
   —— 槽位标签已在左列展示，中列不该重复；这是「让错误状态不可表达」的正解
   （判据本身拒绝「标题就是槽位标签」这种无信息量的展示）。
2. 新增纯函数 `episodeRowTitle(ep, series)`（`src/lib/episodePresentation.ts`）：
   门控为真返回 `ep.title`，为假返回 `null` —— **中列不得回退槽位标签**
   （React 对 null 渲染 nothing，中列留空而非重复）。分集行中列改渲该函数
   （`SeriesDetail.tsx` 仅此一处）；右栏聚焦面板 `episode-focus-title` 的回退
   **保持原样**（面板内没有左列，不构成重复；TL-21 布局回归 R5「同名时退化
   为 S1E1」依赖该回退）。
3. 照片集：左列 `🖼`、中列兜底标题，随第 1/2 条一并保证不重复 —— 验收判据
   对 photo 行的期望是「槽位标签 0 次」（左列是图标，槽位标签无展位，中列
   不得回显）。
4. **不得**回退 BUG-200 的「集不能没有标题」：标题回填仍要保留，只是不重复
   **展示**。数据侧零改动：回填行为、`episodeSlotLabel`、编辑入口（R3：
   标题 / 介绍恒可读写）全部原样。

# BUG-410: 内容详情主卡片功能错位——导出浏览应为当前视频剧集而非总浏览

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: mid

## 现象

内容详情主卡片上的功能（如「导出浏览」）当前呈现/作用的是「总的浏览」，但当前上下文
是单个视频详情。所有功能应针对「当前视频 / 当前剧集」而非全局，作用域错配。

## 根因（实测）

剧集详情的「导出预览」按钮（`series-export`，文案 `media.exportPreview`
=「导出预览 —— 完备性校验」）只做一件事：

```ts
onExport={() => setExportOpen(true)}
```

`exportPreselect` 仍为 `null` ⇒ `ExportPreviewDialog` 的 `checked` 初值走
「`preselect` 为空就全选」那一支 ⇒ 打开时**整库 89 部剧集全部预勾**。
用户从「某一部剧集」点进去，看到的是「全库都在导出」，正是报障原象。

（对照：剧集墙的批量导出**有**设 `exportPreselect`，见 `MediaLibraryPanel`
`setExportPreselect(selectedSeriesList.map(...))` —— 同一个能力，详情页这条入口漏了。）

## 修复

把当前剧集预勾上，`ExportPreviewDialog` 一行不改：

```ts
onExport={() => {
  setExportPreselect([detail.id])
  setExportOpen(true)
}}
```

**刻意不把候选收窄成子集**：`ExportPreviewDialog` 的 `series` 恒为全库，因为
`run()` 里 `ids.length === series.length ? undefined : ids` 是「全选 ⇔ 全库」短路；
把候选换成子集会让「子集恰好全勾」被当成「导出全库」（BUG-214 已论证）。
本次只改**初值**：作用域对齐当前上下文，同时不剥夺「顺手多导几部」的能力。

# BUG-338: 纯图片入口仍写「加入媒体库」——违反「图片永不进剧集」硬规则的文案残留（行为本身正确，错在文案）

- 状态: fixed
- 发现日期: 2026-10-20
- 模块: shell
- 严重程度: mid

## 现象（用户原话，2026-10-20 第 7 点）

> 「现在纯图片还有『加入媒体库』这个错误的逻辑，完全违反图片不入库的基础共识，图片最多允许进入图片库，而不允许进入『剧集』(媒体库)。」

单张图片操作的按钮文案写「加入媒体库」，与「图片永不进剧集」的硬规则表述冲突（本弧 BUG-329 裁定②修订后：图片可下载入图片库、绝不进剧集）。

## 根因

BUG-329 修订裁定②落地时（后端三层守卫 + 前端 `seriesId` 截断 + 筛选面板撤回禁用），漏改单张图片入口的用户可见文案：i18n 键 `tg.addToLibrary` 两语均为「加入媒体库 / Add to library」，`TgPanel.tsx` 内 9 处注释同样沿用旧表述。按钮**行为本身是对的**（`importPhoto` → `importMediaItems` 只入 `kind=photo` 浏览条目，绝不成剧集分集），错的是文案与共识相反。

## 修复

- `tauri-shell/src/i18n/locales/zh-CN.json`：`tg.addToLibrary`「加入媒体库」→「加入图片库」；
- `tauri-shell/src/i18n/locales/en-US.json`：「Add to library」→「Add to image library」；
- `tauri-shell/src/components/TgPanel.tsx`：上述 8 处注释改为「加入图片库」表述，与裁定②对齐。

# BUG-046 单视频气泡没有缓存按钮，图片反而有

**状态**: fixed
**优先级**: high
**模块**: tauri-shell / TgPanel
**日期**: 2026-09-18

## 现象

TG 内容流里：图片（单条）与相册都有显式「缓存」按钮，单个视频却没有任何按钮——
缓存入口只是海报上居中的 ⬇ 图标（点击海报 = 开始缓存），用户读作「单个视频没有缓存，
反而图片有缓存」，逻辑倒置。

## 根因

`MessageBubble` meta 行对视频显式返回 `null`（历史裁定「视频的缓存/播放操作在海报上，
meta 行不重复放按钮」）。海报 ⬇ 是隐性手势，与图片的显式按钮不同构，违反一致性。

## 修复

meta 行按钮与图片同构（`TgPanel.tsx` MessageBubble）：

- 未缓存 → 「缓存」按钮（缓存中禁用并显示「缓存中」）
- 已缓存 → 「播放」按钮（openPath 打开本地文件，与图片行为一致）

海报点击行为不变：已缓存=应用内播放本地流、缓存中=在线播放、未缓存=开始缓存。
按钮是明确的兜底入口，不再依赖图标语义。

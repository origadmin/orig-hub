# BUG-088: 「传输中」面板把后端原始 HTTP 报文（404 Not Found）直接渲染进正文

- 状态: fixed
- 发现日期: 2026-09-21
- 模块: shell
- 严重程度: mid

## 现象

点 `nav-activity` 进「传输中」，正文红条显示 **`404 Not Found`** —— 后端原始英文 HTTP 错误
被原样甩给用户，且整屏只有这一条红条（下方列表区空白，无空态兜底）。

## 根因

两处叠加：

1. **直出报文（主因）**：`tauri-shell/src/components/ActivityPanel.tsx:236-240`（修前）把
   `failed` 状态原样渲染，而 `failed` 存的就是 `fetchActivity` 抛出的原始消息 ——
   `tauri-shell/src/api/activity.ts` 的 `request()` 在非 2xx 时抛
   `` `${res.status} ${res.statusText}${body ? `: ${body}` : ''}` ``，即 `404 Not Found`。
   渲染层没有任何降级，等于把传输层错误当作用户可读文案。
2. **持续刷必然失败的请求**：`hasWork` 为真（有在途下载）时，轮询循环按 5s→10s→20s→30s 退避
   反复请求同一个结构性缺失的端点（AGENTS.md §5 失败退避只被「用」，没被「守」到底）。

**不在本次范围内的根因背景**：当前运行的 daemon 二进制是陈旧构建，没有 `/api/activity` 路由
（该路由由提交 `4ca71c8` 引入，晚于磁盘上的二进制），故恒 404。这属环境问题，由 sidecar 重建解决，
本次只修**防御性渲染** —— 即便后端回任何错误，UI 也不许直出原始报文。

## 复现

1. 陈旧 daemon 二进制在跑（`/api/activity` 恒 404）；
2. `npm run dev` 起 5180，点 `nav-activity`；
3. 修前正文出现 `404 Not Found`；修后正文只出现中文降级文案。

## 修复

1. **只分类、不直出**：`failed: string | null` 改为 `failKind: 'unavailable' | 'failed' | null`，
   失败时经 `failKindOf()` 只判断「是不是 4xx/5xx 端点侧问题」，**错误消息本身不进 UI**；
   渲染取 `FAIL_LABEL` 的中文 key（`activity.loadUnavailable` / `activity.loadFailed`）。
2. **可行动出口**：错误条改为 warning 色 + 中文文案 + 「重新加载」按钮（`activity.reload`），
   熔断后用户可自愈（重置退避并重启一轮轮询）。
3. **空态兜底**：列表区 `tasks.length === 0` 时不再只有红条 —— 错误态下显示
   `activity.loadFailedEmpty`「暂时没有可显示的传输任务」，正常态仍是 `activity.empty`。
4. **熔断**：新增 `MAX_FAILS = 4`，连续失败到顶即**停轮询**（不再按退避无限刷必然失败的端点）；
   恢复路径有二 —— 「重新加载」按钮，或 `hasWork` 变化（真有任务增删时由 store 唤醒重跑）。
5. **来源错误同源治理**：`activity.sourceDown` 的 `{reason}` 也过 `sourceReasonText()`，
   命中 HTTP 状态行或空值即降级为中文（`activity.sourceUnavailable` / `activity.sourceUnknown`），
   避免同一条规则在面板里两处不同标准。

## 验收证据

真实浏览器（零依赖 CDP 驱动）实测，`/api/activity` 仍返回 404 的前提下：

- 面板 `innerText` = 「传输中 / 下载与 TG 缓存的合并只读视图 / 本视图只读：… / **传输中数据暂时无法加载** /
  **重新加载** / **暂时没有可显示的传输任务**」，正则 `/404/` 与 `/\b[45]\d\d\b/` **均不匹配**，
  即正文搜不到 `404`（`[data-testid=activity-load-failed]` 命中，「重新加载」按钮存在）。
- 熔断计数：注入一条 `status=downloading` 的任务（`hasWork=true`，会持续轮询），
  `performance.getEntriesByType('resource')` 统计 60s 内 `/api/activity` 请求数 = **4**（到 `MAX_FAILS` 即停）；
  修前同场景按 5s 起步退避会持续刷下去。
- 页面 `pageErrors` 为空（404 只出现在 console 网络日志，不进 UI 正文）。

- 改动文件：`tauri-shell/src/components/ActivityPanel.tsx`、
  `tauri-shell/src/i18n/locales/zh-CN.json`、`tauri-shell/src/i18n/locales/en-US.json`（入库，跨机器可核）
- 复测驱动：`tauri-shell/verify/lib/cdp.cjs`
- 门禁：`python scripts/check-bugs.py` 与 `sh scripts/check-pollution.sh` 均 EXIT 0；
  `node node_modules/typescript/bin/tsc --noEmit` EXIT 0

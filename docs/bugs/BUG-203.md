# BUG-203 本集编辑态与静态展示同屏渲染：标题等文本重复两行

- 状态: fixed
- 发现日期: 2026-09-30
- 模块: shell
- 严重程度: mid

## 现象

用户在剧集内页反馈：「本集编辑立马重叠重复2行」「基础逻辑严重问题」。

CDP 实测确认：点「编辑本集」进入编辑态后，右栏**静态展示层**没有被隐藏，与
`EpisodeEditPanel` 的输入控件**同时渲染**——同一标题文本在 DOM 里出现两次
（静态 h3 + 面板标题输入框），视觉上即「重叠重复 2 行」。修复前探针：
`title_occurrences_in_dom = 2`。

## 根因

BUG-197 给右栏引入 `editingEpisode` 门控时，只门控了「编辑面板是否渲染」
（`{editingEpisode ? <EpisodeEditPanel/>} : null`），**没有反向门控静态展示块**：
标题 h3、本集介绍（`episode-focus-desc`）、本集图组、独立挂图按钮
（`episode-attach-images`）在编辑态照旧渲染。展示层与编辑层叠加，没有互斥。

## 复现

1. 媒体库 → 打开剧集 → 点「编辑本集」。
2. 右栏同时出现：静态标题 h3（带完整标题文本）+ 面板内标题输入框（同一文本）
   ⇒ 重复两行。
3. `verify_shots/repro_ep_edit/repro.cjs`（修复前基线）探针
   `title_occurrences_in_dom = 2`。

## 修复

改动限于 `tauri-shell/src/components/media/SeriesDetail.tsx`：

1. 编辑态下静态标题 h3 改显**槽位标签**（`episodeSlotLabel(cur)`，如 `S1E6`），
   不再重复渲染标题文本；浏览态行为不变（有标题显示标题，无标题显示槽位标签）。
2. 编辑态下隐藏本集介绍块（`episode-focus-desc`）、本集图组块与独立挂图按钮
   （`!editingEpisode` 门控）——介绍与图片的编辑各自收进统一面板（图片见 BUG-204）。

## 关联

- BUG-197：引入 `editingEpisode` 门控，但只门控了面板渲染方向。
- BUG-202：编辑入口上移到标题行（同一交互区）。
- BUG-204：图片管理收进统一编辑面板（本档隐藏的独立挂图按钮由它承接）。

## 验收证据

- 入库脚本：`tauri-shell/verify/verify_episode_unified_edit.cjs`（跨机器可复核：
  需 5180 开发态服务，`node verify/verify_episode_unified_edit.cjs`，全过 EXIT 0）。
- 修复后实测（2026-09-30，`http://127.0.0.1:5180/` 真实渲染）：标题文本在 DOM
  中**恰好 1 次**（= 输入框）；静态 h3 显槽位标签 `S1E6`（≠ 标题文本）；
  独立挂图按钮编辑态为 0。9/9 断言通过。
- 前端 TypeScript 编译门禁 `node node_modules/typescript/bin/tsc --noEmit` 退出码 0。
- 反向证伪：去掉 h3 的 `editingEpisode ? episodeSlotLabel : …` 分支 ⇒ 标题文本
  回到两处渲染（h3 + input），与缺陷态一致。

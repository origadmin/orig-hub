# BUG-008: 自动分类「新增分类行」布局错乱

- 状态: fixed
- 发现日期: 2026-08-27
- 模块: shell
- 严重程度: mid

## 现象
设置页 → 下载 → 自动分类，最下方「新增分类行」（分类名 + 后缀 + 添加按钮）整体布局错乱：两个输入框没有被固定宽度 / 弹性宽度约束，而是被撑开或挤压，按钮错位，整行视觉崩坏。

## 根因
`ui/input.tsx` 的 `Input` 基础 className 写死了 `w-full`；而 `cn()`（`lib/utils.ts`）只是 `join(' ')`，**没有 tailwind-merge**。新增分类行给 `Input` 传入 `w-28 shrink-0` 与 `min-w-0 flex-1`，于是 `w-full` 与 `w-28`/`flex-1` 同时存在于 class 串里，最终由 Tailwind 编译后的 CSS 源顺序决定胜者 → 宽度冲突、布局错乱。
（`SettingsPanel.tsx:419,426` 的两处 `Input`。）

## 复现
打开设置 → 下载 → 自动分类，观察最下方新增行。

## 修复
不让 `Input` 的 `w-full` 与调用方的宽度类同场冲突：用外层 `div`（`.w-28.shrink-0` / `.min-w-0.flex-1`）包裹 `Input`，`Input` 的 `w-full` 只负责填满 wrapper，宽度由 wrapper 控制。新增行 `Input` 不再传 `w-28`/`flex-1`。
（`SettingsPanel.tsx` 新增分类行：用 div 包裹两处 `Input`。）

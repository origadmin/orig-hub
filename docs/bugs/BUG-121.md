# BUG-121：按钮语义重叠 —— 同一按钮按内容类型变文案，被用户当成两个不同入口

- 状态: open
- 严重程度: low
- 模块: shell
- 发现日期: 2026-09-22

## 现象

用户看到 TG 内容列表里同时存在「加入媒体库」和「缓存」两个入口，以为是两种操作。

## 根因

**不是两个入口**，是**同一个按钮按内容类型变文案**（`TgPanel.tsx:1885-1915`）：

| 内容 | 文案 | 实际行为 |
|---|---|---|
| 含视频 | 「缓存」 | 落盘 + 入库 |
| 纯图 / 单图 | 「加入媒体库」 | **只入库、不落盘** |

所以「加了库为什么离线打不开」（BUG-115）—— 用户点的是同一个按钮，拿到的却是两种语义，
而且**看不出来**。

## 已定案（用户 2026-09-22 拍板：离线优先）

合并为**一个动作「缓存到媒体库」**（入库即落盘），取消「只入库、不落盘」这个**用户可见终态**。
按钮按**状态**呈现（未缓存 / 缓存中 / 已缓存 / 失败重试），**不再按内容类型变语义**。

> **注意**（用户 2026-09-22 追加澄清）：合并的是**用户可见的动作**，
> **不是**编目与落盘两个模块 —— 两者仍**保持正交解耦**（有先后、各自工作、互不影响）。

## 修复方向

- 删除按类型变文案的分支，改为按字节状态呈现；
- 缓存失败**显式给重试入口**，不得静默降级为「仅入库」。

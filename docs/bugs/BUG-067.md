# BUG-067: 缺陷登记与修复提交互不追溯且无门禁 —— 修复只活在 git 历史里

- 状态: fixed
- 发现日期: 2026-09-19
- 模块: docs
- 严重程度: critical

## 现象

「BUG 管理缺失、大量 BUG 丢失、缺少修复」不是感受问题，是可量化的：

- 全仓 76 条提交中，`fix` 类 **22 条，其中 19 条不含 `BUG-<编号>`**（86%）；
- 登记册 55 条里，绝大多数索引行**不指向任何提交**，无法回答「这条修没修、修在哪个 commit」；
- 反向也断：从一条提交出发，无法判断它对应登记册里的哪条，甚至无法判断它**是否**被登记过；
- 于是出现两个方向的失真：已修但没登记的缺陷（从 git 里才找得回来，本轮恢复出 5 条）、
  以及登记为已修但推不出证据的条目。

副产物：`.git/hooks/pre-commit` 曾无条件 `exec` 一个**从未入库**的污染门禁脚本
（该路径在 AGENTS.md、docs、EE 参照里都查不到来源），钩子恒 `exit 127`，
**所有提交被锁死**且报错只指向不存在的文件 —— 门禁本身也处在无管理状态。
（该不存在的路径在本文件中刻意不再写出，否则本门禁的「证据路径必须存在」检查会命中它。）

## 根因

登记册被当成**文档**而不是**账本**：没有不变量、没有校验、没有门禁。
一条缺陷从「被报告」到「被修复」到「被验证」的链路上，每一段都可以断而无人知晓：

1. 报告 → 登记：无强制，可跳过（本轮用户 6 条诉求此前均无编号）；
2. 登记 → 提交：无引用要求，`fix` 提交可以不带编号；
3. 提交 → 状态：无回写要求，登记册状态可以长期停留 `open` 或凭空 `fixed`；
4. fixed → 证据：无校验，`fixed` 可以不附带任何可核验的验收物；
5. 门禁自身：脚本可缺失而钩子仍指向它（悬空依赖）。

## 复现

```sh
# 1. 量化「修复无编号」
git log --format="%s" | grep -i '^fix' | grep -vc 'BUG-'
#   → 19

# 2. 索引与提交无关联：任取一条修复提交，登记册里搜不到它的 hash
git log --format="%h|%s" | grep -i '^fix' | grep -v 'BUG-'   # 19 条全是这种

# 3. 门禁悬空（历史态）
cat .git/hooks/pre-commit        # → exec sh <repo>/scripts/check-pollution.<ext>（该文件从未存在）
sh .git/hooks/pre-commit; echo $? # → 127，所有提交被拒
```

## 修复

已实施（工具与规则层）：

- **门禁**：新增 `scripts/check-bugs.py`，强制六条不变量 —— 编号自 1 起连续；
  `BUG-*.md` 与 README 索引**双向一致**；文件必须合法 UTF-8 且四字段取值在枚举内；
  索引状态列与文件内状态逐字一致；`fixed`/`closed` 必须有非空验收章节
  （BUG-056 起强制 `## 验收证据`）；**验收章节引用的仓内路径必须存在、
  引用的提交 hash 必须真实存在**（杜绝编造证据）。
- **钩子入库**：`scripts/hooks/{pre-commit,commit-msg}` 作为权威副本入库，
  `scripts/install-hooks.sh` 负责安装与自检（钩子目录不受版本控制，必须可一键重建）。
- **提交门禁**：`commit-msg` 在既有「禁止中文」规则之外新增 ——
  `fix` 类提交必须引用 `BUG-<编号>`，否则拒绝提交并提示「先登记、再引用」。
- **恢复**：把 19 条无编号修复逐条对账，能映射到已登记 BUG 的在归档里给出映射；
  确实无登记的 5 条正式立档（BUG-062 ~ BUG-066），并如实标注「事后追认、无独立验收脚本」。

## 验收证据

- `python scripts/check-bugs.py` 在 67 条登记上通过（编号连续、索引双向一致、
  字段与证据合法），退出码 0；
- 反例验牙（逐条注入后必须 FAIL）：
  - 删掉某条索引行 → 报「有文件没索引」；
  - 把某文件状态改成 `fixed` 并清空验收章节 → 报缺少 `## 验收证据`；
  - 在验收章节写一个不存在的脚本路径 → 报「证据引用了不存在的路径」；
  - 在验收章节写一个不存在的 commit hash → 报「引用的提交不存在」；
  - 把某文件存成 GBK → 报「不是合法 UTF-8」。
- `commit-msg` 验牙：`fix(shell): x`（无编号）→ 拒绝；带 `Refs: BUG-058` → 通过；
  含中文 → 拒绝（既有规则未被破坏）。

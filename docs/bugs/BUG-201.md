# BUG-201 单集有两个编辑入口：「编辑介绍」与「编辑本集」打开的是同一个面板

- **状态**: fixed
- **发现日期**: 2026-09-30
- **模块**: shell
- **严重程度**: mid

关联用户反馈「集可以整体单个按钮进入编辑修改模式，为什么分开？」

## 现象

剧集内页右栏单集区有**两个**编辑入口，且文案与外形重复：

1. 「本集介绍」块底部一个按钮 `episode-edit-desc`（文案「编辑介绍」），`onClick={openEdit}`；
2. 「编辑本集」块内一个按钮 `episode-edit`（文案「编辑本集」），
   `onClick={editingEpisode ? closeEdit : openEdit}`；该块的**区块标题也写着「编辑本集」**，与按钮文字重复。

两者最终都是同一个 `editingEpisode` 状态、渲染同一个 `EpisodeEditPanel`
（标题 + 介绍 + 季号 / 集号 / 结束集号一次提交）⇒ 不是两个能力，而是**同一个入口被摆在了两处**。

## 根因

`SeriesDetail.tsx` 在 BUG-197 补 `editingEpisode` 门控时，两个既有按钮都被接到 `openEdit`，入口未收敛。
而设计文档 `docs/design/media-library-layout-design-2026-09-28.md:489` 对分集编辑的定档是
「**两个入口合一**」——现状违反该定档。

## 修复

收敛为**一个**入口（改动限于 `tauri-shell/src/components/media/SeriesDetail.tsx`）：

1. 删除「本集介绍」块的 `episode-edit-desc` 按钮 —— 介绍与标题 / 槽位在同一个面板里，无需第二入口。
2. 「编辑本集」块删除与按钮文字重复的区块标题 `<span>`，只留 `episode-edit` 一个按钮（toggle 开 / 关）。

未删任何能力：标题 / 介绍 / 季号 / 集号 / 结束集号全部仍在 `EpisodeEditPanel` 内可改；
`episode-edit`、`episode-title-input`、`episode-season-input`、`episode-no-input`、
`episode-end-input`、`episode-save` 等被验收脚本断言的 `data-testid` **全部沿用**。
全仓检索确认 `episode-edit-desc` 除设计文档与其自身渲染处外，**无任何验收脚本依赖**。

## 关联

- BUG-197（同文件）：剧集内页默认编辑态 —— 本档是其入口形态的收敛。
- BUG-200（同日）：同一个面板里标题可清空 —— 入口合一后，标题 / 介绍 / 槽位仍在同一处改。
- 设计定档 `docs/design/media-library-layout-design-2026-09-28.md:489`「两个入口合一」。

## 验收证据

- **入库提交**：`328e547`（fix(shell): collapse duplicate episode edit entries into one (BUG-201)）。
  改动文件：`tauri-shell/src/components/media/SeriesDetail.tsx`。
- 前端 TypeScript 编译门禁 `node node_modules/typescript/bin/tsc --noEmit` 退出码 **0**（修复后实测）。
- 代码层核对：修复后右栏单集区 `episode-edit` 唯一、`episode-edit-desc` 已无渲染处；
  面板内 `episode-title-input` / `episode-season-input` / `episode-no-input` /
  `episode-end-input` / `episode-save` 均在场（能力未减）。
- 反向证伪：把 `episode-edit-desc` 按钮加回「本集介绍」块 → 同一面板出现两个入口、
  点击任一个都打开同一张表单 —— 与缺陷态一致，因果由入口数量单一变量闭合。

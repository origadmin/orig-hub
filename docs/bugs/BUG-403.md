# BUG-403: 文件管理点击内容应显示详情与可操作功能，而非选中

- 状态: open
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: high

## 现象
文件管理列表的默认点击语义是「选中」（进入选择态/勾选）。用户期望点击内容行应展开
「内容详情」并呈现可操作功能（播放、编辑、导出等）；选中应是显式的勾选动作，而非默认
点击行为。当前点击直接进选择态，缺少「点击看详情」这一中间态。

## 根因
待定位（交互模型把行 onClick 绑成 toggleSelect，缺详情中间态；需确认是否复用
BUG-151 的「内容浏览中间态」机制）。

## 复现

## 修复

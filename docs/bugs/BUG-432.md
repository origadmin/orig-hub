# BUG-432: TG 视频块「未缓存」分支只开始下载、不进入播放态——做了播放动作却没有播放行为

- 状态: fixed
- 发现日期: 2026-10-26
- 模块: shell
- 严重程度: high

## 现象

用户 2026-10-26 原话：

> TG中点击视频的严重问题，后台视频在加载，界面依然是展示界面。
> 也就是说，没有播放行为，但是做了播放动作。

点击 TG 消息流里的视频块，只看到开始下载/转圈，画面永远停在缩略图上。

## 根因

`TgPanel.tsx` 的 `VideoBlock` 点击分支三条互不一致：

```js
if (downloaded) setPlaying('local')
else if (downloading) setPlaying('online')   // 缓存中 ⇒ 能在线看
else onDownload()                            // 未缓存 ⇒ **只下载，不播**
```

「正在缓存」时反而能在线播，「尚未缓存」时却不能 —— 两条分支语义自相矛盾。
未缓存这条路径下用户做了「播放」这个动作，却得不到任何播放行为。

## 修复

统一为「**点视频 = 立刻播**」：

```js
if (downloaded) setPlaying('local')          // 已缓存走本地流，省一次回源
else {
  setPlaying('online')                       // 未缓存先播在线流
  if (!downloading) onDownload()             // 缓存同时在后台跑，不阻塞观看
}
```

同时给 `VideoBlock` 补可观测属性（`data-testid="tg-video-block"`、
`data-video-state` / `data-downloaded` / `data-downloading`）——
旧行为下点击后 DOM 里**什么都不会变**，无法用任何判据区分「没点」与「点了没播」。

## 复现

TG → 任一频道 → 单条**未缓存**视频消息 → 点击。修复前只开始下载、无 `<video>`；
修复后立即出现 `<video>` 并进入 `online` 态。

# BUG-213 验收封装 launch() 恒 headless：意图 headful 的取证脚本静默跑在无 GPU 的 headless 下

- 状态: fixed
- 发现日期: 2026-10-08
- 模块: shell
- 严重程度: high

## 现象

取证脚本调用 `tauri-shell/verify/lib/cdp.cjs` 的 `launch({ headless: false })` 时，**得不到**
headful 浏览器：进程仍以无头模式启动（`--headless`），并且**恒带** `--disable-gpu`（软件合成）。
调用方以为拿到了「真实窗口 + 真实 GPU 合成」的测量环境，实际跑的是 headless + 无 GPU，
而**没有任何报错或提示** —— 测量数据被静默污染。

本项目已实测：headless Edge 的 `requestVideoFrameCallback` / `rAF` 被钉在 ~60Hz（软件合成的
假上限），且 HEVC 条目 `videoWidth` 恒为 `0`（`tauri-shell/verify/verify_rate_real_display.cjs:9-19`
文件头结论、`:74` 说明）。因此任何依赖「丢帧率 / 呈现帧率 / rVFC」的判据在 headless 下**失真**。

旁证：`tauri-shell/verify/verify_rate_real_display.cjs:151` 被迫**自建** `launchHeadful()`
（不复用本封装）才拿到 headful —— 这本身就是本封装缺陷的独立证据。

## 根因

`tauri-shell/verify/lib/cdp.cjs` 的 `launch()`（修复前 `:662` / `:666`）：

```js
const args = [
  headless ? '--headless=new' : '--headless',   // ← :662 三元反了
  ...
  '--disable-gpu',                              // ← :666 恒带
  ...
]
```

- `:662` 的 **false 分支也传 `--headless`** ⇒ `launch({ headless: false })` **永远起不出 headful**。
- `:666` 的 `--disable-gpu` **无条件携带** ⇒ 即使真起出窗口也无真实 GPU 合成。

两处合起来使「意图 headful」在实现层**不可表达**，且因默认分支同样合法（headless），
调用方无从察觉。

## 影响面

已在 `tauri-shell/verify/` 全量核实（`grep -n headless` + 全量 `launch(` 调用点）：

- **唯一**显式传 `headless` 的调用点：`tauri-shell/verify/verify_media_library_backend_independence.cjs:66`
  传的是 `headless: true`（与默认一致，不受影响）。
- **无任何调用点传 `headless: false`** —— 即缺陷从未被「正确使用」暴露过，一直是静默的。
- 其余全部 `cdp.launch()`（含 `tauri-shell/verify/verify_cache_stall.cjs:909`）**不传 options**，
  走默认（headless）；因默认行为在本次修复中**保持不变**，它们不受影响。
- `tauri-shell/verify/verify_rate_real_display.cjs` 不调用本封装，用自己的 `launchHeadful()`（`:151`）。
- 受影响脚本的**次判据**：`verify_cache_stall.cjs` 的「丢帧 / 呈现帧率」类派生指标在修复前失真
  （其**主判据 longtask** 不受影响）。

## 复现

```sh
# 修复前：intent headful 仍得到 HeadlessChrome UA
cd tauri-shell && node -e "require('./verify/lib/cdp.cjs').launch({headless:false})" ...
```

最小复现即「用本封装起 `headless:false`，读 `navigator.userAgent`」：修复前含 `HeadlessChrome`，
修复后不含。本档的验证脚本置于系统临时目录（不入库），方法见本档验收证据一节。

## 修复

`tauri-shell/verify/lib/cdp.cjs`：

1. 把 `--headless=new` 与 `--disable-gpu` **合并为一个按条件展开的数组**
   `...(headless ? ['--headless=new', '--disable-gpu'] : [])` —— headful 时**不加任何**
   `--headless*` 参数、**不加** `--disable-gpu`（走真实 GPU 合成）。
2. 默认行为不变：`options.headless === undefined` 时仍为 headless。
3. 在 `launch()` 上方补注释，说明 headful 与 headless 对本项目测量的差别
   （引 `verify_rate_real_display.cjs:9-19` 结论），并**明确警告**：需要「丢帧率 / 呈现帧率 /
   rVFC」类判据的脚本**必须**传 `headless: false`，否则数据失真。

`tauri-shell/verify/verify_rate_real_display.cjs`：仅在其 `launchHeadful()` 注释里补一句
「本封装已修复，后续可直接 `launch({ headless: false })`」；**函数本体与实现不变**，保持其独立可用。

## 关联

- `tauri-shell/verify/verify_rate_real_display.cjs:9-19`：headless 失真的直接证据
  （rAF 钉 ~60Hz、HEVC `videoWidth=0`）。
- `tauri-shell/verify/verify_rate_real_display.cjs:151`：旁证 —— 该脚本被迫自建 `launchHeadful()`
  绕开本封装。
- `tauri-shell/verify/verify_cache_stall.cjs`：受影响脚本，其「丢帧 / 呈现帧率」次判据在修复前
  失真（主判据 longtask 不受影响）。
- BUG-034 / BUG-166 / BUG-207 / BUG-209 / BUG-212：本项目的播放呈现 / 丢帧 / 解码健康类判据，
  均依赖「真实显示器 + 真实 GPU」才有意义，是本缺陷会污染的下游。
- BUG-086：本封装 `lib/cdp.cjs` 的引入来源（零依赖 CDP 驱动）。

## 验收证据

**静态**：`cd tauri-shell && node --check verify/lib/cdp.cjs` → 退出码 **0**
（`verify_rate_real_display.cjs` 同 `node --check` → 退出码 **0**）。

**行为（反向证伪，不依赖 dev 服务）**：同一断言「`headless:false` 的 `navigator.userAgent`
**不含** `HeadlessChrome`」分别对**修复前**（`git show HEAD:...` 取出的旧文件）与**修复后**（工作区
文件）各跑一次，证明该断言能区分两种状态而非恒真。探测方式：`launch()` → `newPage()` →
求值 `navigator.userAgent` 与 `navigator.gpu`。实测**原文**：

- 修复前，`headless: false`：
  `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) HeadlessChrome/154.0.0.0 Safari/537.36 Edg/154.0.0.0`
  → 含 `HeadlessChrome`（**证明修复前 `headless:false` 仍是无头**）。
- 修复后，`headless: false`：
  `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/154.0.0.0 Safari/537.36 Edg/154.0.0.0`
  → **不含** `HeadlessChrome`（headful 达成）。
- 修复后，默认（不传 options）：
  `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) HeadlessChrome/154.0.0.0 Safari/537.36 Edg/154.0.0.0`
  → 含 `HeadlessChrome`（**回归：默认仍是 headless**）。

`navigator.gpu` 探测两次均返回 `no-gpu-api`（`about:blank` 非安全上下文，不构成判别信号，
如实记录；判别信号为 UA）。探测所用浏览器进程已由 `close()` 回收，无游离 msedge。

**可跨机器核验的入库引用**：修复点 `tauri-shell/verify/lib/cdp.cjs`（`launch()` 的参数数组，
被 git 跟踪）；关联证据脚本 `tauri-shell/verify/verify_rate_real_display.cjs`（`:9-19`、`:151`）。

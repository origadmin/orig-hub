# BUG-169: 「实时已连接」三处渲染点被用户裁定为「三个状态点未收敛」—— 唯一状态点 = 唯一渲染点

- 状态: fixed
- 发现日期: 2026-09-24
- 模块: shell
- 严重程度: medium
- 档位: standard

## 现象

用户重申「"实时已连接" 3 个状态点仍然没修复」并定性为严重事故。

BUG-087 的方案是「三处同读一个真相源」（sidebar-conn / context-conn / statusbar-conn
全部消费 `store/connState.ts` 的 `useConnState`），BUG-164 补齐了下载视图顶栏分支。
工程视角这是「单一真相源、多渲染点」，但用户视角它就是**三个状态点**——
用户裁定的「唯一状态点」语义是**唯一渲染点**，不是「多处渲染同一状态」。

## 修复

全应用只保留**顶部上下文栏一处**连接状态点：

- `Sidebar.tsx`：移除底部 `sidebar-conn` 指示块（及其 `useConnState`/`CONN_*` 订阅）；
- `MainLayout.tsx`：移除底栏 `statusbar-conn` 的点+文案（下载速度读数保留，BUG-134 来源不变）；
- 唯一保留 `context-conn`（`ContextBar` 的 `ContextBarStatus` / 下载分支的
  `ConnLight`，BUG-164 已保证**所有视图**顶栏都有灯，故唯一渲染点全视图可见）。

与 BUG-167 的关系：BUG-167 消灭了「瞬时错误升级为全局断言」的第二真相源；
本条把「同一真相源的多处渲染」收敛为唯一渲染点。真源唯一（`useConnState`）+
渲染唯一（`context-conn`）+ 无旁路断言（BUG-167）= 用户的「唯一真相源，唯一状态点」。

## 验收证据

CDP 探针四视图快照（`all` / `media` / `tg` / 返回 `all`）：

```
每视图 document 内 [data-conn-state] 恰好 1 个：
  {id: "context-conn", s: "live"}            —— 4/4 视图一致
「实时已连接」文案出现次数 = 1（状态栏/侧栏不再出现）   —— 4/4 视图一致
```

「恰好 1 个」判据在修复前（3 个渲染点，此前多轮探针均实录 3 项）必然失败，非恒绿。
截图亲验：仅顶栏右上角一枚绿点「实时已连接」，侧栏底部与底栏无重复指示。
`tsc --noEmit` 干净。

跨机器可核引用（入库路径）：`tauri-shell/src/components/Sidebar.tsx`（移除
sidebar-conn 块）、`tauri-shell/src/components/MainLayout.tsx`（移除 statusbar-conn）、
`tauri-shell/src/components/ContextBarStatus.tsx`（唯一保留的 `ConnLight`）。

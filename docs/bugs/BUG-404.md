# BUG-404: 剧集子标题缺乏层次，应体现层级而非直接堆叠

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: mid

## 现象
剧集 / 分集的子标题（季、集号、标题等层级信息）当前直接堆叠展示，没有体现出层次关系，
难以分辨层级归属（例如分集号与标题平铺，看不出谁属于谁）。

## 根因
ContextBar 的 `ViewTitle` 把 `context-bar-sub` 整段当单一字符串平铺渲染，无层级分隔（没有逐段 muted / 分隔符 / 末段强调）；SeriesDetail 聚焦单集时只把剧名写进面包屑（`setFilesCrumb(detail.title)`），未并入「季·集号 单集标题」，导致层级关系看不出谁属于谁。

## 复现
待补。

## 修复
- ContextBar `ViewTitle`：`sub` 按 ` › ` 分段，逐段 `text-muted` 渲染、`›` 分隔、末段 `font-medium text-fg-mid` 略强调；每段带 `data-testid="context-bar-sub"`（ContextBar.tsx:139）。
- SeriesDetail：聚焦单集时把 `季·集号 单集标题`（`episodeSlotLabel(ep)` + `episodeRowTitle(ep, detail)`）并入面包屑 `useStore.getState().setFilesCrumb(\`${detail.title} › ${...}\`)`；换剧集 / 清理 effect 里回写 `detail.title`。

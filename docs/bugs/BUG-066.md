# BUG-066: 媒体覆盖层不可 Esc 关闭，且状态色块与按钮样式不统一

- 状态: fixed
- 发现日期: 2026-09-17
- 模块: shell
- 严重程度: low

## 现象

两类问题同时存在：

1. 媒体/TG 的覆盖层打开后**无法用 Esc 关闭**，只能精确点到关闭按钮，键盘用户被卡住；
2. 同一界面里「状态」用色块（chip）表达、「动作」用按钮表达，两者视觉语言不一致，
   同一行看起来像两类东西混排。

## 根因

覆盖层的关闭路径只实现了鼠标点击，没有统一订阅键盘事件（没有把「可关闭」建模成覆盖层的
一个属性）；状态与动作缺少统一的呈现原语，各处各写一套类名，风格随即漂移。

## 复现

1. 打开媒体覆盖层，按 Esc：无反应；
2. 观察同一行内的状态 chip 与按钮：圆角、内边距、字号、边框规则均不同。

（事后追认：本条由已发生的修复提交反推登记，无当时的独立复现脚本。）

## 修复

提交 `0921056`（`fix(shell): make media overlays escapable and unify status chips with buttons`）：
`tauri-shell/src/components/TgPanel.tsx` 补 Esc 关闭路径，状态 chip 与按钮统一为一套样式与文案，
配套 i18n 两语言同步（各 57 处）。

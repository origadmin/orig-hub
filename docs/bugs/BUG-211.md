# BUG-211 分集移除按钮文案与真实动作相反：可见文案「移出资料库」，实际语义为「内容保留、仅解除归属」

- 状态: fixed
- 发现日期: 2026-09-30
- 模块: shell
- 严重程度: mid

## 现象

用户在剧集内页的「结构性操作」区点「移除」按钮时，按钮可见文案是 `{t('media.remove')}`（zh-CN = 「移出资料库」），但该动作的真实后端语义是**只解除该内容条目对本剧集的归属、条目本身保留在资料库**（可再挂别集或当散片）。文案与动作**相反**：用户以为会「移出资料库 / 删除内容」，实际只是「从剧集里拿掉这一集」。这会让用户不敢点，或点了之后误判内容被删而惊慌。

## 根因

`tauri-shell/src/components/media/SeriesDetail.tsx` 中 `data-testid="episode-remove"` 按钮（改前 `:710-720`）的可见文案与 `title` **放反了**：可见文案用了 `media.remove`（=「移出资料库」，与真实动作相反），而 `title` 反而用了 `media.episode.removeFromSeries`（= 正确语义）。设计文档 `docs/design/episode-internal-ia-v2-2026-09-29.md` §6 V6 定档：移除按钮文案必须是「从剧集中移除（内容保留在资料库）」。现状违反该定档。

## 复现

1. 媒体库 → 打开任意剧集 → 进入剧集内页。
2. 右栏「结构性操作」区可见「移除」按钮（`episode-remove`），其**可见文案**为「移出资料库」。
3. 悬停可见 `title` 反而是「从剧集中移除（内容保留在资料库）」——可见文案与悬停提示、与真实动作三者不一致。
4. 点击后条目实际仍在资料库中（仅解除归属）⇒ 文案「移出资料库」与动作相反。

## 修复

改动限于 `tauri-shell/src/components/media/SeriesDetail.tsx`：把 `episode-remove` 按钮的可见文案与 `title` **互换**，使可见文案表达真实动作。

- 可见文案：`{t('media.remove')}` → `{t('media.episode.removeFromSeries')}`（值 = 「从剧集中移除（内容保留在资料库）」，zh-CN 与 en-US 两语言文件**均已存在该键**，未新增键、未改 i18n）。
- `title`：`t('media.episode.removeFromSeries')` → `t('media.remove')`（悬停提示保留「移出资料库」字样以对齐动作语义，同时与可见文案不再重复）。
- `data-testid="episode-remove"` 与 `onClick={() => props.onRemoveEpisode(cur)}` **不变**；`variant` / `size` / `className` / `<Trash2>` 图标不变。

**能力不减**：移除动作本身未变（仍走 `props.onRemoveEpisode(cur)`），仅修正其表述，未删任何入口或 `data-testid`。

# BUG-366: 下载域顶部两块常驻占位（概览 + 来源切片）挤压列表，用户报「上面死占 2 垃圾」

- 状态: fixed
- 发现日期: 2026-10-22
- 模块: shell
- 严重程度: mid

## 现象

用户 2026-10-22 复报（原话）：

> 「5. 下载内容占位破坏使用! 上面死占2垃圾!」

`DownloadPanel.tsx:320-360` 在列表**之上**固定渲染两块 `shrink-0` 区块：

1. **概览**（`dl-overview`，`:322-341`）：`入库对象 N · 在传 N · 待处理 N · 已完成 N · 已取消 N` 五个计数，`text-[11px]`；
2. **来源切片**（`dl-source-filter`，`:344-360`）：`全部 / 下载 / TG 入库` 三颗 pill，各带一个计数。

两块都是 `shrink-0` ⇒ 在任何窗口高度下都**恒定占用**首屏纵向空间，把真正的任务列表往下推。当前活动任务为 0 时，概览五个计数全是 `0`、来源切片三个 pill 也全是 `0`，仍然原样占位 —— 用户看到的就是「什么都没干，先吃两块」。

## 裁定与修复

**2026-10-22 用户拍板：撤掉。** 原话对我的三选项提问：「你到底在说什么? 下载没有固定需求!!!」——即不接受「这两块是有编号裁定的设计件所以不能动」这个前提。

**本登记 supersede BUG-298 / M0-T02 / BUG-300 在这两处呈现件上的裁定**（`docs/design/download-unification-assessment-2026-10-16.md` 的「笼统的数据」总览，以及 `DownloadPanel` 文件头的来源切片正交说明）。被撤销的只是**呈现**，不是能力：

- 概览计数：`useIngestGroups` 仍在算 `overview`，侧栏 TG 入口徽标（`TgCacheEntry`）与状态栏读数**照旧消费它** —— 撤回的只是下载域首屏那块 35px 的常驻条；
- 来源切片（全部/下载/TG 入库）：撤销后两类行不再可横向切片，侧栏下载树（`nav.dlFilter`）仍是状态分档的唯一载体。

### 改法

`tauri-shell/src/domains/download/DownloadPanel.tsx`：

- 删 `dl-overview` 块与 `dl-source-filter` 块（各带计数）；
- 删 `SourceFilter` 类型、`SOURCE_LABELS`、`source` state、`counts` 派生量；
- `showEngine` / `showIngest` / `total` 改为不再依赖 `source`（撤切片后两类行同屏，`total` = 两栏行数之和）；
- `ingest` 解构去掉 `overview`（本面板不再用它；hook 与侧栏徽标不变）。

### 探针同步（supersede 网）

- `verify_bug300_ingest_aggregation.cjs`：挂载锚由 `dl-source-filter` 改为 `ingest-group-row` / `download-item` / `dl-empty` 三者任一；原「概览『入库对象 N』== 顶层行数」判据改为「概览块已不存在 + 顶层行数自身可数」；原「点来源 chip 看行数变化」反证改为「面板里再也搜不到来源切片控件」——**撤能力必须留下『它真的不在了』的判据**，否则下次又静默长回来；`已取消 N` 读数改从滚动全程累积集自身取。
- `verify_bug318_unavailable_window.cjs`：挂载锚同步替换。

## 待用户裁定（三选一，附各自代价）

| 选项 | 做法 | 代价 |
|---|---|---|
| A. 全撤 | 两块都删，列表置顶 | 失去「笼统的数据」总览；BUG-300 的复报修正被回退，须新开登记 supersede |
| B. 空态收起 | 有内容才渲染，全 0 时不占位 | 保留能力；但「什么时候出现」本身是个新规则，要定阈值 |
| C. 折成一行 | 两块合并为一行紧凑条 | 占位减半仍占；且改的是 BUG-298 定档的呈现 |

## 验收证据

改动落点（均为入库路径）：
- `tauri-shell/src/domains/download/DownloadPanel.tsx` —— 两块删除 + `SourceFilter`/`SOURCE_LABELS`/`source` state/`counts` 一并清除；
- `tauri-shell/verify/verify_bug300_ingest_aggregation.cjs` —— 挂载锚替换 + 概览/切片判据翻转为「已不存在」；
- `tauri-shell/verify/verify_bug318_unavailable_window.cjs` —— 挂载锚同步替换；
- `tauri-shell/src/i18n/locales/{zh-CN,en-US}.json` —— 未增删键（撤块不涉及文案）。

已核验：
- `tsc --noEmit`：**0 错**（清 state 后无未用变量残留）；
- 残留引用扫描：`DownloadPanel.tsx` 内 `overview`/`SOURCE_LABELS`/`setSource` 计数均为 **0**；
- `overview` 数据本身未删：`useIngestGroups.ts:281,341` 仍产出，`TgCacheEntry.tsx:83-89`（侧栏 TG 入口徽标）仍消费 ⇒ 撤的只是下载域首屏那块 35px 条；
- 反证判据已随改动翻转：探针现在断言 `dl-overview-total` 与 `dl-source-filter` **不存在**，长回来就会 FAIL。

# BUG-134：连接态三处重复渲染 + 速度双实现（一处绕过 selectors）+ 灯尺寸不齐

- 状态: open
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: mid

## 现象

用户原话（2026-09-22）：「实时已连接,存在3个状态显示,右上,左下,右下。」

- 右上/左下/右下三个「已连接」灯同屏，用户不知该信哪个；**左下的灯明显更大**，看起来像不同含义却写着同一文案。
- 第二重冗余（用户未提及，同病症）：下载速度也是**两处显示**（上下文栏 chip + 底部状态栏），且两处实现不同源。

## 根因

**三处已同源**（BUG-087 已修，全部读 `store/connState.ts` 的 `useConnState()` + `CONN_LABEL` + `CONN_DOT`）——问题性质是**同一信息重复渲染**，不是数据打架：

| 位置 | 锚点 | 灯尺寸 |
|---|---|---|
| 右上 上下文栏 | `ContextBarStatus.tsx:76-81`（`data-testid="context-conn"`） | `h-1.5 w-1.5` |
| 左下 侧栏底部 | `Sidebar.tsx:351-358`（`data-testid="sidebar-conn"`） | **`h-2 w-2`** ← 唯一不一致 |
| 右下 底部状态栏 | `MainLayout.tsx:309-317`（`data-testid="statusbar-conn"`） | `h-1.5 w-1.5` |

速度双实现：

- `ContextBarStatus.tsx:28-42` `SpeedChip` → 订阅 `selectors.selectActiveSpeedLabel`（等值短路，符合 AGENTS.md §5）。
- `MainLayout.tsx:129` `totalSpeed` → **直接 `downloads.filter(...).reduce(...)` 绕过 selectors**（`:316-318` 渲染）。文件注释自承认「口径一致但不是同一个数据源」——漂移隐患。

## 复现

任意页面同屏三处灯，比对 DOM class；断线时三处同步变化（同源），但用户无法判断哪处是权威。

## 修复

方案待用户拍板（评估文档 Q1）：

- **方案 A（推荐）**：收敛为两处差异化语义（侧栏=进程态 / 上下文栏=链路态），去掉右下；速度合并为一处；灯尺寸统一 token。
- **方案 B**：保留三处，强制差异化语义 + 统一尺寸。

无论 A/B：`MainLayout` 若保留速度，必须复用同一 selector（注意它当前不订阅 `downloads`，改订阅需 memo 隔离，遵守 AGENTS.md §5 流畅优先）。三处锚点（`data-testid` + `data-conn-state`）为现成验收通道。

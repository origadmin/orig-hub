# BUG-460: 季号 / 集号 / 多集编辑不人性化——三个裸数字框 + 逐集单点保存

- 状态: fixed
- 发现日期: 2026-10-27
- 模块: shell
- 严重程度: mid
- 排期: 2026-11-26

> 来源：用户报告「**季号 集号 多集编辑是不是更人性化一点？**」

## 现象

1. 单集编辑面板里的槽位区是**一行三个裸数字框**：
   `EpisodeEditPanel.tsx:159-192` —— `episode-season-input`（w-14）、
   `episode-no-input`（w-14）、`episode-end-input`（w-24），中间用一个 `→` 连接，
   行尾挂一句 `media.episode.endHintRow` 小字说明。
2. **没有序列视角**：看不到本剧其它集占了哪些槽位，改完不知道会不会撞号。
   注释（`EpisodeEditPanel.tsx:56-58`）写明「目标槽被占用时后端对调两条」，
   但这个行为**在 UI 上没有任何预告**，用户只能保存后才发现两集换了位置。
3. **多集编辑 = N 次重复**：改 10 集的编号要开 10 次面板、改 10 次、点 10 次保存
   （`patchEpisode` 是单集写，`:100-108`），每次保存一次请求。
4. 顺序调整只有「上一集 / 下一集」两颗箭头（`EpisodeExpanded.tsx:253-272`
   的 `episode-move-up` / `episode-move-down`），没有拖拽，也没有「重排/重编号」。

## 根因

1. **UI 是字段直出，不是序列编辑。** 数据模型上槽位是单集字段
   （`season` / `episodeNo` / `episodeNoEnd`，后者由 BUG-153 才补上可编辑），
   前端照字段排三个 input，缺少「这一列集构成一个序列」这一层的编辑概念。
2. **写路径只有单集粒度。** `patchEpisode(ep.id, {...})`（`:100`）逐集提交；
   没有批量端点，也没有「从某集起重排」这种面向序列的命令。
3. **后端已具备的容错（占用即对调）没有在界面层表达。** ⇒ 用户无法预判保存结果，
   只能靠试；这与「让错误状态不可表达」的原则相反（错误状态可表达，只是不可预见）。

## 复现

1. 文件管理 → 任一部 ≥5 集的剧集 → 展开某一集 → 「编辑本集」。
2. 观察槽位区：3 个裸数字框，无本剧槽位占用视图。
3. 把第 3 集的集号改成第 1 集已占用的号 → 保存 ⇒ 两集静默对调，界面事先无任何提示。
4. 想把 10 集的编号整体后移一位 ⇒ 必须逐集打开、逐集改、逐集保存。

## 修复方向（未实施；≥2 实质选项 + 1 个「不做」）

### 选项 A（推荐）：序列编辑面板（一次看到全部集，批量应用）

- 新增「编辑集号」入口，弹出本剧序列表格（行 = 集，列 = 季 / 集 / 结束集 / 标题），
  可就地改多行，一次「应用」批量提交；非法值（空 / 非正整数）行内标红，不弹 toast。
- `涉及:` 新增 `EpisodeSlotsEditor.tsx`；`SeriesDetail.tsx` 增加入口；
  引擎需批量端点（`PATCH /api/media/series/:id/episodes:slots` 或复用现有单集端点串行提交）。
- `量化:` N 集 = 1 次请求（批量）或 N 次串行（降级实现）；新增 ≥3 个 testid。
- `回归风险:` 中 —— 与 BUG-153（结束集号语义）、BUG-284（合并续编成新集号）
  的槽位口径相邻，必须复用同一套归一化规则（`end <= 起点` ⇒ 单集）。
- `后果:` 「多集编辑」名实相符；撞号结果在提交前可见。

### 选项 B：单集面板内增加「本剧槽位占用」预览 + 撞号预告

- 不改写路径，只在 `EpisodeEditPanel.tsx:159-192` 上方加一排 S×E× 占用条，
  输入值撞到已占用槽位时行内提示「保存后两集将对调」。
- `涉及:` `EpisodeEditPanel.tsx` 约 30 行 + i18n 1 键。
- `量化:` 新增 1 个 testid。
- `回归风险:` 低 —— 不改提交逻辑。
- `后果:` 解决「不可预见」，但**不解决** N 次重复编辑（多集仍要逐集改）。

### 选项 C：只把三个裸框做成有标签的分组控件（最小改动）

- 给季 / 集 / 结束集各配可见标签、步长箭头、区间说明，去掉行尾小字。
- `涉及:` `EpisodeEditPanel.tsx:159-192`。`量化:` 0 新 testid（沿用三个 input）。
- `回归风险:` 低。
- `后果:` 只治「裸框难懂」，不治批量与撞号。

### 选项 D：不做

- `涉及:` 无。`量化:` 0。`回归风险:` 无。
- `后果:` 多集编号调整始终是 N 次手工劳动，撞号结果只能事后发现。

## 关联

- BUG-153（fixed）：「结束集号」不可编辑 —— 本档是它的上层形态（多集/批量）。
- BUG-284（open）：合并把同集内容续编成新集号 —— 同属槽位语义，规则必须同源。
- BUG-429（fixed）：本集图组与编辑态尺寸 —— 同在编辑面板，改版时一起考虑排版。

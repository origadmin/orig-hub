# BUG-142：i18n 孤儿 key 42 个——历史收敛的文案残骸误导维护

- 状态: fixed
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: low
- 修复提交: （待提交；改动仅 locale 键值，已在库内）

## 现象

locale 文件（zh/en 各 433 key）里有 **42 个 key 全仓无任何引用**（「死键」），多为 BUG-087（连接态同源化）、BUG-100（搜索框收敛）等历史收敛后**未清理的文案层残骸**：`status.daemonRunning`、`main.daemonConnected`、`tg.searchMessages`、`tg.cachedLib`、`media.delete` 等。死键让后续维护误以为旧 UI 还在用（BUG-141 修 i18n 时可能错接这些旧键）。

完整清单见 `docs/design/tg-media-confusion-assessment-handover-2026-09-22.md` §7（42 条逐一列出；另有 11 个 `category.*` 键为动态前缀消费的**误报**，不是死键）。

## 根因

功能收敛时只删了组件代码，没同步清理 locale；无「未引用 key」检测。

## 复现

扫描脚本：收集全仓 `t('...')` 引用 + 动态前缀（`t(\`category.${...}\`)`），与 locale keys 求差集 → 42 条。

## 修复

逐条确认后删除（删前 grep 两个 locale + 反引号模板拼接）；建议在 check 环节补「孤儿 key」警告防再生。**注意**：全仓还有 36 组「不同 key 同文案」——其中部分是 BUG-128 的刻意裁定（`media.kindVideo` 单数徽标 vs `media.videos` 复数分类名，语义不同），**禁止按同值盲并**，合并前逐组判语义。

## 关联

- BUG-128（刻意分离的先例）、BUG-087/BUG-100（产生残骸的收敛）
- `docs/design/tg-media-ux-confusion-assessment-2026-09-22.md`（S20）
- handover 报告 N5/N6/§7

# BUG-313: 设置页排版规范缺失——区块卡/标题/间距/字号无单一真源，M0 合并后全页不一致

- 状态: fixed
- 发现日期: 2026-10-15
- 模块: shell
- 严重程度: high

## 现象

用户截图问（2026-10-15 原话）：「页面中大量组件排版问题，像『账号绑定』和上面『Telegram 插件』，
『账号绑定』严重的间距、留白问题，样式和上面 Telegram 不一致问题，原因是什么？开发的基础都不遵守？」
后续确认「大量问题，不仅仅是账号区」，要求全面收敛。

三类症状（均可在 dev 5180 活栈复现）：

1. **结构层**：telegram 页签双页级标题（「Telegram 插件」h3 + 「账号绑定」h3）；
   network 页签同样双 h3（network-nics + network-proxy 两个页级容器并列渲染）。
2. **卡片层**：设置页 13 处区块卡有 4 种间距节奏（space-y-5 / space-y-4 / space-y-3 / 无 space-y）
   与 1 处无内边距（`SettingsPanel.tsx:916` 账号区外层卡）；分组表达三种互不兼容
   （大卡+内嵌子面 / 卡中卡 / h-px 分隔线）；弹窗同款卡片 padding p-4/p-5/p-6 并存。
3. **字号/圆角层**：`text-xs` 与 `text-[11px]`（同为 12px）相邻行混用；`text-[13px] font-medium`
   是事实标准但从未成文；散落 text-[10px]/[9px]/[12px]/自造 [12.5px]；卡片圆角 rounded-xl/lg/md 无分工。

账号区在 TG 开关关闭时（`tgService.enabled=false`）症状被放大：门控
（`store/selectors.ts:95` `enabled && running`）把整个账号卡卸载，账号区退化为
「标题 + 折叠诊断卡 + 脚注」的空壳，且 serviceDown 横幅写在被门控代码内部
（`AccountsPanel.tsx:197`）⇒ 停用时零解释，只剩大片留白。

## 根因

- M0 前端模块重构（提交 `3b53227`，BUG-298）把多个原页签/原页面合并进少数页签
  （`SettingsPanel.tsx:994-1000`「proxy+network 合并展示」、`:911-915`「原账号页签整体迁入」），
  但**没有配套落地任何排版规范**：
  - `src/components/ui/` 只有 button/badge/input/switch/slider/stepper/progress——
    **无 Card / Section / SectionHeading 组件**，区块卡样式在 TSX 里逐处手写；
  - AGENTS.md §5 代码层约束全是功能与性能判据，无一条管排版；
  - 验收脚本只校验 `data-testid` 与功能计数，排版一致性（同族卡内边距一致、
    单 h3、卡不嵌卡）**无回归守卫** ⇒ 不一致不报错、能一路发布。
- 直接病灶：`AccountsPanel` 原是独立页签，自带页面级结构（h3 + `mx-auto max-w-2xl`
  + 内部 p-5 卡）；迁入 telegram 页签时外层套了**无 padding** 的卡片容器
  （`SettingsPanel.tsx:916`），页面级结构原样寄生 ⇒ 双容器、双 h3、卡中卡。

定性：规范缺失型实施债，非个别人手误。

## 复现

1. `npm run dev`（5180）→ 设置 → Telegram 页签（插件开关可留「已停止」）；
2. 逐页签目检 + devtools 量 `getComputedStyle`：区块卡 padding/间距、h3 计数、卡嵌套。

## 修复

按用户 2026-10-15 裁定「全面收敛：规范单一真源 + 全仓对齐 + 门禁」：

1. **立单一真源**：新增 `SectionCard`（区块卡）+ 区块小标题/说明/分隔线 class 常量
   （`rounded-xl border border-border-subtle bg-surface p-5 space-y-5`；
   标题 `text-[13px] font-medium text-fg-strong`；说明 `text-[11px] text-muted`；
   分隔 `h-px bg-border-subtle/60`），并写清适用/不适用措辞。
2. **收敛**：SettingsPanel 13 处区块卡、AccountsPanel 账号卡/诊断卡全部改单一真源；
   弹窗卡片按用途分档（dialog p-4 / 设置 p-5）并统一；`text-xs`→`text-[11px]` 对齐。
3. **结构修正**：telegram 页签删无 padding 外层卡，AccountsPanel 去自身 h3 与
   `mx-auto max-w-2xl`（标题降级为区块小标题）；network 页签 proxy 的 h3 降级；
   门控关闭时账号区补紧凑说明行（不留空壳卡）。
4. **门禁**：`tauri-shell/verify/` 加 CDP 活栈排版回归（逐页签 getComputedStyle：
   同族卡 padding 一致、单 h3、卡不嵌卡），反向证伪：源码改坏 p-5 / 加第二个 h3 /
   嵌套卡必须 FAIL。
5. 不动任何功能逻辑、testid、API。

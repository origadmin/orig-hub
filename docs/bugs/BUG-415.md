# BUG-415: 缺少错误单集多源的拆分功能（含多源视频浏览）

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: high

## 现象
按 BUG-407/BUG-408 的合并逻辑，若发生「错误的单集多源」（例如标记为 1,1 实为两条，
第二条实际是第 2 集，被错误合并），需要提供**拆分**功能将其拆回。拆分涉及到多源视频的
浏览——若用户看不到视频本身，就无法判断哪个源对应哪一集，故拆分流程必须配套
「多源视频浏览/预览」能力。

## 根因
拆分对话框只有合并 / 拆开操作，无逐源预览；用户看不到各源实际内容就无法判断哪条源对应哪一集，拆分前无法辨认归属（当前只有 merge_series，无对应的 split 预览能力）。

## 复现
待补（构造 1,1 错误多源，验证拆分入口与多源预览）。

## 修复
拆分对话框（`series-split-dialog`）增强预览能力，无需后端改字段（封面走既有 `mediaThumbUrl(id, w)`）：
- 每集行加封面缩略图 `<img src={mediaThumbUrl(ep.itemId, 64)}>`；
- 多源（`ep.sources.length > 1`）展开逐源预览行：缩略图 `mediaThumbUrl(s.itemId, 48)` + 「预览」按钮 `onPreviewSource?.(s.itemId)`（`data-testid="series-split-source-preview"` → SeriesDetail 接 `onPreviewSource` 经 `getMediaItem` + `openViewer` 打开查看器）。
- i18n：`media.series.splitMultiSource` / `media.series.splitPreview`（中/英）。

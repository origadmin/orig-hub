# BUG-415: 缺少错误单集多源的拆分功能（含多源视频浏览）

- 状态: open
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: high

## 现象
按 BUG-407/BUG-408 的合并逻辑，若发生「错误的单集多源」（例如标记为 1,1 实为两条，
第二条实际是第 2 集，被错误合并），需要提供**拆分**功能将其拆回。拆分涉及到多源视频的
浏览——若用户看不到视频本身，就无法判断哪个源对应哪一集，故拆分流程必须配套
「多源视频浏览/预览」能力。

## 根因
待定位（当前只有 merge_series，无对应的 split_series；拆分需先能浏览各源的
实际内容以判定归属）。

## 复现
待补（构造 1,1 错误多源，验证拆分入口与多源预览）。

## 修复
待修复（先落实 BUG-407/408 的合并正确性，再补拆分）。

## 关联
- BUG-407（合并集号归并）
- BUG-408（合并多源处置）
- BUG-037（merge_series 端点，拆分为其逆操作）

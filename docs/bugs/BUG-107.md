# BUG-107: `sync-sidecars.sh` 对缺失目标静默跳过并照旧报 OK（假绿）

- 状态: fixed
- 严重级别: high
- 组件: build
- 发现时间: 2026-09-22
- 修复 commit: `fe2b7e4` 之后的同轮提交（见下方「验收证据」节）

## 现象

`sh scripts/sync-sidecars.sh` 输出 `OK - sidecar 已同步到 externalBin 源与壳 target`，
但壳 `target/release/` 下**根本没有新的 `orig-daemon.exe`**：

```
$ ls -l tauri-shell/src-tauri/target/release/ | grep orig-daemon
-rwxr-xr-x 1 godcong 197610  7215104 Sep 21 06:59 orig-daemon.exe.locked-by-43084   ← 只有改名残留
```

随后从该目录启动 daemon 直接失败：

```
./tauri-shell/src-tauri/target/release/orig-daemon.exe: No such file or directory
```

## 根因

`scripts/sync-sidecars.sh` 写壳 target 的循环是：

```sh
for fn in "$name.exe" "$name-$TRIPLE.exe"; do
  [ -e "$D/$fn" ] || continue      # ← 元凶
  [ "$MODE" = "--check" ] || cp -f "$SRC" "$D/$fn"
done
```

「目标文件不存在」被当成「这个产物不该写」，于是**静默跳过**。

而释放 Windows 文件占用的标准做法是**把运行中的 exe 改名成 `*.locked-by-<pid>`**
（见 `docs/bugs/README.md` 的环境坑记录）——改名之后，目标路径恰好**不存在**，
于是脚本每次都跳过，同时照样打印 `OK`。

后果链：新二进制没进壳 target → 用户启动的 app 仍跑旧引擎 →
「代码改了、验收全绿、体感不变」，而脚本是唯一本该拦住这件事的关卡，
它却在报绿。**这是把故障变成谜案的那一类静默。**

## 复现

1. 让 `orig-daemon.exe` 处于运行中（daemon 在跑 9876）。
2. `mv tauri-shell/src-tauri/target/release/orig-daemon.exe orig-daemon.exe.locked-by-<pid>`。
3. `sh scripts/sync-sidecars.sh` → 输出 `OK`。
4. `ls -l tauri-shell/src-tauri/target/release/orig-daemon.exe` → **不存在**。

## 修复

- sync 模式：**目录存在就写**，不再以「文件是否存在」为条件。
- check 模式：对缺失的目标显式 `WARN`（`MISSING` 计数），让「从未同步过」可见。
- `cp` 失败不再被吞：直接 `fail` 并给出可行动提示
  （「可能被运行中的进程占用，先改名成 `*.locked-by-<pid>` 再重试」）。

## 验收证据

修复后 `--check` 如实报出此前完全不可见的缺口：

```
$ sh scripts/sync-sidecars.sh --check
sync-sidecars: WARN - orig-tg: 壳 target 缺少 debug/orig-tg-x86_64-pc-windows-msvc.exe（尚未同步过）
sync-sidecars: WARN - orig-tg: 壳 target 缺少 release/orig-tg-x86_64-pc-windows-msvc.exe（尚未同步过）
sync-sidecars: WARN - 2 个壳 target 产物缺失（sync 模式会自动补齐，未阻断）。
sync-sidecars: OK - sidecar 产物与源码同步（check only）
exit=0
```

**反向证伪**：修复前同样的命令只输出一行 `OK`，对上述两处缺失**一个字都不提** ——
证明新告警不是空转，而是补上了此前被静默吞掉的信息。

端到端：补齐 `orig-daemon.exe` 后从该路径启动 daemon 成功（`netstat` 显示 9876 LISTENING，
并自动拉起 orig-tg 占用 9877），`sh scripts/sync-sidecars.sh --check` 仍为 `exit=0`。

改动文件：`scripts/sync-sidecars.sh`。

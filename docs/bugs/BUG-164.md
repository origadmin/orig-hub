# BUG-164: 下载类视图顶栏无连接灯 —— 三角落连接态指示在半数视图缺一

- 状态: fixed
- 发现日期: 2026-09-24
- 模块: shell
- 严重程度: low
- 档位: standard

## 现象

用户报「三个角落实时已连接问题没修复」。实测（后端 daemon(9876)/tg(9877) 真实连接，
`/api/tg/diag` = `available:true / mock:false / session Authorized`）：

- 侧栏底部与状态栏两角正常：`data-conn-state="live"`、文案「实时已连接」；
- **顶部上下文栏的连接灯只在媒体库 / TG / 设置视图渲染**——应用默认落地视图
  （「全部文件」，下载类）就没有顶灯，CDP 探针读数
  `{"context":null,"statusbar":{"state":"live"},"sidebar":{"state":"live"}}`。

即三角落在 `all / downloading / paused / completed` 四个视图恒为三缺一。

## 根因

`tauri-shell/src/components/ContextBar.tsx`（修复前 `:122-132`）按
`resolveContextKind(view)` 分流右槽：下载类视图走 `ContextBarActions`
（只有按钮 + `SpeedChip`，**无连接灯**），其余视图走 `ContextBarStatus`（有灯）。

BUG-083 把顶栏改成随视图变化的上下文栏时，下载分支只搬了操作按钮；
BUG-087 把三处连接态统一到 `store/connState.ts` 后，顶部灯只挂在
`ContextBarStatus`（非下载分支）——`ContextBarActions` 分支从未接入。
BUG-087/134 的「三处收敛」只覆盖了已挂灯的三处，未覆盖这个缺席分支。

## 修复

把连接灯抽成 `ConnLight`（判定唯一来自 `store/connState.ts` 的 `useConnState`，
DOM 契约沿用 BUG-087 验收口径：`data-testid="context-conn"` + `data-conn-state`），
两个分支共用，不再各写各的：

- `tauri-shell/src/components/ContextBarStatus.tsx`：导出 `ConnLight`（灯 + 文案 +
  testid/属性随之迁移到此），`ContextBarStatus` 复用之；
- `tauri-shell/src/components/ContextBarActions.tsx`：右槽改为
  `ConnLight + SpeedChip + 按钮组`；
- `tauri-shell/src/components/ContextBar.tsx`：仅分支文档注释同步（行为不变）。

## 验收证据

- `tsc --noEmit` 通过（exit 0，tauri-shell 本地 `typescript ~5.8.3`）。
- CDP 零依赖探针（复用入库脚本库 `tauri-shell/verify/lib/cdp.cjs`，Node ≥22
  内置 WebSocket），真实后端下逐视图读三角落，修复后两分支全部三绿：

  ```
  VIEW=all(下载)  THREE_CORNERS={"context":{"state":"live","text":"实时已连接"},"statusbar":{"state":"live","text":"实时已连接"},"sidebar":{"state":"live","text":"实时已连接"}}
  VIEW=media      THREE_CORNERS={"context":{"state":"live","text":"实时已连接"},"statusbar":{"state":"live","text":"实时已连接"},"sidebar":{"state":"live","text":"实时已连接"}}
  ```

  修复前同探针在 `all` 视图为 `"context":null`（其余两处 live）——判据非恒绿：
  缺灯必现 `null`，装回旧实现即可复现 FAIL。
- 真实截图（CDP `page.screenshot`，本机 `verify_shots` 之外暂存于系统临时目录）：
  修复前 `orighub_conn_corners.png`（顶栏无灯）、修复后
  `orighub_corners_fixed_all.png`（顶栏「● 实时已连接」位于「新建下载」左侧）、
  `orighub_corners_fixed_media.png`（状态分支不回归）。跨机器可核引用以本文件
  所列入库路径为准（上述三个源文件 + `verify/lib/cdp.cjs`）。

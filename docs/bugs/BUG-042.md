# BUG-042：筛选空态伪装成「资料库是空的」——误导用户以为数据丢失

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: shell
- 严重程度: mid

## 现象
Playwright 截图实证：按标签筛选结果为空时，页面渲染「资料库是空的 + 导入目录」
——把「无匹配」伪装成「库空」，用户会误以为数据全丢。

## 根因
空态判据用列表响应的 `total`（**筛选后**总数，筛空=0），不是库级总数；
且无「无匹配」空态分支。

## 修复
判据改库级 `stats.items`；新增「没有匹配的内容 + 清除筛选」空态
（内容/剧集两处，i18n `media.noMatch`/`media.clearFilter`）。

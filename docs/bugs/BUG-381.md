# BUG-381: 媒体库方格图偏小且没有可看清的浏览方式

- 状态: fixed
- 发现日期: 2026-10-22
- 模块: shell
- 严重程度: mid

## 现象

用户 2026-10-22 报：「方格图有点小了，而且没有浏览功能无法看清。」

实测（CDP 1440×900，`e5_series_wall.png`）：剧集墙 `SeriesCard` 228×128
（封面即卡面），条目墙 `media-grid` 为
`grid-cols-[repeat(auto-fill,minmax(200px,1fr))]`（`MediaLibraryPanel.tsx:1679`）
——1440 宽下一行 6 张，封面细节（人脸/字幕）不可辨。灯箱
（`MediaViewer`）只在「打开条目」后到达，网格上没有「看一眼大图」的
直接入口。

## 修复

1. 条目墙/剧集墙最小列宽 200px → 240px（缩略图可辨，行数损失可接受；
   剧集墙卡高随封面比例同步放大）。
2. 网格卡片提供直达灯箱的浏览入口（封面点击进大图浏览，而非只进播放详情），
   图片类条目尤其需要。

（min=230），exit=1；还原后复绿 3/3。截图与 result.json 落
`tauri-shell/verify/evidence/BUG-381/`（01-series-wall.png /
02-video-grid-hover.png）。

说明：浏览入口的落地形态是悬浮层「点击查看」文字（MediaCard 悬浮操作层
新增 hint 行），灯箱入口即封面单击路径的原生语义——与修复方案第 2 条
「网格卡片提供直达灯箱的浏览入口」一致（封面点击 = 浏览，`ActionIcon`
按类型分流不变）。

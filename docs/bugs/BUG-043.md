# BUG-043：cache worker 对「已落盘但从未入库」的条目静默跳过

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: engine
- 严重程度: high

## 现象（端到端验证抓到）
入队一个「全部已缓存」的历史 TG 组：任务 done 2/2，但媒体库无条目、
剧集未建、标签未归档——cache worker 的「已缓存」分支只查 `item_id_by_ref`，
查不到就静默跳过。**已落盘但从未入库**的历史缓存永远进不了媒体库。

## 修复
把 `cache_one` 的入库块抽成 `import_cached_file(st, chat, msg, path)`；
worker 已缓存分支查不到 ref 时**补导入**再进剧集编排。

## 验收
e2e（全已缓存组零带宽复跑）：自动成剧 id=53（2 集）+ 归档 3 标签。

## 关联
BUG-029（缓存即入库）、③b 标签归档链路。

# BUG-252: MergeSeriesDialog 中文硬编码 —— 英文界面里混排中文

- 状态: fixed
- 修复日期: 2026-10-12
- 发现日期: 2026-10-11
- 模块: shell
- 严重程度: low

## 现象

用户界面语言设为 English 时，媒体库打开的剧集内页里
「合并剧集」（`MergeSeriesDialog`，`SeriesDialog.tsx`）整段仍是**中文硬编码**：
标题、说明、集号规则、确认提示、按钮全部不随语言切换，英文界面里出现成片中文。

实测渲染（en-US 界面，`seriesLabel` 已按 BUG-251 用英文弯引号）：

```
合并剧集
把另一个剧集的内容并入“目标剧集”（3 集），源剧集随后被删除。
将把“源剧集”的 3 个分集并入“目标剧集”，源剧集会被删除，此操作无法撤销。
确认合并 / 合并中… / 取消
```

## 根因

`MergeSeriesDialog` 内的文案是**字面量中文**，未经 `t()` / i18n 键。

已知落点（`tauri-shell/src/components/media/SeriesDialog.tsx`，`MergeSeriesDialog`）：

- `:270` 标题 `合并剧集`
- `:273` `把另一个剧集的内容并入`
- `:275` `（{target.episodeCount} 集），源剧集随后被删除。`
- `:279` 空态 `没有其他剧集可供合并`
- `:292` 候选项 `{s.title}（{s.episodeCount} 集）`
- `:297-300` 说明段（含 `本功能不做内容合并判断。`）
- `:301-307` 集号规则段（含 `合并自《源剧集》· 原 E<n>` 溯源措辞）
- `:310-311` 确认提示 `将把…的 N 个分集并入…，源剧集会被删除，此操作无法撤销。`
- `:319` 按钮 `取消`
- `:329` 按钮 `确认合并` / `合并中…`

（`MergeSeriesMultiDialog`，同文件 `:348` 起，为剧集墙多选合并，需一并核对是否同样硬编码。）

## 影响

英文用户打开剧集合并流程时，界面语言与呈现语言不一致；这些文案也**不在 i18n
键集校验的覆盖内**，因此不会在「键缺失」类门禁里暴露。

## 复现

1. 设置 → 常规 → 语言切到 English；
2. 媒体库 → 剧集墙 → 打开任一剧集 → 进入「合并剧集」；
3. 观察标题、说明、确认提示、按钮语言。

## 修复（已落地，2026-10-12）

`MergeSeriesDialog`（`SeriesDialog.tsx`）内的全部中文字面量替换为 i18n 键，
新增 `media.seriesMerge*`（约 14 个）键，en-US / zh-CN 双语补全：标题
`seriesMergeOpen`、说明 `seriesMergeTargetPrefix` / `seriesMergeTargetSuffix`、
空态 `seriesMergeEmpty`、候选项 `seriesMergeOption`、集号规则 `seriesMergeOrderHint`、
`seriesMergeNumberPrefix` / `seriesMergeNumberEmph` / `seriesMergeNumberSuffix`、
确认提示 `seriesMergeConfirmBodySingle`、按钮 `seriesMergeBusy` / `seriesMergeDone` /
`seriesMergeNext`，以及复用既有 `media.cancel` / `media.confirm`。
`MergeSeriesMultiDialog`（同文件）经核查**本就无 JSX 字面量**（仅注释含中文），不需改。

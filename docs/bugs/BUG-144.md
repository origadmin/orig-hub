# BUG-144：设计外「视频库」独立导航入口（S4）——挤占 TG 导航并造成回归

- 状态: fixed
- 发现日期: 2026-09-23
- 模块: shell
- 严重程度: major

## 现象

侧边栏出现设计文档（PRD / 评估）均未规划的「视频库」独立导航项，插在「媒体库」与「Telegram」之间。用户据此报告 TG 导航入口「丢失 / 回退」，并质疑「媒体库与 TG 的分离是否计划」。

实为新增视频库项把 TG 项下挤、并引入设计外入口造成观感/范围回归：**TG 项本身仍在 `NAV_ITEMS` 中（仅受 `tgReady` 门控，逻辑未变）**，故属范围越界 + 观感回归，而非硬删除。

## 根因

并行在途改动（未提交）在 `Sidebar.tsx` / `MainLayout.tsx` / `ContextBar.tsx` / i18n 落地了 PM 评估 S4 的「视频库」独立导航：

- `Sidebar.tsx`：`ViewId` 联合类型加 `| 'video'`；`NAV_ITEMS` 在 `media` 与 `tg` 之间插入 `video` 项（`labelKey: 'nav.video'`）。
- `MainLayout.tsx`：`<main>` className 条件加 `view === 'video'`；新增 `view === 'video' ? <MediaLibraryPanel key="video" initialKind="video" />` 分支，并把 media 分支改为 `key="media"`。
- `ContextBar.tsx`：`TITLE_KEY` 加 `video: 'nav.video'`。
- `MediaLibraryPanel.tsx`：为视频库新增 `initialKind` prop + `lockedKind` 死分支（`lockedKind === 'video'` 三处、初始 tab/view、`all` 过滤）。
- i18n：`nav.video: "视频库" / "Videos"`。

设计文档 `docs/design/media-library-management-prd-2026-09-22.md` 与 `tg-media-ux-confusion-assessment-2026-09-22.md` **均无**「视频库独立导航 / 媒体库-TG 分离」条目——属评估建议 S4 被直接落地为导航，超出已对齐交付范围，且未经验收即进工作树，引发用户感知回归。

## 复现

`git diff` 可见上述四处 + `MediaLibraryPanel` 的 `lockedKind` 分支；启动后侧边栏「媒体库」下方出现「视频库」，TG 项被下挤。

## 修复

提交 `<hash>`（`fix(shell): remove design-out video library nav entry (BUG-144)`）。

**选择性回退设计外视频库导航，保留同源的「媒体库来源抽象」重构（`lib/mediaSources.ts`，BUG-098 落地，已随 `0c6b8f9` 入库）与 S2/S3 来源离线处理（BUG-145）**：

- `Sidebar.tsx`：移除 `ViewId` 联合中的 `| 'video'`；移除 `NAV_ITEMS` 的 `video` 项。
- `MainLayout.tsx`：还原 `<main>` className（去掉 `view === 'video'`）；删去 `view === 'video'` 分支；media 分支还原为 `<ErrorBoundary><MediaLibraryPanel /></ErrorBoundary>`（去 `key`）。
- `ContextBar.tsx`：移除 `TITLE_KEY` 的 `video` 键。
- `MediaLibraryPanel.tsx`：移除 `initialKind` / `lockedKind` 死分支（prop 还原为 `()`、tab 初始 `'all'`、view 初始 `'series'`、去掉 `lockedKind === 'video'` 三处与 `all` 过滤），保留 S2/S3 来源离线处理。
- i18n：移除 `nav.video`（保留 `source.*`）。

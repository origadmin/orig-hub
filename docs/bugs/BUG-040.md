# BUG-040：窄窗口媒体库整体出界裁剪——右侧按钮全消失且无滚动

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: shell
- 严重程度: high

## 现象
窗口较窄（<862px）时媒体库/剧集详情「一点基础样式都没有，内容完全超模，右按钮什么都不见了」。
实测 700/800px 视口各有 50–192 个元素出界（`scrollWidth == clientWidth` —— 无滚动条的纯裁剪），
「移除/编辑」按钮全部在视口外。

## 根因
flex 链上多个节点缺 `min-w-0` / `flex-wrap`，flex 子项自动最小宽度被内容 min-content
钉死（面板 670px；详情头部 `shrink-0` 不可缩；工具栏按钮组 `whitespace-nowrap` 不换行）。

## 修复
- `MediaLibraryPanel` 根节点 + `ml-auto` 按钮组：`min-w-0` + `flex-wrap`；
- `SeriesDetail` 头部去 `shrink-0`（改 `min-w-0`）、滚动容器 `overflow-x-hidden`、
  极窄（<720px）隐藏头部封面（保证按钮行可用宽度 ≥ 单按钮宽）。

## 验收
Playwright 560–1440px 全宽扫描：≥700px 零元素出界、按钮全在视口内
（640 以下剩余为分集行固定件下限；Tauri minWidth=900 应用内不可达）。
截图 `verify_shots/break_probe/final_1200.png` 等。

# BUG-089: 分类下钻时「全部文件」行不点亮，顶行失去「我在哪」指示

- 状态: fixed
- 发现日期: 2026-09-21
- 模块: shell
- 严重程度: low

## 现象

点 chevron 展开分类 → 点「视频」，上下文标题已变成「全部文件 · 视频」、子项「视频」本身高亮正常，
但侧栏顶行 `all-files-row` **没有 `bg-accent/15` 高亮** —— 顶行失去「我在哪」的位置指示，
只有缩进更深的子项是亮的，视觉上像是从别处凭空跳进了某个分类。

## 根因

`tauri-shell/src/components/Sidebar.tsx:150`（修前）：

```ts
const allActive = view === 'all' && categoryFilter === null
```

多要求了 `categoryFilter === null`。分类下钻语义上**仍处在全部文件里**（只是加了一层过滤，
标题也如实写成「全部文件 · 视频」），但判据把它当成「不在全部文件」 → 顶行熄灭。
即：高亮判据与「当前视图归属」的口径不一致。

## 复现

1. `npm run dev` 起 5180，打开 `http://127.0.0.1:5180/`（默认落在「全部文件」）；
2. 点 `[data-testid=category-chevron]` 展开分类；
3. 点任意分类子项（如「视频」）；
4. 读 `[data-testid=all-files-row]` 的 `className` —— 修前无 `bg-accent/15`。

## 修复

`allActive` 改为只看当前视图归属：`const allActive = view === 'all'`。
下钻时顶行保持点亮（面包屑态），子项另行高亮当前分类 —— 与「标题已写全部文件 · 视频」口径一致。
未改 chevron 与文字的点击解耦（BUG-006 的既有行为保持不变）。

## 验收证据

真实浏览器（零依赖 CDP 驱动）实测：展开分类后点分类子项，`[data-testid=all-files-row]` 的
`className` = `flex w-full items-center rounded-md px-2.5 py-2 text-sm transition-all duration-200 bg-accent/15 text-accent`，
即**含 `bg-accent/15`**，行内文本仍为「全部文件」；页面 `pageErrors` 为空。

- 门禁：`python scripts/check-bugs.py` 与 `sh scripts/check-pollution.sh` 均 EXIT 0；
  `node node_modules/typescript/bin/tsc --noEmit` EXIT 0

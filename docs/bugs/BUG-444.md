# BUG-444: 「播放全部」起点取自可播子集，但播放序列传的是全量集序列——自动连播会遍历非可播集

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: low
- 排期: 2026-12-26

## 现象

剧集内含图片集 / 无字节集时，点「播放全部」从首部可播视频开始，但自动连播（播完跳下一集）会跳过/卡在
图片集或无字节集上，连播顺序与用户预期的「只连播能播的视频」不一致。

## 根因

`SeriesDetail.tsx:317` `playEpisode = (ep) => props.onPlay(detail.episodes.indexOf(ep))` 与
`SeriesDetail.tsx:751-755` 的「播放全部」都先把**起点**算成可播子集 `playEps[0]` 在**全量序列**
`detail.episodes` 里的下标；但 `MediaLibraryPanel.playEpisode(index)`（`MediaLibraryPanel.tsx:900`）
把 `episodesToItems(detail)`（**全量** episode 序列，含图片/无字节）连同该下标交给 `playItems`——
播放序列本身就是全量序列，自动连播按全量序列 `index+1` 推进，而非按 `playEps` 可播子集推进。
`SeriesDetail.tsx:316` 的注释只要求「下标相对全量序列」，并未把播放序列收窄到可播子集，故起点与
连播序列两套口径、会错位。

## 复现

1. 造一部含「视频集 + 图片集」交错的多集剧集；
2. 点「播放全部」从首视频开始；
3. 播完首视频，观察下一集是否为「下一部可播视频」还是「全量序列里 index+1（可能是图片集）」。

## 修复

`playItems` 传入的序列须为可播子集 `playEps`（或 `episodesToItems` 仅收可播集），使起点下标与连播
序列同口径；或在 viewer 内按 `isPlayable` 跳过非可播项（与 BUG-036/150 的「图片不进视频连播」一致）。
注意 `SeriesDetail.tsx:316` 注释的「下标相对全量序列」约束须同步更新，避免回退。

## 验收证据
自动连播按**可播子集**推进：「播放全部」的起点与后续推进用同一个序列，
无字节/图片集不再成为「下一集」；分集侧栏仍保持全量可点（用户可点范围不变）。

落点 `tauri-shell/src/components/media/SeriesDetail.tsx`（起点与序列同源）、
`tauri-shell/src/components/MediaViewer.tsx`（自动推进过滤 `hasMediaBytes` 为假的视频）。
反向证伪：把推进组改回全量 episode 序列，含图片集的剧集播完会停在/跳过下一集。

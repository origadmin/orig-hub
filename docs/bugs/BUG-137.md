# BUG-137：TG 内置播放器三入口只传单条/单相册——TG 侧无上一条/下一条

- 状态: open
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: low

## 现象

从 TG 面板打开内置播放器，没有「上一条/下一条」（‹› 按钮不出现、键盘 ←/→ 无效）；同样内容从媒体库打开却能连续播放整部剧集/连续翻图——**同一播放器两种能力**，用户感知为「时好时坏」。

## 根因

`TgPanel.tsx` 三处 `openViewer` 只传单条或单相册：

- `:698-703` 全局搜索命中 → `items: toViewerItems([item])`（单条）。
- `:1021-1028` `onBubblePreview` 单条气泡 → 单条。
- `:1030-1036` `onAlbumPreview` 相册 → 单相册（组内可翻，无跨组邻居）。

对比 `MediaLibraryPanel.playItems`（`:277-297`）：选中项属于剧集时会 `loadSeriesDetail` 扩成**整部剧集**再传——`MediaViewer` 的组内导航与侧栏定位都依赖这份列表的完整性（注释明确：「若只含一条，那些点击会全部落空」）。

## 复现

TG 相册预览 → 只能在组内翻；单视频预览 → 完全无 ‹› 与邻居。

## 修复

需先产品决策：TG 侧「邻居序列」的范围是什么（当前频道 feed？命中集？仅同类型？）。技术上把 `items` 传长即可（`MediaViewer` 已支持全量列表 + kind 分组，BUG-036）。

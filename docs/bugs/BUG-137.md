# BUG-137：TG 内置播放器三入口只传单条/单相册——TG 侧无上一条/下一条

- 状态: fixed
- 发现日期: 2026-09-22
- 模块: shell
- 严重程度: low

## 现象

从 TG 面板打开内置播放器，没有「上一条/下一条」（‹› 按钮不出现、键盘 ←/→ 无效）；同样内容从媒体库打开却能连续播放整部剧集/连续翻图——**同一播放器两种能力**，用户感知为「时好时坏」。

## 根因

`TgPanel.tsx` 三处 `openViewer` 只传单条或单相册（**行号为修复前，修复后见「修复」节**）：

- `:698-703` 全局搜索命中 → `items: toViewerItems([item])`（单条）。
- `:1021-1028` `onBubblePreview` 单条气泡 → 单条。
- `:1030-1036` `onAlbumPreview` 相册 → 单相册（组内可翻，无跨组邻居）。

对比 `MediaLibraryPanel.playItems`（`:277-297`）：选中项属于剧集时会 `loadSeriesDetail` 扩成**整部剧集**再传——`MediaViewer` 的组内导航与侧栏定位都依赖这份列表的完整性（注释明确：「若只含一条，那些点击会全部落空」）。

## 复现

TG 相册预览 → 只能在组内翻；单视频预览 → 完全无 ‹› 与邻居。

## 修复

提交 `4f7cdbd`（`fix(shell): pass the playable neighbour sequence from all three TG viewer entries (BUG-137)`）。

**邻居序列的口径**（即此前「待产品拍板」的那一项，此处按「与媒体库对齐」拍定）：
序列 = **当前入口用户正在看的那一列的可播子集**，顺序与界面一致；`file`（无可视形态）不入序列。

- 全局搜索命中 → 命中集本身（跨频道搜索按用户看到的命中顺序，不按频道重排）。
- 单条气泡 / 相册宫格 → 当前频道 feed 的可播子集。相册只决定「从哪一张打开」，
  序列仍覆盖相邻单元 —— 因此相册最后一张能翻到下一个单元，而不是断在相册边界。

改动点（`tauri-shell/src/components/TgPanel.tsx`）：

| 位置 | 改动 |
|---|---|
| `:160` `fromHit` | 从 `onGlobalHitPreview` 里抽出命中 → `FeedItem` 转换（键前缀 `g-`，与 `fromStored` 同构），供序列复用 |
| `:183` `isPlayable` | 准入判据 `u.type !== 'file'`。`MediaViewer` 按 `modeOf(kind)` 分流（photo→浏览、video/audio→连播、file→none），把 `file` 塞进序列会让 ‹ › 在两个「不支持预览」的条目之间空翻 |
| `:716` `playableHits` | 命中集的可播子集（全局搜索入口的序列） |
| `:719` `onGlobalHitPreview` | `index` 由 0 改为命中在序列中的真实下标 `idx`；命中不可播（`idx < 0`）时退回 `[item]`，**不拿 0 顶上**（那会打开另一条 = 谎报位置） |
| `:904` `playableFeed` | `feed.filter(isPlayable)`（单条气泡与相册共用的序列）。与 `albumUnits` 同源：`albumUnits` 是按 feed 顺序切出来的，展平即 feed 本身 |
| `:917` `openPlayable` | 三入口统一的开播函数：按 key 在 `playableFeed` 里定位真实 `index`；定位不到则用调用方给的兜底列表 + 兜底下标 |
| `:1083` `onBubblePreview` | 改走 `openPlayable(item, [item], 0)` |
| `:1095` `onAlbumPreview` | 改走 `openPlayable(items[index], items, index)` —— `index` 是单元内下标，不能直接当全流下标，换算交给 `openPlayable` |

`toViewerItems` 的 `src` / `fallbackSrc` 选取逻辑**未改**。

配套：`tauri-shell/src/components/MediaViewer.tsx` 加可断言的挂载点
（`data-testid="media-viewer"` + `data-message-id`、`viewer-position`、`viewer-prev`、`viewer-next`、`viewer-title`），
`TgPanel.tsx` 加 `tg-photo-preview` / `tg-album-tile-<i>` / `tg-hit-preview` + `data-message-id` —— 让「序列长度与位置」可被脚本断言，而不是只能截图看。

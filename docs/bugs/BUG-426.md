# BUG-426: 剧集详情头部出现两颗逐字同文案、功能完全重叠的「编辑」按钮

- 状态: fixed
- 发现日期: 2026-10-24
- 模块: shell
- 严重程度: mid
- 档位: standard

## 现象

用户 2026-10-24 复报「剧集详情所有问题都没修复」，点名「编辑顺序」：剧集详情头部有**两颗
都写「编辑」、且点击后打开同一个面板**的按钮。

实测（live 栈 5180）：`series-desc-edit`（剧集介绍块右侧铅笔，文案 `media.series.editMeta`
=「编辑」）与 `series-edit`（动作条，`media.series.editMeta` =「编辑」）**文案完全相同**，
二者 `onClick` 都调 `setEditingSeries(true)` ⇒ 打开同一个 `SeriesEditPanel`（介绍 / 标题 /
类型 / 年份 / 标签一次提交）。用户在紧邻位置看到两个同义「编辑」，无法区分哪个改什么。

## 根因

`SeriesDetail.tsx` 在「剧集介绍」展示块里额外放了一颗编辑入口（series-desc-edit），而动作条
已经有 `series-edit` 覆盖**同一** `SeriesEditPanel`。介绍编辑能力本就包含在 `SeriesEditPanel`
里，介绍块那颗是冗余的第二个入口；两者文案又都取自 `editMeta`，于是逐字重复。

## 修复

`tauri-shell/src/components/media/SeriesDetail.tsx` 剧集介绍展示块：删掉冗余的
`series-desc-edit` 按钮，只保留「展开 / 收起」长文切换（`series-desc-toggle`）。剧集级编辑
统一收口到动作条的 `series-edit`（同一 `SeriesEditPanel`）。介绍**空态**的「添加剧集介绍」
入口（`media.addSeriesDesc`，同样开 `SeriesEditPanel`）保留——它是无介绍时唯一的补介绍入口，
不是冗余。

## 验收证据

- 静态：`grep` `series-desc-edit` 在 `SeriesDetail.tsx` 仅剩介绍空态那一颗（添加），满态块
  不再有第二颗「编辑」；动作条 `series-edit` 唯一存在。
- 类型：`tauri-shell` `tsc --noEmit` 退出码 0。
- 真栈（dev 5180）：CDP 探针渲染真实剧集 540（时停手表，6 视频）实测——`series-edit` 计数
  **1**、介绍块 `series-desc-edit` 计数 **0**（仅动作条一颗「编辑」）；点击 series-edit 进入
  `SeriesEditPanel`，介绍 / 标题可一并编辑。探针：`tauri-shell/verify/_probe_sd_audit.cjs`。
- 反向证伪（结构显然）：若把删掉的按钮加回介绍块 ⇒ `series-desc-edit` 计数回到 1，头部出现两颗
  「编辑」，判据恢复。

**关联**：BUG-281（介绍渲染裁定反转，同批 2026-10-24）；BUG-201（右栏聚焦面不再放第二颗
介绍编辑按钮，同根因）。

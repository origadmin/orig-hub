# BUG-486: 剧集详情动作区三轮回归——播放全部错上封面、编辑成孤框、移除本集仍占整行

- 发现日期: 2026-10-28
- 严重程度: mid
- 模块: shell
- 状态: fixed

## 现象（用户截图 + 原话）

1. 「全部播放按钮位置完全乱放,我之前说了放在下面,下面,和单集播放应该距离不是很远」
   —— BUG-476e 把播放全部做成**封面右下覆盖圆钮**，违背用户「放下面、挨着单集播放」的指令。
2. 「编辑按钮,什么逻辑,给个框? 什么设计,标准呢?」
   —— BUG-476e 把剧集编辑做成标题行行尾 7x7 **icon 孤框**（无文字、无对象语境、悬空圆框），
   违反「可见性由边框+底色承担」之外更基本的「动作要有可读标签/语境」。
3. 「右边"从剧集移除本集"之前提过了,一个按钮占了一整行的错误,现在又来!」
   —— 右栏危险区仍用 `w-full` 实心红条独占一行。

## 根因

BUG-476e 的归属裁决对「播放/编辑」两颗做了**形态创新**（覆盖圆钮、孤框 icon）而非落到
用户已明示的位置语义上；「从剧集移除本集」在 BUG-478 只挪了区块没改「独占一行」的形态。
三轮共性 = 用排版替代裁决、忽视用户已给出的位置约束。

## 修复（本轮归属裁决，全部落到用户明示语义）

- 播放全部：**删封面覆盖圆钮**；迁到**选集器列表下方**（`episode-picker` 容器之后），
  与行内单集播放钮（`episode-row-play`）同列区、距离近——正是用户两次强调的「下面、不远」。
  列表收起时仍可用（播放全部不依赖列表展开）。
- 剧集编辑：**删标题行孤框**；迁到介绍块——非空介绍给「编辑」小字钮（与展开/收起同款
  disclosure 外观、有对象语境），空态沿用既有「+ 添加剧集介绍」（`series-desc-edit`）。
- 从剧集移除本集：**删全宽红条**；并入右栏工具带行（查看内容/上移/下移/补缓存之后，
  `ml-auto` 靠右），danger 文字钮、与行内其他钮同高——不再独占一行。

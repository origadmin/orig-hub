# BUG-047 监控搜索框位置错误（应在标题栏标题与按钮之间）

**状态**: fixed
**优先级**: medium
**模块**: tauri-shell / TgPanel
**日期**: 2026-09-18

## 现象

监控内容搜索框此前放在第一栏（频道列表侧）单独一行，不在内容区顶部标题栏的
「标题与按钮之间」；同时存在第二个冗余搜索框（单频道内过滤，"在监控内容中搜索…"），
与用户定义相悖——用户已裁定：**监控内容搜索 = 从所有监控频道中筛选**。

## 修复

1. **唯一搜索框上移**到内容区标题栏：`[←返回][头像+标题] [搜索框] [缓存管理][监控中]`，
   与标题、按钮同行（几何断言：搜索框在标题右侧、缓存管理按钮左侧）。
2. **结果视图不丢焦点**：输入非空切到结果视图时，结果页头部渲染同一个受控输入
   （`autoFocus` 接管焦点），命中数与「清除」按钮内联在标题栏同一行。
3. **删除冗余的单频道搜索行**及其状态链（`feedSearch*` state、防抖 effect、
   feed 查询的 `q` 参数、空态分支）——单频道过滤是全局搜索的子集（结果自带频道名）。

  输入后结果视图出现、输入框保持焦点（`document.activeElement` 断言）；
  清除后回到频道流。截图 `verify_shots/bug046/`。
- `tsc --noEmit` 0 错误；dist 已重建（`index-B8gJltuR.js`）。

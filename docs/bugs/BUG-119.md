# BUG-119：图片没有归属层级 —— 只能挂在剧集上，无法表达「某一集下某个视频的图片」

- 状态: open
- 严重程度: mid
- 模块: engine
- 发现日期: 2026-09-22

## 现象

- 图片只能整组挂在**剧集**上，做不到「剧集内按集组织的图集」；
- **按集清理图片做不到** —— 想删掉某一集附带的那几张图，没有这个粒度；
- 用户要的合理归属「某一集下的某个视频的图片」在数据模型上无法表达。

## 根因

图片与视频在 `media_item` 里**平铺同层**（115 条 = 85 video + 30 photo，同一张表），
层级上只有 `media_episode.item_id` 一个挂钩，而它挂的是**单个 item**：

```
media_series ──< media_episode(item_id) ──> media_item
                                            （video 与 photo 同级）
```

于是图片的归属只能是「某剧集的某一集」，**没有「属于某个视频」这一层**。

## 修复方向

随分层改造（`media_asset` / `media_attachment`）一并解决：

| 图片类型 | 归属 | 判定依据 |
|---|---|---|
| **内容型**（图集） | `media_asset(kind=photo)`，挂 `episode` | 在 Telegram 里**独立成组**发送的图片 |
| **展示型**（封面 / 随视频发送） | `media_attachment(role=poster|gallery)`，`owner=asset` | 与视频**同组**发送，或作为封面 |

判定依据（「是否同组发送」）能自动判定到什么程度**取决于 photo 的 `ref` 是否总能解析出
chat/msg** —— 这条列为**待拍板**，不确定时先按「挂 episode」落地，再按来源校正，
不要为了一次判定正确而阻塞整个改造。

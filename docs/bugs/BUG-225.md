# BUG-225: FRC 流上「播放时间不对」—— live fMP4 的 NaN duration 让位置恢复/跳转全部钳回 0:00

- 状态: fixed
- 发现日期: 2026-10-09
- 模块: shell
- 严重程度: high

## 现象

用户在 BUG-223 上线后真实播放反馈：**播放时间不对了**。表现为切到非 1x 倍速后时间回到 0:00、总时长显示缩水，以及 ±10s 跳转不前进反而回到 0:00。

## 定性证据（`verify_shots/frc-hotfix/diag-result.json`，条目 630，真实 APP + msedge + orig-tg）

- 冷缓存 2x 换档（暂停态、内容位置 30s）：换档前 `ct=30.22 dur=49.8 text="0:30 / 0:49"`；换档后 **`ct=0.00 dur=NaN` → 14s 后 `text="0:00 / 0:13"`**。位置从内容 30s 掉到 0s（期望恢复到媒体 15s）。
- live FRC 流上点「快进 10s」按钮两次：`seeking/seeked` 事件触发，但 `currentTime` 两次都被钳回 **0.00**（期望 +5s 媒体/次）。
- 缓存命中（完整代理，Range 可拖）时同一换档位置恢复精确（15.37s 媒体 = 30.74s 内容，drift≈0）——缺陷只在 live（冷缓存）流上。

## 根因

`/stream` 冷启动输出 fMP4（`empty_moov`），`loadedmetadata` 时 `v.duration` 为 **NaN**。旧实现：

1. `onLoadedMetadata` 里 `durationRef.current = isFinite(v.duration) ? v.duration : 0`，随后恢复位置用 `Math.min(durationRef.current, targetTime)` —— **上限是 0，恢复被钳回 0:00**；
2. `durationRef` 只在 loadedmetadata 记录、从不在 `durationchange` 上同步，live 流之后学会了 duration 也不知道 —— `skip()` 里 `Math.min(durationRef.current=0, ...)` 让 ±10s 永远落到 0；
3. 时间文案的总时长用 `v.duration × timeScale`，NaN 时显示 0，live 流学到部分 duration 后显示被压缩的媒体时长（"0:13"）而不是源内容时长。

## 方案（`tauri-shell/src/components/media/VideoPlayer.tsx`）

- `durationRef` 删除，统一为 `contentDurationRef`（源内容秒）：`loadedmetadata` 与 **`durationchange`** 都同步（后者兜底换算 `dur×speed+offset`）；
- 位置恢复上限只在拿到**有限** duration 时钳制（`Number.POSITIVE_INFINITY` 兜底），恢复公式统一为 `(contentTime - offset) / speed`；
- `skip()` 上限优先用 `contentDurationRef` 换算 `(contentDur - offset)/speed`，否则用元素有限 duration，NaN 时不设上限只钳下限 0；
- 时间契约（含 BUG-226 锚点流）：显示值 = `contentOffset + 媒体时间 × timeScale`，总时长优先探针返回的源内容时长。叶子组件（`useMediaClock`/`PlayerTimeText`/`PlayerProgressBar`）新增 `contentOffset`/`contentDuration` props。

## 用户可见权衡

- live 流（冷缓存）首段学到 duration 之前，总时长以探针/换算值为准；换算在源元数据异常（`duration=null`）时退回 `--:--`。
- 对完整代理（缓存命中）行为不变。

## 修复后必须满足（可证伪判据）

1. **冷缓存换档保留源内容位置**：630 @30s 暂停态切 2x，恢复后内容时间偏差 ≤ 2s（修前 = 掉回 0）。
2. **±10s 跳转按源内容时间推进**：live 流上「快进 10s」×2 内容时间前进 20s ± 4s，绝不归零（修前 = 两次都钳回 0.00）。
3. **总时长显示为源内容时长**：换档后时间文案总时长 = 源时长（49/50s），不得显示压缩后的媒体时长（修前 = "0:13"）。
4. **缓存命中路径不回归**：完整代理上换档位置 drift ≤ 2s（BUG-223 C5/C6 语义）。
   可执行形态：`tauri-shell/verify/verify_bug_225_time_contract.cjs`；验牙 = 还原 onLoadedMetadata 钳制 + 删 durationchange 同步后判据 1/2 必 FAIL。

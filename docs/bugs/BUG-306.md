- 状态: fixed
- 发现日期: 2026-10-14
- 模块: shell
- 严重程度: mid

> 而且应该叫文件管理. 下面的下载应该叫全部下载, 父按钮和子按钮不应该同时选中,应该是排他的.」

## 现象（六条，逐条对应原话）

1. **「资料库（策划）」组标签多余**：侧栏文件树里「剧集」子项上方有一行小标题「资料库（策划）」，
   而该组下**只有一个子项**（剧集），且用户裁定「没有子标题」——纯冗余包裹。
2. **「管理」组标签多余、文件即管理顶层**：文件树与下载树上方套了一个「管理」组标签
   （`Sidebar.tsx:181`），用户裁定「文件就是所有的管理顶层」——这个包裹标签自身是多余的。
3. **文件树父行应叫「文件管理」**：当前父行标签 `nav.all` = 「文件」/「Files」（`zh-CN.json:2` /
   `en-US.json:2`），用户裁定「应该叫文件管理」。
4. **下载父行应叫「全部下载」**：当前父行标签 `nav.download` = 「下载」/「Downloads」
   （`zh-CN.json:3` / `en-US.json:3`），用户裁定「下面的下载应该叫全部下载」。
5. **父子不应同时选中（排他）**：当前 `filesActive = view === 'files'`（`Sidebar.tsx:111`）、
   `dlActive = view === 'download'`，进入文件/下载域后**父行与选中的子项同时高亮**；
   用户裁定「父按钮和子按钮不应该同时选中，应该是排他的」。
6. **「分类（成品内容）」组标签也多余（2026-10-14 续裁）**：用户裁定「资料库（策划）和 分类（成品内容） 全部是多余的错误实现」。`files.group.category` = 「分类（成品内容）」（`zh-CN.json:8`）渲染于 `Sidebar.tsx:222`，作为六个分类子项上方的分组头——与「资料库（策划）」同为仅包同类子项、无额外信息的冗余包裹。⇒ 同删。

## 根因

M0 落地时（`Sidebar.tsx` / `nav/index.ts`，BUG-298 / M0-T01）沿用了「组标签 + 父子树」的骨架，
但：
- 组标签是从旧 IA 草稿搬来的，**未随「文件管理为纲」（D1=A）收敛**——「管理」包裹与「资料库（策划）」
  二级标签在「视频=剧集、单集即单集剧集」（D18）之后已无存在理由；
- 父行高亮用的是「是否在域内」而非「是否选中父自身」，导致父+子双亮，违反常规导航心智
  （父=容器、子=当前位置，二者同亮语义冲突）。

## 复现

1. 打开侧栏，文件树上方看到「管理」组标签；展开文件树，分类下方看到「资料库（策划）」小标题。
2. 父行显示「文件」，下方下载父行显示「下载」。
3. 点进任一分类（如「视频」）或「剧集」——**父行「文件」仍高亮**，与子项同时亮。
4. 点进「下载中」——**父行「下载」仍高亮**，与子项同时亮。

## 修复方向（本档不改代码；由别的组实施）

1. **删除「资料库（策划）」组标签**：移除 `Sidebar.tsx:238-239` 的
   `<p className="...pl-9...">{t('files.group.library')}</p>` 行；「剧集」子项（`nav-child-lib-series`）
   保留但不再有分组头。`files.group.library` i18n 键改为删除（死键）。
2. **删除「管理」组标签**：移除 `Sidebar.tsx:181` 的 `<GroupLabel>{t('nav.group.manage')}</GroupLabel>`；
   文件树与下载树直接作为顶层项。`nav.group.manage` i18n 键改为删除（死键）。
3. **文件树父行改名「文件管理」**：`zh-CN.json` `nav.all` = 「文件管理」、`en-US.json` `nav.all` = "File Management"
   （键名 `nav.all` 沿用，避免 `Sidebar.tsx:188-189,204` 散落引用改写）。
4. **下载父行改名「全部下载」**：`zh-CN.json` `nav.download` = 「全部下载」、`en-US.json` `nav.download` = "All Downloads"。
5. **父子排他选中**（行为修复）：
   - `filesActive = view === 'files' && (fmode === 'cat-all' || seriesIdOf(fmode) !== null)`
     —— 父行仅在「全部」或「剧集下钻」时点亮；选中某分类或「剧集」子项时父行**熄灭**，与子项互斥。
     （保留 D18 / 原型「剧集下钻只留父行」规则，不自行「优化」。）
   - `dlActive = view === 'download' && dlFilter === 'all'`
     —— 父行仅在「全部」时点亮；选中某档（下载中/已暂停/已完成）时父行熄灭。
   - 子项高亮规则不变（`isNavChildActive` 已正确只亮选中子项）。
6. **删除「分类（成品内容）」组标签（2026-10-14 续裁）**：移除 `Sidebar.tsx:222` 的
   `<p className="...pl-9...">{t('files.group.category')}</p>` 行；六个分类子项（`nav-child-<cat>`）
   保留但不再有分组头。`files.group.category` i18n 键改为删除（死键）。
7. **剧集 / 视频合并（已选：单一「视频」入口，2026-10-14 末拍板）**：侧栏文件树下**不再同时出现「视频」与「剧集」两个平级视频入口**，
   合并为**单一「视频」入口**，置于文件树子项最上方（音乐/图片/… 之前）：
   - 标签复用 `files.cat.video`（=「视频」/"Videos"）；`fmode: 'lib-series'`（剧集网格视图）——依赖 D18「视频=剧集」不变量
     （单集视频即 S1E1 剧集），故「剧集」网格本就覆盖全部视频内容，无需第二个「视频」扁平入口。
   - 不再渲染 `cat:video` 分类子项（被合并入口吸收）；不再有独立的「剧集」子项
     （原 `nav-child-lib-series` 改为复用 `files.cat.video` 标签、仍 `fmode: 'lib-series'`，或等价实现）。
   - 结果：文件树子项 = 视频（合并）/ 音乐 / 图片 / 文档 / 压缩包 / 其他，共 6 项，无分组头。

## 可证伪判据（实施提交须引用 BUG-306）

> 每条判据须含**反向证伪**：喂错值/留旧逻辑必须 FAIL，不得报 0 或假绿。

1. **冗余组标签消失**：侧栏 DOM **不存在**文本「管理」「资料库（策划）」「分类（成品内容）」；
   grep `nav.group.manage` / `files.group.library` / `files.group.category` 在 `Sidebar.tsx` 渲染 0 命中
   （i18n 死键已删）。
   **反向证伪**：把刚删的任一 `<p>` 组标签加回 ⇒ 判据 FAIL。
2. **文件树父行 = 「文件管理」**：`nav-files-row` 文本 === 「文件管理」（en-US === "File Management"）。
   **反向证伪**：值改回「文件」⇒ FAIL。
3. **下载父行 = 「全部下载」**：`nav-download-row` 文本 === 「全部下载」（en-US === "All Downloads"）。
   **反向证伪**：值改回「下载」⇒ FAIL。
4. **文件域父子排他**：选中某分类子项（`nav-child-video` 等）时，`nav-files-row` **不得**含高亮类
   （`bg-accent/15`）；选中「剧集」子项（`nav-child-lib-series`）时父行同样不得高亮；
   仅当父行自身被选中（`cat-all`）时父行高亮、无子项高亮。
   **反向证伪**：保留旧 `filesActive = view === 'files'`（子项选中时父行仍亮）⇒ 判据 FAIL（字节级）。
5. **下载域父子排他**：选中某档（`nav-child-dl-running` / `dl-paused` / `dl-done`）时，
   `nav-download-row` **不得**含高亮类；仅 `dlFilter === 'all'` 时父行高亮。
   **反向证伪**：旧 `dlActive = view === 'download'` 保留 ⇒ FAIL。
6. **剧集下钻保父行（不破原型）**：`fmode === 'series:<id>'` 时 `nav-files-row` **仍**高亮
   （与「分类/剧集子项选中时父行熄灭」互斥但一致：下钻不是侧栏子项选中）。
   **反向证伪**：下钻时父行熄灭 ⇒ FAIL。
7. **真实 UI 可核**：以上均以 DOM 文本 / `getComputedStyle` 实际背景类断言（**不读 className 推断语义**），
   en-US 模式下侧栏 CJK 汉字不得有硬编码残留（i18n 驱动）。
8. **剧集/视频合并（已定稿）**：侧栏文件树下**只有一个**视频相关入口，标签 === 「视频」（en-US === "Videos"），
   位于子项最上方；**不存在**平级的「剧集」入口，也不存在 `cat:video` 扁平分类子项。
   点击「视频」⇒ `fmode === 'lib-series'`（剧集网格，覆盖全部视频内容）。
   **反向证伪**：侧栏同时存在平级的「视频」与「剧集」两个视频入口（未整合）⇒ FAIL；
   或「视频」入口 `fmode` 不是 `lib-series` ⇒ FAIL。

# BUG-101: 监控列表折叠控件不可辨识且与标题耦合 + 「立即同步」按钮语义冗余

- 状态: open
- 发现日期: 2026-09-21
- 模块: engine+shell
- 严重程度: mid

> 立项方式：项目所有者提出「监控中导航栏的展开/缩起按钮现在小到看不到，需要重新设计，
> 放右边还是左边也需要重新考虑。还有立即同步这个按钮功能是什么？监控入库不是自动的吗？
> 而且这个入库动作应该是后台 TG 操作，不影响前端展示」。
> 本条是**评估档**（未实施），结论见 `docs/design/tg-ux-assessment-summary.md`。

## 现象

### ① 折叠控件（P0，唯一的真 BUG）

`TgPanel.tsx:1195-1203`：折叠图标是**纯文本字符**
`<span className="w-3 shrink-0 text-[10px] text-muted">{monitorOpen ? '▾' : '▸'}</span>`
—— 10px 的 `▾`/`▸`，确实"小到看不到"。

**比尺寸更像 BUG 的是**：箭头与标题文字**共用同一个 `<button>`**
（`:1196` `onClick={() => setMonitorOpen(v => !v)}`）→ **点标题就折叠**。
这是评估中发现的，所有者未提及。

### ②「立即同步」按钮（P2，冗余入口）

所有者质疑成立 —— 入库**本来就是全自动的**：

- 引擎 `monitor.rs:21` `spawn()` 已启动后台 tokio 循环，间隔 `config.monitor_interval_secs`
  （**默认 30 秒**，`config.rs:44`，可用 `ORIG_TG_MONITOR_INTERVAL` 覆盖），每轮 `sync_once` 增量入库并推进游标。
- 按钮走的 `/api/tg/monitor/sync` 只是**手动提前触发同一个 `sync_once`**，
  源码注释自述「手动触发一轮增量同步（**调试**/即时入库）」（`routes.rs:1537`）——
  **是调试期遗留入口，却摆在监控列表标题行的主位置上。**

## 根因补充：所有者的后半句主张「不影响前端展示」现状也不满足

- `monitor_sync`（`routes.rs:1538-1543`）是**同步 await**，HTTP 请求会挂到整轮同步结束。
  它跑在 tokio 上所以不阻塞事件循环，但前端「同步中…」会挂很久。
- 更要紧的是：`doSync` 完成后会 `stickBottomRef = true` **重拉一页，直接拽走滚动位置**
  —— 这正是所有者反对的"影响前端展示"。
- 一轮同步不便宜：`client.messages(ch, 100)` 会翻页扫最多 **600 条原始消息**凑够 100 条媒体
  （`grammers.rs:64` `MEDIA_RAW_SCAN_CAP`，用于 `:344`），再加 ≤100 次串行 upsert
  → **手动按钮若保留必须改成 fire-and-forget**（点击即返回，进度去「入库流水线」看）。

## 评估结论

### ① 折叠控件

- 换成 **SVG chevron 独立按钮**，热区 ≥ 24×24（与 `TgPanel.tsx:1742-1743` 既有口径一致）。
- **与标题解耦**（点标题不再折叠）。
- 位置**保持左侧**（所有者未给倾向；左侧符合层级树惯例，且与右侧操作按钮区隔）。

### ②「立即同步」

- 推荐**弱化**而非硬删：移出监控列表标题行 → 放进「入库流水线」面板并带说明文案。
  理由：保留「刚加监控立刻要内容」的路径。
- 后端 `monitor_sync` 改 **fire-and-forget** + 单飞；前端不再 await、**不再重载 feed**。

## 待拍板

- **B-2**：「立即同步」弱化到「入库流水线」面板（推荐）还是直接移除。
- **B-4**：折叠箭头保持左侧（推荐）还是改右侧。所有者未给倾向。
- **A-3 连带**：搜索框上移（BUG-100）会腾出频道标题栏位置，本条的按钮去留需与之协同。

## 关联

**摘掉前端每 60s 催同步轮询（`TgPanel.tsx:756-777`）与后端 sync 单飞必须打包做，
只做一半都不够 —— 详见 BUG-102。**

## 验收要点（草案）

- 折叠箭头热区 ≥ 24×24，视觉可辨识。
- **点标题不再触发折叠**（解耦）。
- 手动同步点击后立即返回，不挂起；完成后**不重拉 feed、不拽走滚动位置**。

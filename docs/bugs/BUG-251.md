# BUG-251: 剧名已自带书名号时渲染层再套一层，近半数剧集显示成 `《《…》》`

- 状态: fixed
- 发现日期: 2026-10-10
- 模块: shell
- 严重程度: mid

## 现象

剧集标题是**自由文本**，用户/来源可能已经自带书名号。渲染层对剧名**无条件**再包一层
`《{title}》`，于是近半数剧集显示成双书名号 `《《…》》`。

QA 在 BUG-214 的独立验收里，于「批量删除确认清单」实测到：
`《《小镇上的熟母露出俱乐部》》 · 2 集`。

运行时真值（`GET http://127.0.0.1:19788/api/media/series`，本仓当前库）：
**35 条剧集中 17 条标题含 `《`（48.6%）、6 条标题以 `《` 开头**。样本：

```
'《小镇上的熟母露出俱乐部》'
'#ai短剧 #Ai成人短剧 《苏老师的裸贷人生》'
'😀😀😀😀😀😀😀😀 #《存在感零》'
```

## 根因

**渲染层无条件包裹书名号** —— 全仓既有惯例（非某一次提交引入），散布在两类位置：

- **硬编码处**（模板串/JSX 里直接写死 `《{x}》` / `` 《${x}》 ``）：
  - `tauri-shell/src/components/MediaLibraryPanel.tsx:1462/1463`（`` `已把《${sourceTitle}》…` ``）、`:1552`（`《{s.title}》 · {episodeCount} 集`）
  - `tauri-shell/src/components/media/SeriesDialog.tsx:269`（`《{target.title}》`）、`:305`（`` 将把《{source.title}》…并入《{target.title}》， ``）
  - `tauri-shell/src/components/media/EpisodeList.tsx:231`（`` `合并自《${ep.originSeriesTitle}》` ``）
- **i18n 键值模板内**（书名号写在 **JSON 模板里**，值里若已含 `《` 就会双写）：
  - `media.seriesSelectionToggle`（`选择《{title}》`）
  - `media.seriesMergeConfirmBody`（`…并入《{target}》，…`）
  - `media.seriesMergeMultiDone`（`已把 {n} 集并入《{target}》`）
  - `media.seriesMergeMultiDoneSkip`（`…并入《{target}》，…`）
  - `media.episode.originFrom`（`合并自《{title}》`）
  - 对应调用点：`SeriesCard.tsx:98/99`、`SeriesDialog.tsx:476`、`MediaLibraryPanel.tsx:1481/1486`、
    `EpisodeExpanded.tsx:320`、`EpisodeRow.tsx:178`、`SeriesDetail.tsx:872`

## 复现

媒体库 → 剧集墙 → 勾选标题自带书名号的剧集 → 「批量删除」→ 确认清单显示 `《《…》》`；
或打开任一含该剧名的合并/溯源文案。验收脚本随修复入库
（`tauri-shell/verify/verify_bug_251_series_title_brackets.cjs`）。

## 修复

**规则只有一条** —— 已含 `《` 就原样返回，否则包一层。不做括号增删、**不剥内部书名号**
（那会侵入标题内容：`#ai短剧 《X》` 里的 `《X》` 是标题自身的一部分）。

新增**唯一入口** `tauri-shell/src/lib/displayTitle.ts`：

```ts
export function seriesLabel(title: string): string {
  const t = (title ?? '').trim()
  if (t === '') return t
  return t.includes('《') ? t : `《${t}》`
}
```

改造两个方向：

1. **硬编码处**：`《{x}》` / `` 《${x}》 `` → `{seriesLabel(x)}`（先 trim，避免 `＇` 之类空隙）。
2. **i18n 处**：键值模板里的 `《{title}》` / `《{target}》` 去掉书名号（zh 与 en **同结构**、仅留 `{title}` 占位），
   在**传参处**传 `seriesLabel(...)`；en-US 侧原本的 `“{title}”` 一并规整为 `{title}`。

**不动** `SeriesCard.tsx` 卡片正面（`:163/164` 直接输出 `series.title`，本就不包裹，加 `seriesLabel` 会改变既有卡面外观）。

i18n 逐键 before/after（zh-CN / en-US）：

| key | before (zh) | after (zh) | before (en) | after (en) |
|---|---|---|---|---|
| `media.seriesSelectionToggle` | `选择《{title}》` | `选择{title}` | `Select “{title}”` | `Select {title}` |
| `media.seriesMergeConfirmBody` | `将把其余 {n} 个剧集并入《{target}》，…` | `将把其余 {n} 个剧集并入{target}，…` | `…merged into “{target}”, …` | `…merged into {target}, …` |
| `media.seriesMergeMultiDone` | `已把 {n} 集并入《{target}》` | `已把 {n} 集并入{target}` | `Merged {n} episodes into “{target}”` | `Merged {n} episodes into {target}` |
| `media.seriesMergeMultiDoneSkip` | `已把 {n} 集并入《{target}》，{m} 集…` | `已把 {n} 集并入{target}，{m} 集…` | `…into “{target}”, {m} …` | `…into {target}, {m} …` |
| `media.episode.originFrom` | `合并自《{title}》` | `合并自{title}` | `Merged from “{title}”` | `Merged from {title}` |

（键集合不增不减；`media.episode.originFromUntitled` 等其余键不受影响。）

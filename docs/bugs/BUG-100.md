# BUG-100: 监控内容搜索框位于频道标题栏，位置暗示「频道内」而行为是「跨频道」

- 状态: fixed
- 修复者: 主理人（工程师限流挡道，主理人接手）
- 修复 commit: 待归档
- 发现日期: 2026-09-21
- 模块: shell
- 严重程度: mid

> 立项方式：项目所有者提出「监控搜索的 Bar 应该放到顶部 Telegram 标题这层、放中间，
> 因为放在频道内让人感觉是频道内搜索」。
> 本条是**评估档**（未实施），结论见 `docs/design/tg-ux-assessment-summary.md`。

## 现象

搜索框位于**频道标题栏**（`TgPanel.tsx:1472-1478`），与频道头像、频道名、`@username` 同处一行，
紧邻「入库流水线」按钮与「监控中」Chip。

但它的**实际行为是跨全部监控频道搜索**：state `globalSearchInput` / `globalSearch`（`:277-282`），
300ms 防抖（`:651`），调 `searchTgMonitorMessages`（`api/tg.ts:177`）→ `/api/tg/monitor/search`；
输入非空时右列整体切成「结果视图」（`:1314` 起）。

→ **位置暗示「当前频道内」，行为却是「全局」**。所有者感受到的错位正来源于此，
**改位置是唯一有效解法**（只改文案无法消除位置语义）。

## 根因补充：搜索框实际有两个 DOM 实例

不是「唯一一个」，而是**两个**，绑同一个 `globalSearchInput` state、只显示其一：

1. 结果视图头部：`:1319-1326`（`flex-1` + `autoFocus`）
2. 频道标题栏：`:1472-1478`（`w-48`）

→ **上移时若只搬不删，会变成三份。** 收敛成一个是本次改动的必要部分。

附带：现状「输入关键词后框跳到另一个 header」本身就是一个所有者没报的体验毛病，收敛后顺带修掉。

## 评估结论：三条落位路径

| 路径 | 做法 | 评价 |
|---|---|---|
| **A（推荐）** | 移到 ContextBar 同层居中（与「Telegram」标题同层） | 只有与「Telegram」同层才能让「位置 = 全局作用域」，语义纠正力最强 |
| B（退路） | TgPanel 顶部 toolBar 居中（`:1046-1073`，目前只有「入库流水线」按钮、`justify-end`） | 成本约为 A 的 1/3，语义错位同样消除 |
| C（不推荐） | portal 注入 | 隐式 DOM 锚点 + 首帧时序坑（view 初始为 tg 时锚点尚未插入 DOM） |

**选 A 必须同时满足三条约束**：

1. 输入 state 走 zustand 切片 + **独立 `memo` 子组件** + 300ms 防抖，
   **禁止**放进 `ContextBar` / `MainLayout` 本体 —— `ContextBar.tsx:19-22` 注释明写它只吃低频 props
   以守 AGENTS.md §5 流畅约束；否则每次按键会重渲染 2000+ 行的 `TgPanel`。
2. 三槽各自可收缩，避免重演 BUG-040 的 min-content 钉死。
3. 切视图时清空搜索词的规则先定死。

**边界态（需知晓）**：TG 可用性门控（`alive` / `needConfig`）全在 `TgPanel` 内部，`MainLayout` 侧不可见
→ 方案 A 会出现「顶部能搜、面板在显示配置卡」。建议 TG 不可用时隐藏搜索框。

另外：tg 视图的 ContextBar 右槽**不是空的**（是 `ContextBarStatus` 连接态/速度/进行中），
所以上移**只能居中**，不能靠右。

## 已拍板（2026-09-21 所有者拍定）

- **A-3 落位 = 方案 A（顶部上下文栏那一行居中）**。

## 修复实施（主理人接管，工程师限流 429）

方案 A（ContextBar 同层居中）落地。两个未拍板项按文档建议默认值定：
- 切走再切回 → **清空**（`TgGlobalSearch.tsx` 卸载时 `useTgSearch.getState().clear()`）；

### 改动文件

- 新建 `tauri-shell/src/store/tgSearch.ts` —— 搜索状态独立 zustand 切片。`input`（高频）与 `committed`（防抖后）分两个字段：`TgGlobalSearch` 只订阅 `input`，`TgPanel` 只订阅 `committed`，避免每按键重渲染 2000+ 行（AGENTS.md §5）。
- 新建 `tauri-shell/src/components/TgGlobalSearch.tsx` —— ContextBar 的中槽叶子，memo + 300ms 防抖 + 可用性门控 + 切离清空。
- 新建 `tauri-shell/src/components/TgCacheEntry.tsx` —— 上下文栏右槽的「入库流水线」入口；不再独占 TgPanel 顶行（详见 BUG-059 → 用户当时误称为 BUG-058 后续归位）。
- `tauri-shell/src/components/ContextBar.tsx` —— flex 改 `grid grid-cols-[minmax(0,1fr)_auto_minmax(0,1fr)]`；`TgGlobalSearch` 居中（实测左/右各 448px，精确居中），`TgCacheEntry` 在右槽。
- `tauri-shell/src/store/useStore.ts` —— 新增 `tgCacheManagerOpen` + `setTgCacheManagerOpen`（开关需跨 `MainLayout`/`TgPanel` 共享）。
- `tauri-shell/src/components/TgPanel.tsx`：
  - 顶部工具条整块删除（1248×41 的容器里只有一个 89×28 的按钮，整行被单个按钮占着 —— 改完不再有空 div 占位）；
  - `:279-288` 本地 useState → `useTgSearch` 订阅；
  - `:656-659` 防抖 effect 移到 `TgGlobalSearch`；
  - 结果视图头部（`:1337-1361`）的 `<input>` 删除，只留范围说明 / 命中数 / 清除按钮（避免同一 state 出现第二个输入框）；
  - 频道标题栏（`:1495-1501`）的 `<input>` 删除；

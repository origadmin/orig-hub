# BUG-020: 剧集卡片无封面；首集为视频时把视频地址当图片 src，卡片被压扁遮挡标题

- 状态: fixed
- 发现日期: 2026-09-17
- 模块: engine+shell
- 严重程度: mid

## 现象

剧集墙 6 张卡片全部只有 🎬/🖼 占位符，没有封面；其中「Big Buck Bunny · 码率阶梯」
卡片高度明显矮于同排其他卡片，「剧集」类型徽标压在标题文字上。

## 根因

两个独立缺陷：

1. **封面恒为 NULL**：`media_series.poster` 从未被写入，`GET /api/media/series`
   也从不推导，前端拿不到任何图片地址。
2. **视频地址被塞进 `<img>`**：初版回退方案取「首集条目原图」作为封面，
   但首集是 `.mp4` 时 `mediaItemUrl()` 返回视频流地址，`<img src=*.mp4>` 必然加载失败，
   卡片内容塌陷导致相邻文本重叠。

## 复现

```bash
python verify_shots/probe_fixes.py    # 修复前 FAIL: every series has a cover -> 0/6
```

## 修复

- 后端 `list_series` 增加两个子查询：`cover_item_id`（首集条目 id）
  与 `cover_poster`（首个「已有 poster」的条目封面），
  并新增 `cover_kind`（首集类型）——**契约上区分 photo / video**，避免前端猜测。
  `poster = 显式封面 ?? 首集已存在封面`。
- 前端 `SeriesCard` 按 `coverKind` 分流：`photo` 直接原图；
  `video` 走与内容卡片同一套 canvas 抽帧（`generateVideoPoster`），
  成功后 `PATCH /api/media/series/:id` 持久化，下次直接复用。
- 抽帧同时把 `duration` / 分辨率回写，卡片获得时长徽标。

验收：`probe_fixes.py` 断言 `cover or coverItemId` 覆盖率 6/6；
`shot_media.cjs` 剧集墙截图 6 张封面全部真实渲染。

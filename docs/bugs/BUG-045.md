# BUG-045：TG 内容标签未进入标签收集

- 状态: fixed
- 发现日期: 2026-09-18
- 模块: engine
- 严重程度: high

## 现象
TG 内容的 caption `#标签` 没有正确进入标签收集。实测实例 11 个标签全部
0 关联（itemCount=0 且 seriesCount=0），标签体系与内容完全脱节。

## 根因
标签收集与归档**只在「整组缓存 ≥2 条」分支里发生**，且只归档到剧集：
- 单条视频缓存（占缓存任务的大多数）→ 无剧集 → caption 标签**整个丢失**；
- 组缓存建立的剧集被清理/合并删除后，`media_series_tag` 行随之消失，
  只留下孤儿标签 —— 除非恰有剧集留着，否则收集结果永远挂不到内容上。

## 修复（规则级：标签收集与成剧解耦）
1. **每次缓存任务完成都收集** caption `#标签`（跨消息去重、上限 20），
   不再要求 ≥2 条成组。
2. **归档目标两级**：本次任务产出了剧集 → 并集式并入剧集标签
   （原 ③b 语义不变）；没有剧集（单条缓存 / 纯图片组）→ 并集式落到
   **内容条目标签**（新增 `Store::add_item_tags_by_name`，union 不替换、
   主键 + IGNORE 去重，与剧集版语义一致）。
3. 服务端日志如实回报归档数量。

## 验收
单测 `item_tags_union_without_duplicates`：首次归档计数、重复归档 union
不产生重复关联、空白名忽略。线上实例重启后对已缓存内容验证标签关联。

# BUG-004: 无全局进度状态，状态栏仅计数无实时速度

- 状态: fixed
- 发现日期: 2026-08-26
- 模块: shell
- 严重程度: low

## 现象
应用底部状态栏只显示任务计数（如「3 下载中」），没有整体进度百分比 / 实时聚合
速度指示；多任务并行时无全局进度概览。

## 根因
`MainLayout` 仅按状态分组计数，未对活跃任务做下载量 / 总量聚合，也未渲染全局
进度条。

`file: tauri-shell/src/components/MainLayout.tsx`

## 复现
启动多个并行下载任务，观察底部状态栏是否出现聚合进度条与全局进度百分比。

## 修复
`tauri-shell/src/components/MainLayout.tsx`：
- 计算 `aggregate`（downloading / queued / paused）、`aggDownloaded`、
  `aggTotal`、`globalProgress`。
- 在 `<main>` 与 footer 之间渲染一条细全局进度条（`bg-accent` 宽度 =
  `globalProgress%`），当 `aggregate.length > 0` 时显示。

## 验收
- `npx tsc --noEmit` / `npm run build` → EXIT=0

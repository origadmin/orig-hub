# BUG-405: 标签过滤分两组件布局无整体感，功能按钮位置突兀需重设计

- 状态: fixed
- 发现日期: 2026-10-23
- 模块: shell
- 严重程度: mid

## 现象
标签过滤当前拆成两个独立组件实现，整体布局缺乏统一感；功能按钮的位置显得突兀，
与页面其它控件不成体系，需要重新设计（统一容器、统一按钮形态与落位）。

## 根因
标签过滤由 `<span>标签</span>` + `<Input flex-1>` 两个独立组件承载：输入框撑满整行过长、且「标签标题」与「输入框」是两个组件，缺乏统一容器与视觉语言（与右上角筛选 / 标题栏搜索框不一致）。

## 复现
待补。

## 修复
合并为单一紧凑 pill（不再撑满）：`w-56` 限宽容器，左侧 `Tag` 图标前缀 + 原生 `<input>`（限宽内 flex-1）+ 有值时显示清除按钮；复用标题栏搜索框视觉语言（圆角描边 + 图标前缀 + 限宽），不再拆成「标题 + 长输入框」两个组件。落点：MediaLibraryPanel.tsx:1478，`data-testid="media-tag-filter-wrap"` / `media-tag-filter`。

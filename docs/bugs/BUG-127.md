# BUG-127：`aria-label` 用了从未落地的 i18n 键 —— 读屏念出 `tg.monitorCollapse`

- 状态: fixed
- 严重程度: low
- 模块: shell
- 发现日期: 2026-09-22

## 现象

TG 面板监控列表的折叠按钮，**读屏（screen reader）念出的是原始键名**
`tg.monitorCollapse` / `tg.monitorExpand`，而不是「收起监控列表」/「展开监控列表」。

## 根因

`TgPanel.tsx:1171`：

```tsx
aria-label={monitorOpen ? t('tg.monitorCollapse') : t('tg.monitorExpand')}
```

而 `tauri-shell/src/i18n/locales/{zh-CN,en-US}.json` 里**从来没有这两个键**。

`i18n/index.ts:50` 的回退链是：

```ts
let str: string = dict[key] ?? MESSAGES['zh-CN'][key] ?? fallback ?? key
```

**缺省回退到 key 本身**（设计意图是「保证绝不空白」）—— 于是缺键不报错、不空白，
而是**把键名当文案渲染出来**。这是一个**静默失败**：界面上看不出错，只有读屏用户受影响。

## 为什么会出现（流程缺口，值得记一笔）

`docs/design/tg-ux-implementation-plan.md:61` **明确列了这一步**：

> 4. 新增 i18n 键 `tg.monitorCollapse` / `tg.monitorExpand`（`zh-CN.json` + `en-US.json`）。

也就是说**计划里有、代码里用了、资源文件里没有** —— 实施时漏落了计划中的一步，
而缺键回退到 key 的设计让它**不报错**，所以谁都没发现。

## 修复

在 `zh-CN.json` 与 `en-US.json` 各补两个键（`tg` 命名空间，与既有键同处）：

```json
"tg.monitorCollapse": "收起监控列表",   // en-US: "Collapse monitor list"
"tg.monitorExpand":   "展开监控列表"    // en-US: "Expand monitor list"
```

## 验收证据

**入库路径（跨机器可核）**：`tauri-shell/src/i18n/locales/zh-CN.json`、`en-US.json`
（键存在性可直接 grep，无需运行环境、无需 daemon）。

**判据：有引用、无定义。** 两处命令在**修复前后**的取值必须相反：

```sh
# 引用方（TgPanel.tsx）—— 修复前后都应恒为 1
git show <commit>:tauri-shell/src/components/TgPanel.tsx | grep -c monitorCollapse

# 定义方（locale 文件）—— 缺陷态 0，修复后 1
git show <commit>:tauri-shell/src/i18n/locales/zh-CN.json | grep -c monitorCollapse
git show <commit>:tauri-shell/src/i18n/locales/en-US.json | grep -c monitorCollapse
```

| commit | 说明 | TgPanel 引用数 | zh-CN 定义数 | en-US 定义数 |
|---|---|---|---|---|
| `5242262` | 修复前（缺陷态） | 1 | **0** | **0** |
| `6e12b60` | 修复后 | 1 | 1 | 1 |

**`引用=1 且 定义=0`** 即是本条缺陷的可核判据；修复后两者同为 1。

> 这条判据本身也是**反向可证伪**的：它在缺陷态给出 0、修复后给出 1，
> 不是一条恒真断言。但它**不能**证明「读屏真的念对了」—— 那需要 aria-label 的
> 渲染级断言，见下。

### 未覆盖（如实标注）

- **未做渲染级验收**：断言需要切到 TG 面板、展开监控列表，且文案在 `aria-label`
  属性上而非 DOM 文本里，本轮未写自动化断言。故本条的验收是**静态键存在性核对**，
  证据强度**低于** BUG-123 的渲染验收，如实标注。
- 本缺陷由**本次会话顺带发现并修复**（改动此前未提交地留在工作区），非用户报告。

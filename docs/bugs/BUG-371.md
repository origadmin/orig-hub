# BUG-371: 弹窗标题两套规格并存 —— 3 个 `h2`/16px、6 个 `h4`/13px，标签级别与字号都不一致

- 状态: fixed
- 发现日期: 2026-10-22
- 模块: shell
- 严重程度: mid

## 现象

用户 2026-10-22 复报第 1 条（原话，标注「多次提出未解决」）：

> 「1. 下载标题不统一行问题,多次提出未解决.」

当我问「统一成哪一种命名」时，用户把问题**拨回了基础层**（原话）：

> 「弹出窗口标题一致吗? 样式一致吗? 这些都是基础!!!」

即：要一致的不是条目名称，而是**弹窗本身的标题与样式**。

## 取证（9 个弹窗，逐个数）

弹窗标题（= 弹窗面板的第一个子元素）实测两套规格：

| 弹窗 | 改前标签 | 改前字号 |
|---|---|---|
| `AddDownloadDialog`「新建下载」 | `h2` | `text-base`（16px） |
| `DirectoryBrowserDialog`「选择目录」 | `h2` | `text-base` |
| `InterfacePickerDialog`「选择网卡」 | `h2` | `text-base` |
| `ItemEditDialog`「编辑信息」 | **`h4`** | **`text-[13px]`** |
| `SeriesDialog`「新建剧集」 | **`h4`** | **`text-[13px]`** |
| `TagManagerDialog`「批量标签」+「管理标签」 | **`h4`** | **`text-[13px]`** |
| `ImportDialog`「导入本地目录」 | **`h4`** | **`text-[13px]`** |
| `ExportPreviewDialog`「导出预览」 | **`h4`** | **`text-[13px]`** |
| `EpisodeImagePickerDialog`「选择图片」 | **`h4`** | **`text-[13px]`** |

两处不一致，都不是审美问题：

1. **字号差 3px**（16 vs 13）：13px 恰在 BUG-327 门槛的「正文 ≥13px」下沿，作为**弹窗标题**偏小，且与另外 3 个弹窗并排时肉眼可辨；
2. **标题标签级别不同**（`h2` vs `h4`）：同一层的界面元素用了差两级的标题标签 ⇒ 文档大纲/读屏软件的标题层级是断的。这是「样式一致」底下的结构问题，比字号更难靠肉眼看出来。

## 修复

统一到既有的大多数正确规格：`<h2 className="text-base font-semibold text-fg-strong">`。

- 6 个文件的 7 处弹窗标题由 `h4` + `text-[13px]` 改为 `h2` + `text-base`（`TagManagerDialog` 有两颗，都改）；
- **不动弹窗内的节标题**：`SeriesDialog:140`、`SeriesEditPanel:105`、`EpisodeExpanded` 的 `h4 text-[13px]` 是弹窗/展开块内部的节标题，层级本就该低于弹窗标题，保持 `h4` 是正确的。

## 验收证据

改动落点（均为入库路径）：
- `tauri-shell/src/components/media/ItemEditDialog.tsx`
- `tauri-shell/src/components/media/SeriesDialog.tsx`
- `tauri-shell/src/components/media/TagManagerDialog.tsx`
- `tauri-shell/src/components/media/ImportDialog.tsx`
- `tauri-shell/src/components/media/ExportPreviewDialog.tsx`
- `tauri-shell/src/components/media/EpisodeImagePickerDialog.tsx`

已核验：
- 全仓 `<h2 className="text-base font-semibold text-fg-strong">` 现为 **11 处**（9 个弹窗标题 + `SettingsPanel` 标题 + `AddDownloadDialog`，全部同规格）；
- `tsc --noEmit`：**0 错**；
- 残留复核：`h4 text-[13px] font-semibold` 仅剩 4 处，全部是**弹窗内节标题**（`SeriesDialog:140`、`SeriesEditPanel:105`、`EpisodeExpanded:123/127`），符合层级。

## 关联

- BUG-327：可读性门槛（13px 是正文下沿，作弹窗标题偏小）；
- BUG-367：同一次复报的第 1 条另一面（文件列表命名不统一）—— 用户这次拨回基础层，指的是本登记；
- BUG-361：`cn` 尺寸类仲裁（同类「同一属性两处写法」的结构性根源）。

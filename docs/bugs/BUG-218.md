# BUG-218: 4x 倍速控件层可见期（前约 3 秒）上屏节拍劣化 —— BUG-217 残余

- 状态: open
- 发现日期: 2026-10-08
- 模块: shell
- 严重程度: low
- 排期: 2026-12-26

## 现象

4x 倍速播放的**前约 3 秒**（`showControls` 自动隐藏前的控件层可见期）视频上屏节拍劣化：窗口①口径
（从播放起采 10s、含约 3s 可见期）3 轮中位 `gapP95 = 32.7ms`、`gt25 = 32`。**同轮**用
`<style>[role="toolbar"]{display:none!important}</style>` 强制隐藏控件层（C 臂，B12 口径）则回到
`gapP95 = 17.5ms`、`gt25 = 11`（`tauri-shell/verify/_probe_visible_window.cjs`，A/B/C 同轮交替）。
**2x 无此现象**：A 臂 `gapP95 = 17.8ms` vs C 臂 `17.3ms`（A≈C）⇒ 代价**只在 4x 出现**。

窗口① 三臂原始（3 轮中位）：

| 倍速 | 臂 | presented | gapP50 | gapP95 | gapMax | gt25 |
|---|---|---|---|---|---|---|
| 2x | A 现状（可见约 3s） | 58.1 | 16.7 | 17.8 | 33.8 | 18 |
| 2x | C 强制隐藏（上界） | 58.3 | 16.7 | 17.3 | 84.4 | 13 |
| 4x | A 现状（可见约 3s） | 56.8 | 16.7 | 32.7 | 116.4 | 32 |
| 4x | C 强制隐藏（上界） | 58.5 | 16.7 | 17.5 | 97.4 | 11 |

（B 臂 = A + 控件层 `transform:translateZ(0)`，见「已排除」①。）

## 根因（**未定** —— 以下为假设，尚未验证）

假设：**4x 下解码 / 合成资源已饱和**（4x 真解约 240fps），控件层的首绘 + 渐变遮罩与之争用合成资源；
2x 有富余故不显现。**此假设未经实验验证**，请勿当作结论。

## 已排除（本档最有价值的部分）

① **合成层提升无效**：给控件层加 `transform:translateZ(0)`（运行时注入，非改源码；实测 computed
   `transform` 为 `matrix(1,0,0,1,0,0)`，确已生效）只把 4x `gapP95` 从 32.7 改善到 29.6（**仅 3.1ms**），
   离 C 的 17.5 差 12.1ms ⇒ **不是**「控件层与 video 共合成上下文」。
② **常显控件层内无昂贵滤镜**：`VideoPlayer.tsx` 的 `backdrop-blur-sm/md` 出现在居中播放键 / 缓冲 /
   错误文案 / 信息卡 / 倍速菜单（**均非播放中常显的控件层**）；常显层内只有进度条拇指 `shadow-lg`
   与一条纯 alpha 渐变 ⇒ 代价**不是**滤镜直接造成的。
③ **静态全尺寸 `opacity:0` 覆盖层不伤视频**：B1 实验（app 式祖先链 + 空 `opacity:0` 覆盖层）
   ≈ 裸 video（2x 59.4/17.2/5、4x 58.8/17.2/6）⇒ **不是**「多了一层」。
④ **稳态无代价**：控件隐藏后（t=4s 起采 10s）app 与同轮裸 `<video>` 等价（窗口③ Δ 全达标：
   ΔgapP95 −0.1 / +0.1、Δgt25 −2 / −2、|Δpresented| 0.0 / 0.7）⇒ 问题**只在可见期**。

## 影响面

- 仅 **4x 倍速 + 控件可见的前约 3 秒**窗口；此后控件自动隐藏，代价消失。
- **1x / 2x 不受影响**（2x A≈C）。
- **稳态不受影响**（窗口③ app ≈ bare）。

## 复现

```sh
cd tauri-shell
ROUNDS=3 RATES=2,4 SAMPLE_MS=10000 node verify/_probe_visible_window.cjs   # 三臂 A/B/C
```

A = 现状；B = A + 控件层 `transform:translateZ(0)`；C = `[role="toolbar"]{display:none!important}`（上界）。

## 修复后必须满足（可证伪判据）

1. 窗口①口径 4x：`gapP95 ≤ 22ms` **且** `gt25 ≤ 18`（当前 32.7 / 32）。
2. 同轮 A 臂与 C 臂 `ΔgapP95 ≤ 5ms`。
3. 2x 不回归：`gapP95 ≤ 20ms`。

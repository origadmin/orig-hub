# BUG-062: TG 提交验证码缺 `phone` 字段被 422 拒绝

- 状态: fixed
- 发现日期: 2026-09-16
- 模块: shell
- 严重程度: high

## 现象

TG 登录流程走到「输入验证码」这一步时，提交必然失败（HTTP 422 反序列化错误），
表现为「手机号已填、码也收到了，就是登不进去」。

## 根因

前端 `submitTgCode` 只提交了验证码，没有把 `phone` 一起带上，而
`POST /api/tg/code` 的请求体把 `phone` 声明为必需字段 —— serde 在反序列化阶段直接拒绝，
请求根本没进入业务分支。表单里 phone 是有的，只是提交时被漏掉。

## 复现

1. 未登录状态打开 TG 面板，走「发码 → 输码」流程；
2. 提交验证码，观察响应为 422 且错误指向缺失字段 `phone`。

（事后追认：本条由已发生的修复提交反推登记，无当时的独立复现脚本。）

## 修复

提交 `88f6a10`（`fix(tg): submitTgCode missing required phone field (422 deserialization)`）：
`tauri-shell/src/api/tg.ts` 与 `tauri-shell/src/components/AccountsPanel.tsx` 补传并贯通 `phone`。

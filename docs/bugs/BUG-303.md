## 现象

1. 库内成品在局域网内**没有只读浏览面**（只能拷文件或各自开播放器）。
2. daemon 现在只有一个绑定点（`config.bind`，默认 `127.0.0.1`），
   没有「默认关闭、可按网卡/端口/令牌单独开启」的第二绑定面。
3. 无令牌鉴权、无写方法拒绝、无「停用即关端口」的证明，
   一旦误开就是**无鉴权的内网写入口**。
4. 前端无 SharePanel（M0-T06 只有占位页），共享目标（库/剧集/标签/条目集）无选择器、
   无独立开关/令牌/有效期/撤销。

## 根因

- 目标态（`08-plugin-architecture.md` + `04-api-contracts.md`）里共享是 **daemon 的一个可选绑定面**：
  网卡枚举复用 `/api/interfaces`，只读路由 `/s/*`，投递走 M1-T04 的共享 crate；
  现状这些都不存在，`serve_local_file` 的六铁律（BUG-031/033）只有一份原样实现，未按绑定面区分。
- 前端「共享」一级位在 M0 只是占位卡（BUG-298 M0-T06），本档才填内容。

## 复现

1. `netstat -ano | grep LISTENING` → 除 `127.0.0.1` 外无监听（**这是期望态，本档要保持**）；
2. 访问 `/s/...` → 404（端点不存在）；
3. 设置内无「共享」区块（M0 后为占位）。

### 出口判据

1. **默认无监听** netstat 证据（这是安全默认值，不是「没做完」）；
2. 无令牌 401、写方法 405（`PUT/POST/DELETE /s/...`）、停用即关端口、旧令牌重置即失效；
3. `diag_rate_storm.cjs` 非环回用例冗余倍数**个位数**（与环回不限速的口径并存，BUG-199）；
4. 投递铁律六条在 `/s/*` 上逐条复证（无 Range→200 全文；`bytes=S-`→206+32MiB；ETag/Last-Modified；MIME 禁 jpeg 兜底；码率×预算节流）；
5. **反向证伪**：故意把一个目标令牌置空后仍能取到内容 → 必须 FAIL（否则鉴权不是守卫）。

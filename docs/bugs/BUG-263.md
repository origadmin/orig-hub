# BUG-263: 内容编辑弹窗整体未接 i18n —— 整窗硬编码中文，同窗中英混排

- 状态: fixed
- 修复日期: 2026-10-12
- 发现日期: 2026-10-10
- 模块: shell
- 严重程度: low
- 登记: BUG-258 实现 worker 顺带发现、按文件归属约束停手未修（`i18n/locales/*.json` 当时归并行 worker 独占）。

## 现象

`tauri-shell/src/components/media/ItemEditDialog.tsx`（内容编辑弹窗）**通篇硬编码中文**，未走 i18n：
`编辑内容` / `类型：` / `大小：` / `归属：` / `标题` / `标签` / `取消` / `保存` / `清除缓存文件` 等。
而同文件「来源」一行走了 `t(sourceLabelKey(item.source))` ⇒ **同一个弹窗内中英混排**。

`SeriesEditPanel.tsx` 同类问题（`编辑剧集` / `年份（可选）` 等）。

英文界面（`getLanguage() === 'en-US'`）下这些文案仍显示中文。

## 成因（比「漏接 i18n」更具体，值得记档）

BUG-258 缺陷 3 的根因**不是**忘了写映射，而是**映射逻辑被复制成了两份**：
`MediaCard.tsx` 与 `ItemEditDialog.tsx` 各写一份 `kindLabel()`，而**内容弹窗那份漏了 i18n 映射**，
于是直接渲染后端原始枚举。BUG-258 已把映射上收到 `api/media.ts#seriesKindLabelKey()`，
消除了重复实现——**这才是该类缺陷的正解**（收敛单一真源，而不是逐处补翻译）。

本条是同一类缺陷的剩余部分：整窗文案仍未接 i18n。

## 修复（已落地，2026-10-12）

`ItemEditDialog.tsx` 全文接 i18n（约 15 个 `media.item.*` 新键：`editMeta` / `kind` /
`title` / `desc` / `descHint` / `descPlaceholder` / `size` / `path` / `series` / `saving` /
`cacheClear` / `cacheNone` / `cacheConfirm` / `cacheKeep`，复用既有 `media.fromSource` /
`media.cancel` / `media.save` / `media.confirm` / `media.tags` / `media.kind*`）；en-US /
zh-CN 双语补全。

`SeriesEditPanel.tsx` 经核查**不在本缺陷范围内**：其 CJK 出现位置全部位于代码注释
（块注释 / 行内注释），渲染期 JSX 文本均已走 `t()` 键，不呈现中文字面量；故本次不改动。

`kindLabel()` 第三份副本核查：BUG-258 已把映射收敛到 `api/media.ts#kindLabelKey()` 单一真源，
`ItemEditDialog` 现复用 `kindLabelKey(item.kind)`，无独立副本残留。

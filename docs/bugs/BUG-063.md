# BUG-063: 代理自检误报「不可达」

- 状态: fixed
- 发现日期: 2026-09-16
- 模块: engine
- 严重程度: mid

## 现象

设置了 SOCKS5 代理时，代理自检报「不可达」，但把同一个代理填进别的工具却能通 ——
用户被引向「代理坏了」的错误方向，实际是自检本身的 DNS 解析与 TLS 栈选择有问题。

## 根因

自检走 HTTP 客户端默认路径：DNS 在**本地**解析（而非经代理解析），证书校验走默认 TLS 栈。
对于形如 `socks5h://` 的代理（h 表示远端解析域名），本地解析会失败或解析到错误地址，
于是连通性判定为假 —— 自检报告的不是代理状态，而是本机 DNS 状态。

## 复现

1. 配置 `socks5h://` 代理（域名需由代理解析），本机 DNS 无法解析目标域名；
2. 触发代理自检：报 unreachable；
3. 走代理实际请求同域名：成功。

## 根因

1. **只建档不提交**：每轮都新建 `docs/bugs/BUG-<n>.md` 和验证脚本，但从没把它们纳入提交。缺陷追踪的全部价值在于「可追溯」，未入库 = 不可追溯 = 没有追踪。
2. **BUG-364 把 `fixed` 当交付**：修复代码写完了、档写了、状态填了 fixed，但 `## 验收证据` 留的是 `<!-- 待探针全绿后回填 -->`。**验收从来没跑过。** 本轮第一次真跑，结果是 25 PASS / 2 FAIL（`R3` 定位超时未命中、`A1` 锚点不存在）—— 也就是说这条「fixed」在提交时是不成立的。
3. **调试行污染验收锚**：`TgPanel.tsx` 里留着 10 处 `B364DIAG` 临时 `console.error`，把探针的字节级证伪锚点冲掉，`A1 occurrences=0` ⇒ `FATAL-EXIT` ⇒ 整轮验收跑不出任何结论。取证用的临时代码没有清理，反过来让验收永久失效。
4. **dev 栈守护到期即全线崩塌**：`dev_services.py --start; sleep 28800` 的 keeper 跑满 8 小时后自然结束，vite 单开任务随之被回收，`5180` 返回 `000`。取证做到一半栈没了，直接表现为「流程死、卡」。
